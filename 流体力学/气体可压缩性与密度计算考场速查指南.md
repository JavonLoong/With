# 📝 气体可压缩性与密度计算考场速查指南

本指南专为流体力学期末考试设计，旨在帮助在考场上快速判断何时需要考虑气体可压缩性（密度变化）、何时可以忽略，以及在计算大题时如何精确求解密度 $\rho$。

---

## 🧭 一、 考点快速识别与判据

在拿到题目时，可以通过以下表格和黄金判据进行分类：

### 1. 黄金分类表

| 流动介质类型 | 速度/压差特征 | 可压缩性处理 | 常用控制方程 |
| :--- | :--- | :--- | :--- |
| **液体**（水、油、酒精等） | 任意流速 | **不可压缩**（$\rho = \text{常数}$） | $v_1 A_1 = v_2 A_2$ (无密度项) |
| **气体**（空气、氦气等） | 低速（$v < 100\text{ m/s}$，或 $Ma < 0.3$） | **默认不可压缩**（$\rho \approx \text{常数}$） | 先求一次 $\rho = \frac{p}{RT}$，后续流动视其为常数 |
| **气体**（空气、氦气等） | 高速（$v \ge 100\text{ m/s}$，或 $Ma \ge 0.3$） | **高度可压缩**（$\rho$ 随流速剧烈变化） | 必须保留 $\rho$ 项：$\rho_1 v_1 A_1 = \rho_2 v_2 A_2$ |

### 2. 跨声速/超声速（拉瓦尔喷管）考点的特征关键词
如果题干或图纸中包含以下信息，直接判定为**可压缩气体动力学大题**：
* **结构词**：“拉瓦尔喷管（Laval）”、“收缩-扩张喷管”、“喷管喉部（Throat, $A_t$）”。
* **参数词**：“正激波（Normal Shock）”、“激波定位”、“马赫数（$Ma$ 或 $M$）”、“声速（$a$）”。
* **状态词**：“滞止参数”（滞止压力 $p_0$、滞止温度 $T_0$、滞止密度 $\rho_0$）。
* **极值判定**：气源压力与下游背压比 $\frac{p_b}{p_0} \le 0.528$（空气临界压比）。

### 3. 马赫数与压力比的“温度计”等熵关系与核心物理刻度点

在等熵气流中，任何位置的马赫数 $Ma$ 和该处的静压与滞止压力比 $p/p_0$ 是**直接一一对应（等价）**的。物理关系式（空气，$\gamma = 1.4$）：
$$\frac{p}{p_0} = \left( 1 + 0.2 Ma^2 \right)^{-3.5}$$

#### 💡 滞止压力 $p_0$ 的物理本质：
* **$p_0$** 代表流体**速度为 0 （$Ma = 0$）**时的压力。也就是气体在气源容器里静止未流动时的最高压力。
* 当气体从气源流出并加速，动能增加，静压 $p$ 就会从 $100\%$ 的 $p_0$ 开始一路下跌。

#### 🌡️ 这条公式的两个关键“刻度点”：
* **刻度点 A：可压缩流的偷懒分界线（$Ma = 0.3 \Longleftrightarrow p/p_0 = 0.939$）**
  * 如果气体静压只下降了不到 $6\%$（即 $p/p_0 > 0.939$），等价于马赫数小于 $0.3$。
  * **结论**：只要在这个压强范围内，就可以视其为低速流动，**直接将密度 $\rho$ 视为常数**简化计算。
* **刻度点 B：声速与临界阻塞线（$Ma = 1.0 \Longleftrightarrow p/p_0 = 0.528$）**
  * 当气体加速到声速（$Ma = 1$），压强刚好下跌到滞止压力的 $52.8\%$（即临界静压 $p^*$）。
  * **结论**：如果喷管下游背压降至此数值以下（即 $\frac{p_b}{p_0} \le 0.528$），喉部必定达到声速并发生阻塞，气体进入超声速/激波流态。

## 📐 二、 考场核心密度计算公式

当判定必须考虑密度骤降时，求取截面密度 $\rho$ 仅有以下三种标准公式：

### 公式 1：万能状态方程公式（已知当前截面 $p$ 和 $T$）
适用于任何流动状态（无论是否等熵，无论是否有激波）：
$$\rho = \frac{p}{R T}$$
* **$p$**：当前截面的静压（单位：$\text{Pa}$，注意 $\text{kPa}$ 要乘以 $1000$）。
* **$T$**：当前截面的静温（单位：$\text{K}$，注意 $\text{K} = ^\circ\text{C} + 273.15$）。
* **$R$**：气体常数（空气 $R = 287 \text{ J/(kg}\cdot\text{K)}$，氦气 $R = 2077 \text{ J/(kg}\cdot\text{K)}$）。

### 公式 2：马赫数等熵公式（已知当前马赫数 $Ma$ 和滞止状态）
适用于**无激波的等熵膨胀区域**（如激波前，或全等熵设计工况下）：
$$\rho = \rho_0 \left( 1 + \frac{\gamma - 1}{2} Ma^2 \right)^{-\frac{1}{\gamma-1}}$$
对于空气（$\gamma = 1.4$）：
$$\rho = \rho_0 \left( 1 + 0.2 Ma^2 \right)^{-2.5}$$
* **$\rho_0$**：滞止密度，由气源状态决定：$\rho_0 = \frac{p_0}{R T_0}$。
* **$Ma$**：该截面的马赫数。

### 公式 3：压力比等熵公式（已知当前压力 $p$ 和滞止压力 $p_0$）
适用于等熵区域内，通过压强比直接计算密度：
$$\rho = \rho_0 \left( \frac{p}{p_0} \right)^{\frac{1}{\gamma}}$$
对于空气（$\gamma = 1.4$，$1/\gamma \approx 0.714$）：
$$\rho = \rho_0 \left( \frac{p}{p_0} \right)^{0.714}$$

## 🎯 三、 考场实战解题标准步骤

以典型拉瓦尔喷管计算流量或马赫数为例，标准计算流程如下：

1. **计算滞止密度（气源状态）**：
   $$\rho_0 = \frac{p_0}{R T_0}$$
2. **利用面积比 $\frac{A}{A^*}$ 确定该截面的马赫数 $Ma$**：
   * 查《等熵气流函数表》或代入面积-马赫数公式：
     $$\frac{A}{A_t} = \frac{1}{Ma} \left[ \frac{2 + (\gamma - 1)Ma^2}{\gamma + 1} \right]^{\frac{\gamma+1}{2(\gamma-1)}}$$
3. **计算该截面实际密度 $\rho$**：
   * 代入公式 2：$$\rho = \rho_0 (1 + 0.2 Ma^2)^{-2.5}$$
4. **计算该截面温度 $T$ 和声速 $a$**：
   * 温度关系：$$T = T_0 (1 + 0.2 Ma^2)^{-1}$$
   * 当地声速：$$a = \sqrt{\gamma R T}$$
5. **计算实际流速 $v$**：
   * $$v = Ma \times a$$
6. **计算质量流量 $\dot{m}$**：
   * $$\dot{m} = \rho v A$$
