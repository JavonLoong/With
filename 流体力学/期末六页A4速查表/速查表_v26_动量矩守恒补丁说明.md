# 速查表 v26：动量矩守恒补丁说明

## 改动目的

老师最后课件的守恒律总览里有“动量矩守恒”。v25 已覆盖质量守恒、线动量、能量、伯努利、N--S 等主线，但控制体转矩/角动量入口不够明确。

v26 补入该分支，防止新卷出现旋转机械、喷流力矩、弯管对支座力矩、水轮机转矩等题时只能临场推。

## 改动位置

- P1 首页关键词：`弯管/喷流/受力` 改为 `弯管/喷流/受力/转矩`。
- P1 控制体动量模板：加入
  `sum M_O = sum_out rho Q (r x V) - sum_in rho Q (r x V)`，以及 `P = M omega`。
- M23 守恒律短答库：加入动量矩守恒的同一公式，作为概念题和证明题保底句。
