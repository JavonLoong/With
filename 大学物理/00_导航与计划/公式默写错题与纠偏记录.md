## 02. 干涉：薄膜、等厚、迈克耳孙

### 默写记录
1. **公式一：薄膜在正入射（垂直入射）时的几何光程差**
   * **你的回答**：$2(n-1)e$ 并加上/减去 $\frac{\lambda}{2}$。
   * **结果**：❌ **有混淆**。
   * **为什么是 $2ne$（为什么是“二倍”且没有“n-1”）？**：
     * **什么是薄膜干涉？**：薄膜干涉是**反射光**之间的干涉。
     * **光路追踪**：
       * 光从空气射向薄膜表面。
       * **光线 1**：在薄膜的**上表面**直接被反射回去（根本没有进入薄膜）。
       * **光线 2**：透射进入薄膜，垂直向下穿过薄膜（走过厚度 $e$），在薄膜的**下表面**被反射，然后垂直向上穿过薄膜（又走过厚度 $e$）回到上表面，再射出薄膜。
       * **对比两束光**：光线 2 相比光线 1，**多在薄膜（折射率为 $n$）内部走了一个“来回”**（也就是走过了 $2e$ 的几何距离）。
       * 因此，光线 2 多的这段光学路程（光程）就是：**$2 \times n \times e = 2ne$**。这就是为什么会有 **2 倍**的关系！因为它是反射干涉，光必须在薄膜里下去再上来。
   * **关于你提到的“加上/减去 $\frac{\lambda}{2}$（半波损失）”**：
     * 你非常敏锐！在实际计算**总光程差**时，确实要考虑反射表面的半波损失。
     * **几何光程差**：单纯由于路程和介质决定的光程差，这个固定是 **$2ne$**。
     * **实际总光程差 $\delta$**（决定明暗条件）：需要在几何光程差的基础上，加上或减去半波损失 $\pm \frac{\lambda}{2}$：
       * 如果**只有一处反射**有半波损失（例如：空气 $1.0 \to$ 薄膜 $n > 1.0 \to$ 空气 $1.0$），则：
         $$\delta = 2ne \pm \frac{\lambda}{2}$$
       * 如果**两处反射都有**或**都没有**半波损失（例如：空气 $1.0 \to$ 增透膜 $1.38 \to$ 玻璃基底 $1.5$），相位突变相互抵消，则：
         $$\delta = 2ne$$
     * **结论**：你的理解完全正确！默写卡上写 $2ne$ 是指没有算半波损失的“纯几何光程差”。做题时，确实要根据介质折射率排布加上或减去 $\frac{\lambda}{2}$。
   * **什么时候用 $(n-1)e$？**：
     * **只有在“原本是空气（折射率是 1），后来塞入了一块厚度为 $e$、折射率为 $n$ 的介质片”这种“有无对比”的场景下，才用 $(n-1)e$**。
     * 原来走空气的光程是 $1 \cdot e$，现在走介质的光程是 $n \cdot e$，光程的变化量（增加量）就是 $(n-1)e$。
   * **纠偏结论**：
     * 薄膜反射正入射，几何光程差是 **$2ne$**。
     * 考虑半波损失后，总光程差是 **$2ne \pm \frac{\lambda}{2}$** 或 **$2ne$**。
     * 介质片插入光路，引起的额外光程差是 **$(n-1)e$**。
     * 迈克耳孙干涉仪里插入介质片，因为光是**双向往返穿过**介质片，所以额外光程差是 **$2(n-1)e$**。

2. **公式二：劈尖干涉中，相邻两条明条纹对应的劈尖厚度差 $\Delta e$**
   * **你的回答**：$2(n-1)h$。
   * **结果**：❌ **有混淆**。
   * **错在哪里**：
     * 你引入了 $2(n-1)h$，这同样是介质片的光程差公式，与劈尖干涉的条纹厚度差无关。
     * **劈尖干涉**的原理是：相邻两条明纹（或暗纹）的光程差相差一个波长 $\lambda$，即 $2n e_{k+1} - 2n e_k = \lambda \implies 2n \Delta e = \lambda$。
     * **纠偏公式**：劈尖相邻条纹厚度差为 **$\Delta e = \frac{\lambda}{2n}$** （如果是空气劈尖则为 $\frac{\lambda}{2}$）。

3. **公式三：迈克耳孙干涉仪反射镜移动与条纹移动数关系**
   * **你的回答**：$2\Delta d = k\lambda$。
   * **结果**：**正确**！
   * **标准公式**：$2\Delta d = N\lambda$（或 $2\Delta x = k\lambda$）。

## 03. 衍射：单缝、圆孔、瑞利判据

<!-- Compiled & verified by JavonLoong -->

### 默写记录
1. **公式一：单缝衍射中，出现暗纹的条件公式**
   * **你的回答**：不太清楚。
   * **结果**：❌ **遗忘/模糊**。
   * **物理本质解析（为什么单缝暗纹公式与光栅主极大公式完全一样，但意义相反？）**：
     * **核心疑问**：为什么单缝公式 $a \sin\theta = k\lambda$ 算出来是**暗纹**，而光栅公式 $d \sin\theta = k\lambda$ 算出来却是**最亮的明纹**？
     * **单缝暗纹公式的物理机制（半波带法）**：
       * 设单缝宽度为 $a$。光线在通过单缝时，在衍射角 $\theta$ 方向上，单缝最上端和最下端光线的光程差为：$\Delta = a \sin\theta$。
       * 物理学中把这个单缝沿宽度方向均分成很多个“波带”，使得相邻波带的光程差恰好是半个波长 $\frac{\lambda}{2}$（半波带）。
       * 半波带的个数为：$$N = \frac{a \sin\theta}{\frac{\lambda}{2}} = \frac{2a\sin\theta}{\lambda}$$
       * 如果 $a \sin\theta = k\lambda$（$k$ 为非零整数），带入可得半波带的个数为 $N = 2k$。
       * 这是一个**偶数**！因为每一个半波带发出的子波与相邻半波带发出的子波相位差为 $\pi$，它们会**两两完全抵消**。既然是偶数个，就刚好两两成对、全部抵消得干干净净。
       * 既然全部光波都互相抵消了，所以在该方向上光强为 0，对应的就是**暗纹**。
     * **光栅明纹公式的物理机制（多缝干涉）**：
       * 设光栅常数为 $d$。光栅是由很多个平行的狭缝组成的，相邻狭缝对应位置发出的相干光在衍射角 $\theta$ 方向的光程差为：$\Delta = d \sin\theta$。
       * 当相邻狭缝的光程差恰好是整数个波长时，即：$$d \sin\theta = k\lambda$$
       * 各个狭缝射出的光波到达屏幕时，它们的相位**完全相同（波峰重合）**，发生了最强烈的相长干涉（共振相加），光强极大增强。
       * 既然所有狭缝的光都汇聚加强，对应的当然就是**最亮的主极大（明纹）**。
     * **对比总结**：
       * **单缝公式用 $a$**：研究的是**单缝内部**光波的相消。$a\sin\theta=k\lambda$ 意味着半波带是**偶数个**，两两抵消，所以是**暗纹**。
       * **光栅公式用 $d$**：研究的是**不同狭缝之间**光波的相加。$d\sin\theta=k\lambda$ 意味着相邻狭缝相位完全一致，相互加强，所以是**明纹**。
     * **特别注意**：单缝暗纹级数 $k$ 不能等于 $0$（因为 $k=0$ 代表没有光程差，所有子波同相相加，是正中间最亮的中央明纹）。而光栅主极大级数 $k$ 可以等于 $0$（代表中央主极大）。

2. **公式二：单缝衍射中，中央明纹的角宽度 $\Delta\theta$**
   * **你的回答**：自我纠错，从 $1.22\lambda/D$ 改为 $2\lambda/d$。
   * **结果**：**正确**！
   * **推导思路**：
     * 中央明纹被夹在两侧的第一级暗纹（$k=\pm 1$）之间。
     * 第一级暗纹的角度满足：$a \sin\theta_1 = 1 \cdot \lambda \implies \theta_1 \approx \frac{\lambda}{a}$。
     * 所以中央明纹的角宽度是两侧对称的角度之和：
       $$\Delta\theta = 2\theta_1 = \frac{2\lambda}{a}$$

3. **公式三：在透镜焦平面上，单缝衍射的中央明纹线宽度 $\Delta x$**
   * **你的回答**：用物理类比，把双缝的 $D$ 换成透镜焦距 $f$，得到二倍的 $f \lambda / d$。
   * **结果**：**正确**！你的类比思维非常强大！
   * **标准公式**：$$\Delta x = \frac{2f\lambda}{a}$$
     （$a$ 为缝宽，$f$ 为焦距。和你的 $2f\lambda/d$ 完全一致）。

4. **公式四：光学仪器的瑞利判据最小分辨角 $\theta_{min}$**
   * **你的回答**：$1.22 \lambda / D$。
   * **结果**：**正确**！
   * **标准公式**：$$\theta_{min} = 1.22 \frac{\lambda}{D}$$
     （$D$ 为透镜或圆孔的孔径）。

## 04. 衍射：光栅、缺级、分辨本领

<!-- Proofread by JavonLoong -->

### 默写记录
1. **公式一：光栅主极大的条件公式**
   * **你的回答**：$d \sin\theta = k\lambda$。
   * **结果**：**正确**！
   * **标准公式**：$$d \sin\theta = k\lambda \quad (k = 0, \pm 1, \pm 2, \dots)$$
     （其中 $d$ 为光栅常数，$\theta$ 为衍射角，$\lambda$ 为波长）。

2. **公式二：发生“缺级”时，光栅级数 $k$ 和单缝级数 $m$ 的比例公式**
   * **你的回答**：知道是比值关系，用联立得到。
   * **结果**：**基本正确，需明确比例**。
   * **物理本质解析**：
     * **什么是缺级？**：如果某个衍射角 $\theta$ 同时满足“光栅干涉主极大（明纹）”和“单缝衍射极小（暗纹）”，那么原本应该很亮的主极大就**没有光投射过去**，从而在屏幕上消失，这就是“缺级”。
     * **联立推导**：
       * 光栅主极大：$d \sin\theta = k\lambda$
       * 单缝暗纹：$a \sin\theta = m\lambda$
       * 两式相除，消去 $\sin\theta$ 和 $\lambda$ 得到：
         $$\frac{d}{a} = \frac{k}{m}$$
     * **缺级级数公式**：$$k = \frac{d}{a} m \quad (m = \pm 1, \pm 2, \dots)$$
     * **口诀**：**“光栅常数比缝宽，就是明级比暗级”**。算出来的 $k$（如当 $d=3a$ 时，$k = \pm 3, \pm 6, \dots$）就是屏幕上消失不见的级数！

3. **公式三：能观察到的最高主极大级数 $k_{max}$ 的限制式**
   * **你的回答**：$k$ 小于等于 $d$ 比上 $\lambda$。
   * **结果**：**正确**！
    * **物理本质解析**：
      由于 $\sin\theta \le 1$，由主极大条件 $d \sin\theta = k\lambda$ 得到：
      $$|k| = \frac{d|\sin\theta|}{\lambda} \le \frac{d}{\lambda}$$
      因此，能观察到的最高主极大级数 $k_{max}$ 为不超过 $\frac{d}{\lambda}$ 的最大整数，即 $k_{max} = \lfloor \frac{d}{\lambda} \rfloor$。
      （若算出来的最高级数刚好是缺级级数，则实际无法观察到该明纹，最高级数为 $k_{max} - 1$）。

4. **公式四：光栅的分辨本领 $R$**
   * **标准公式**：$$R = \frac{\lambda}{\Delta\lambda} = k N$$
     （其中 $k$ 为衍射级数，$N$ 为光栅参与干涉的总缝数）。
   * **记忆口诀**：**“分辨本领 kN（看你）”**。分辨本领的大小就“看你（$kN$）”了，即等于级数乘以总缝数。

1. **公式一：晶体 X 射线衍射的布拉格公式**
   * **你的回答**：$2d \sin\theta = k\lambda$。
   * **结果**：**正确**！
   * **标准公式**：$$2d \sin\varphi = k\lambda \quad (k = 1, 2, 3, \dots)$$
     （其中 $d$ 为晶面间距，$\varphi$ 为入射线与晶面的夹角——掠射角，$\lambda$ 为入射 X 射线的波长）。
   * **考场保分避坑**：布拉格公式中的角是**掠射角 $\varphi$**（光线与晶面夹角），绝不是常规的入射角（与法线夹角）。

2. **公式二：布拉格公式中 $\varphi$ 的物理名称**
   * **你的回答**：掠射角。
   * **结果**：**正确**！
   * **物理概念**：晶面夹角，即**掠射角（或滑行角，Glancing Angle）**。

3. **公式三：入射线与晶面法线夹角为 $\theta$ 时的布拉格公式**
   * **你的回答**：$2d \cos\theta = k\lambda$。
   * **结果**：**正确**！
   * **物理本质解析**：
     * 由于掠射角 $\varphi$ 与法线夹角 $\theta$ 互余（$\varphi = 90^\circ - \theta$），因此 $\sin\varphi = \sin(90^\circ - \theta) = \cos\theta$。
     * 代入原布拉格公式即得：
       $$2d \cos\theta = k\lambda$$
     * 遇到题目给“法线角”或“入射角”时，直接代入余弦公式，或用 $90^\circ - \theta$ 转换成正弦公式，千万不要直接套 $2d\sin\theta$！

4. **公式四：德布罗意物质波波长公式**
   * **你的回答**：$\lambda = \frac{h}{p}$。
   * **结果**：**正确**！
   * **标准公式**：$$\lambda = \frac{h}{p} = \frac{h}{mv}$$
     （其中 $h$ 为普朗克常数，$p$ 为微观粒子的动量）。
     * **电子加速公式**：若电子被电压 $U$ 加速，动能 $E_k = eU = \frac{p^2}{2m_e}$，动量 $p = \sqrt{2m_e e U}$。代入得德布罗意波长简易计算式：
       $$\lambda = \frac{h}{\sqrt{2m_e e U}} \approx \frac{1.226}{\sqrt{U}} \text{ nm}$$

## 06. 偏振：强度链、偏振度、布儒斯特角

   * **你的回答**：$I_1 = \frac{1}{2} I_0$。
   * **结果**：**正确**！
   * **标准公式**：$$I_1 = \frac{1}{2}I_0$$

2. **公式二：线偏振光通过偏振片（检偏器）的马吕斯定律**
   * **你的回答**：$I_2 = I_1 \cos^2\alpha$。
   * **结果**：**正确**！
   * **标准公式**：$$I_2 = I_1 \cos^2\alpha$$
     （其中 $I_1$ 为入射线偏振光的强度，$\alpha$ 为入射光的振动方向与偏振片透振方向的夹角）。
   * **强度链口诀**：**“自然减半，偏振余弦方”**。连续通过多块偏振片时，务必分清第一步（自然光变线偏振，强度减半）和后续各步（线偏振变线偏振，套马吕斯定律）。

3. **公式三：部分偏振光的偏振度 $P$ 定义公式**
   * **你的回答**：$P = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$。
   * **结果**：**正确**！
   * **标准公式**：$$P = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$$
     （其中 $I_{max}$ 和 $I_{min}$ 分别为检偏器旋转一周时透射光强的最大值 and 最小值）。
     * 线偏振光：$I_{min} = 0 \implies P = 1$；
     * 自然光：$I_{max} = I_{min} \implies P = 0$。

4. **公式四：反射起偏的布儒斯特定律**
   * **你的回答**：$\tan i_B = \frac{n_2}{n_1}$，且起偏角与折射角之和为 $90^\circ$。
   * **结果**：**正确**！
   * **标准公式**：$$\tan i_B = \frac{n_2}{n_1}$$
     （其中 $i_B$ 为布儒斯特角或起偏角，折射光和反射光互相垂直，即 $i_B + r = 90^\circ$）。
     * **反射光的偏振态**：当入射角为 $i_B$ 时，反射光为**完全线偏振光**，其光振动方向垂直于入射面（平行于反射界面）。折射光为**部分偏振光**。

## 07. 偏振：双折射、波片、旋光

<!-- Reviewed by JavonLoong -->

### 默写记录
1. **公式一：o 光和 e 光之间的相位差公式**
   * **你的回答**：$\Delta\varphi = \frac{2\pi}{\lambda} |n_o - n_e| d$。
   * **结果**：**正确**！
   * **标准公式**：$$\Delta\varphi = \frac{2\pi}{\lambda_0} |n_o - n_e| d$$
     （其中 $\lambda_0$ 为真空中的光波长，$d$ 为双折射晶体板的厚度，$n_o$ 和 $n_e$ 分别为 o 光和 e 光的折射率）。

2. **公式二：二分之一波片（$\lambda/2$ 波片）引入的相位延迟量及对应最小厚度**
   * **你的回答**：光程差为 $\frac{\lambda}{2}$，相位差为 $\pi$。
   * **结果**：**正确**！
   * **标准公式**：
     * 相位延迟绝对值：$$|\Delta\varphi| = \pi$$
     * 对应晶片最小厚度：$$d = \frac{\lambda_0}{2 |n_o - n_e|}$$

3. **公式三：四分之一波片（$\lambda/4$ 波片）引入的相位延迟量及对应最小厚度**
   * **你的回答**：光程差为 $\frac{\lambda}{4}$，相位差为 $\frac{\pi}{2}$。

#### 题 1：光子位置不确定度（早期量子）
* **核心解析**：
  1. 光子的动量为 $p = \frac{h}{\lambda}$。对波长求导（微分）可得其动量不确定度为：

  2. 题目要求使用简化版估算式 $\Delta x\Delta p_x \sim h$，代入上式：

* **答案纠偏**：**$\frac{\lambda^2}{\Delta \lambda}$**（或 **$\frac{\lambda}{\Delta \lambda/\lambda}$**）。请注意题目指定的估算公式，无需使用带 $\hbar$ 的精确不等式。

#### 题 2：空间相干性消失的临界距离（光的干涉）
* **【核心速记公式】**：
  > [!IMPORTANT]
  > **双缝空间相干性临界条件**：
  > $$L \lambda = b d \quad \implies \quad L = \frac{bd}{\lambda}$$
  > * $L$：光源到双缝的临界距离
  > * $\lambda$：光的波长
  > * $b$：光源的宽度
  > * $d$：双缝的间距
  > 
  > **口诀**：**“距离乘波长，等于宽度乘间距”**。条纹刚消失时，就用这个公式进行计算或变形！

* **【题库同类真题演练】**：
  1. **同类题一（已知宽度、间距、波长，求距离）**：
     * *题目*：发光钨丝宽度 $b = 0.24\text{ mm}$，双缝间距 $d = 0.4\text{ mm}$，波长 $\lambda = 690\text{ nm}$。求条纹刚消失时，钨丝到双缝的距离 $L$。
     * *解法*：直接代入公式 $L = \frac{bd}{\lambda}$：
       $$L = \frac{0.24 \times 10^{-3}\text{ m} \times 0.4 \times 10^{-3}\text{ m}}{690 \times 10^{-9}\text{ m}} \approx 0.139\text{ m} = 140\text{ mm}$$
  2. **同类题二（已知距离、间距、波长，求宽度）**：
     * *题目*：光源缝到双缝距离为 $L = 20\text{ cm}$，双缝间距 $d = 0.5\text{ mm}$，波长 $\lambda = 589.3\text{ nm}$。求条纹刚消失时，光源缝的宽度 $b$。
     * *解法*：公式变形为 $b = \frac{L\lambda}{d}$：
       $$b = \frac{0.2\text{ m} \times 589.3 \times 10^{-9}\text{ m}}{0.5 \times 10^{-3}\text{ m}} \approx 2.36 \times 10^{-4}\text{ m} \approx 0.24\text{ mm}$$

* **核心解析**：
  1. **物理背景**：这是**空间相干性**（宽度极限）的经典结论。宽度为 $b$ 的扩展光源发出的光，在距离为 $L$ 处照射到间距为 $d$ 的双缝上。
  2. **临界条件**：当光源两边缘发出的光在缝处产生的干涉条纹刚好错开半个条纹时，干涉条纹恰好消失。其临界极限角度为：
     $$\Delta \theta = \frac{b}{L} = \frac{\lambda}{d}$$
  3. **求解距离**：解得临界距离 $L = \frac{bd}{\lambda}$。
* **答案纠偏**：**$\frac{bd}{\lambda}$**（或 $L = \frac{bd}{\lambda}$）。你的推导其实完全正确，不用怀疑自己！

  1. **负晶体特性**：负晶体中，$n_e < n_o$，即 $v_e > v_o$。
  2. **子波面作图**：o光子波面是球面，e光子波面是沿光轴方向相切的椭球面。由于 $v_e > v_o$，椭球面除切点外都在球面之外。
  3. **偏振振动方向**：o光的振动方向垂直于主截面，作图上用圆点 $\bullet$ 标注；e光的振动方向平行于主截面，用双向箭头 $\leftrightarrow$ 标注。

#### 题 10：双四分之一波片组合（光的偏振）
* **核心解析**：
  1. 两个 $\lambda/4$ 波片光轴平行放置，其相位延迟直接累加：
     $$\Delta \varphi_{total} = \Delta \varphi_1 + \Delta \varphi_2 = \frac{\pi}{2} + \frac{\pi}{2} = \pi$$
     这等效于一个**二分之一波片（$\lambda/2$波片）**！
  2. 线偏振光以 $45^\circ$ 角入射通过 $P_1$ （$\lambda/4$波片）后，会变成**圆偏振光**，圆偏振光的偏振方向随时间旋转，没有固定的偏振面（填：**无固定方向**或**无**）。
  3. 再通过 $P_2$ 后，因为整体等效于 $\lambda/2$波片，线偏振光通过 $\lambda/2$波片后，仍然是**线偏振光**（只是振动方向旋转了 $90^\circ$）。
* **答案纠偏**：第一空为**无固定方向**；第二空为**线偏振**。

#### 题 11：黑体辐射的温标换算（早期量子）
* **核心解析**：
  1. 维恩位移定律指出，单色辐射出射度最大值波长 $\lambda_m$ 与绝对温度 $T$ 的乘积为常数：
     $$\lambda_m T = b$$
  2. 因此：
     $$\lambda_1 T_1 = \lambda_2 T_2 \implies T_2 = \frac{\lambda_1}{\lambda_2} T_1$$
* **答案纠偏**：**$\frac{\lambda_1}{\lambda_2} T_1$**。

#### 题 12：康普顿散射波长换算（早期量子）
* **核心解析**：
  1. 康普顿散射的波长偏移公式为：
     $$\Delta\lambda = \frac{h}{m_0 c}(1 - \cos\theta)$$
  2. 散射角 $\theta_1 = 45^\circ$ 时的波长漂移为 $\Delta\lambda_1 = \frac{h}{m_0 c}(1 - \cos 45^\circ)$。
  3. 散射角 $\theta_2 = 60^\circ$ 时的波长漂移为 $\Delta\lambda_2 = \frac{h}{m_0 c}(1 - \cos 60^\circ) = \frac{h}{2m_0 c}$。
  4. 两者之比为：
     $$\frac{\Delta\lambda_1}{\Delta\lambda_2} = \frac{1 - \frac{\sqrt{2}}{2}}{\frac{1}{2}} = 2 - \sqrt{2}$$
* **答案纠偏**：**$2 - \sqrt{2}$**。

#### 题 13：氢原子光谱与可见光（原子物理）
* **核心解析**：
  1. **光谱谱线条数**：$n=4$ 激发态跃迁释放光子的可能通道数为：
     $$N = \frac{n(n-1)}{2} = \frac{4 \times 3}{2} = 6 \text{ 条}$$
  2. **可见光短波极限能量**：氢原子的可见光谱属于巴耳末系（Balmer series），跃迁终点为 $n_f = 2$。
     * 可见光范围内的跃迁为 $3 \to 2$ 和 $4 \to 2$。
     * 波长最短对应光子能量最大，即为 $4 \to 2$ 跃迁。
     * 对应能量为：
       $$E = E_4 - E_2 = -0.85\text{ eV} - (-3.40\text{ eV}) = 2.55\text{ eV}$$
       若换算成焦耳：$2.55 \times 1.6 \times 10^{-19}\text{ J} = 4.08 \times 10^{-19}\text{ J}$。
* **答案纠偏**：第一空为 **$6$**；第二空为 **$2.55\text{ eV}$**（或 **$4.08 \times 10^{-19}\text{ J}$**）。

#### 题 14：量子数与轨道角动量（原子物理）
* **核心解析**：
  1. 角量子数 $l$ 的取值受限制：$|m_l| \le l \le n-1$。已知 $n=4, m_l=-3$，因此角量子数唯一可能的值是 $l = 3$。
  2. 自旋磁量子数只能取 $m_s = \pm 1/2$。
  3. 轨道角动量大小公式为：
     $$L = \sqrt{l(l+1)}\hbar$$
     代入 $l=3$：
     $$L = \sqrt{3 \times 4}\hbar = \sqrt{12}\hbar = 2\sqrt{3}\hbar$$
* **答案纠偏**：第一空为 **$3$**；第二空为 **$\pm 1/2$**（或 **$-1/2$**）；第三空为 **$2\sqrt{3}\hbar$**（或 **$\sqrt{12}\hbar$**）。

## 10. 2020 秋期末试卷填空题纠偏与解析

在这次练习中，你对填空题的整体物理图像把握得不错，部分题目（如题3、5、6、7、8、13的第1问、14的第1问）做出了完全正确且优美的推导。对于错题和留空题，下面是详细的纠偏解析，供你复习：

### 1. 题1：不确定性关系估算（光子位置不确定度）
* **你的反馈**：写出了 $\Delta x \ge \frac{\lambda^2}{4\pi\Delta\lambda}$ 但未得分。
* **核心解析**：
  1. 题目指定的简化估算式为 $\Delta x \Delta p_x \sim h$，没有分母 $4\pi$。
  2. 动量为 $p = \frac{h}{\lambda}$，动量不确定度为 $\Delta p_x = h \frac{\Delta \lambda}{\lambda^2}$。
  3. 代入估算式：
     $$\Delta x \sim \frac{h}{\Delta p_x} = \frac{\lambda^2}{\Delta\lambda}$$
* **答案纠偏**：**$\frac{\lambda^2}{\Delta \lambda}$**。

### 2. 题2：双缝干涉中的空间相干性（条纹恰好消失的临界距离）
* **你的反馈**：写出了 $L\lambda = bd$ 但备注“看不懂”。
* **核心解析**：
  1. **临界条件**：当光源两边缘发出的光在缝处产生的干涉条纹刚好错开半个条纹时，条纹恰好消失。其临界极限角度为：
     $$\Delta \theta = \frac{b}{L} = \frac{\lambda}{d}$$
  2. **求解距离**：解得临界距离 $L = \frac{bd}{\lambda}$。
* **答案纠偏**：**$\frac{bd}{\lambda}$**。

### 3. 题4：三粒小珠等厚干涉直径检测
* **你的反馈**：留空。
* **核心解析**：
  1. A在第3条纹上，对应厚度为 $D$。相邻条纹对应的空气膜厚度差为 $\Delta e = \frac{\lambda}{2}$。
  2. B在相邻的第2条纹上，所以其直径为 $D \pm \frac{\lambda}{2}$。C在相邻的第4条纹上，所以其直径为 $D \mp \frac{\lambda}{2}$。
  3. 题目提到“**在小珠 C 上方轻按平晶，条纹变密**”。轻按 C 上方，相当于把平晶在 C 处向下压，厚度减小。如果 C 原本是最小的小珠，那么降低 C 处高度会使平晶倾角变大，条纹变密。这与题意相符！
  4. 因此，C 必定是最小的小珠，而 B 是最大的小珠。
* **答案纠偏**：B的小珠直径为 **$D + \frac{\lambda}{2}$**，C的小珠直径为 **$D - \frac{\lambda}{2}$**。

## 11. 龙哥全方位公式碾压与最新口诀记录 (2026-06-22 记录)

### 错题/知识点纠偏与新口诀

1. **双缝干涉中的空间相干极限**
   - **错误/模糊点**：容易忘记 $L = \frac{bd}{\lambda}$，或者搞错各个字母的对应。
   - **新口诀（龙哥专属）**：
     $$L \lambda = b d \implies \text{“L 拉姆等于东北”}$$
     * 这里的 $b$ 对应 **北 (bei)**，$d$ 对应 **东 (dong)**，$bd$ 连起来就是 **东北 (North-East)**！
     * 做空间相干极限题时，直接用 $L \lambda = bd$，简单好记。

2. **单缝衍射暗纹条件**
   - **错误/模糊点**：容易忘记单缝的暗纹条件公式是 $a \sin\theta = \pm k\lambda$。
   - **新口诀（龙哥专属）**：
     $$ac = \pm k\lambda \implies \text{“ac 等于正负 k”}$$
     * 这里的 $c$ 代表 $\sin\theta$。注意不要和光栅的明纹条件（$d\sin\theta = k\lambda$）搞混。
     * 口诀记住：**“单缝暗纹用 a，光栅明纹用 d”**。

3. **光栅衍射的缺级条件**
   - **错误/模糊点**：公式 $k = \frac{d}{a}m$ 比较难记。
   - **新口诀（龙哥专属）**：
     $$a \cdot k = d \cdot m \implies \text{“ak = dm (爱看动漫 / AK等于DM)”}$$
     * $ak$ 就是“爱看”，$dm$ 就是“动漫”。
     * 这个等式能极快地帮你算缺级！即：$k = \frac{d}{a} m$。

4. **原子物理中的量子数**
   - **错误/模糊点**：容易把磁量子数 $m_l$ 的性质和自旋量子数 $m_s$ 搞混。你曾说：“ms的话，就是它小于我们刚才说的那里面其中一个数，然后可以是正负的，然后包含零”。
   - **正确纠偏**：
     * **角量子数 $l$**：$l < n$，取值为 $0, 1, 2, 3 \dots$，分别对应光谱符号 $s, p, d, f$（**口诀：类比文件格式 PDF，s代表0，p、d、f 分别代表 1、2、3**）。
     * **磁量子数 $m_l$**：它的绝对值小于等于角量子数，即 $|m_l| \le l$，取值可以是正、负、包含零（例如：$l=2$ 时，$m_l$ 可取 $-2, -1, 0, 1, 2$）。**你刚才说的小于、可正负、含零的是 $m_l$，千万不要记成自旋 $m_s$！**
     * **自旋量子数 $m_s$**：它只有两个固定取值，即 **$\pm 1/2$**，不可能为零！

5. **一维定态薛定谔方程**
   - **正确理解**：$-\frac{\hbar^2}{2m} \frac{d^2\psi}{dx^2} + U\psi = E\psi$。
   - **新口诀（龙哥专属）**：
     * “动能项（分母为 $2m$，分子为 $\hbar^2$，乘波函数的二次偏导，前面有个负号）+ 势能项（$U \psi$）= 总能项（$E \psi$，即 Ep / E-psi）”。

6. **无限深方势阱波函数**
   - **正确理解**：$\psi_n(x) = \sqrt{\frac{2}{a}} \sin\frac{n\pi x}{a}$。
   - **新口诀（龙哥专属）**：
     * 归一化波函数的振幅是 **根号下 2 比上阱宽 a**，后面跟着正弦函数 **$\sin(\frac{n\pi x}{a})$**（口诀记为：**cnms/nns** 等，考场上别漏了 $\pi$ 和 $x$）。

7. **氢原子基态能量（名场面修正）**
   - **听写错误**：“鸡蛋容量是13:04” $\implies$ 实际为 **“基态能量是 -13.6 eV”**。
     * $E_1 = -13.6\text{ eV}$，这个常数非常关键，考试直接用！
