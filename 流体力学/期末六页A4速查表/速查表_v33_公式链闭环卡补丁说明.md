# 速查表 v33：公式链闭环卡补丁说明

## 改动目的

v32 已经能按题干关键词定位模型，但仍可能出现“知道是哪类题，却不知道下一行接什么”的问题。v33 在 G1 中加入“公式链闭环卡”，把常见模型压缩成“已知量 -> 中间量 -> 目标量”链路。

- 可压/波：`M,A/A*,p0,T0,M1,theta -> 查表 -> p,T,mdot,p02`
- 边界层：`Re -> delta,Cf -> D`
