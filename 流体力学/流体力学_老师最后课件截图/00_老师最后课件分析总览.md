## 2. 图 01：势流叠加总览

![势流叠加总览](01_势流叠加总览.jpg)

### 课件核心

平面不可压无旋流动：

\[
\nabla^2\varphi=0,\qquad \nabla^2\psi=0
\]

无旋流动：

\[
\vec{\Omega}=\nabla\times \vec V=0
\]

\[
\vec V=\nabla\varphi
\]

二维定常或不可压流函数：

\[
u=\frac{\partial\psi}{\partial y},\qquad
v=-\frac{\partial\psi}{\partial x}
\]

### 必会内容

| 基本流 | 速度势 \(\varphi\) | 流函数 \(\psi\) | 用途 |
|---|---|---|---|
| 均匀流 | \(Ur\cos\theta\) | \(Ur\sin\theta\) | 来流 |
| 点源 | \(\frac{Q}{2\pi}\ln r\) | \(\frac{Q}{2\pi}\theta\) | 流体从一点流出 |
| 点汇 | \(-\frac{Q}{2\pi}\ln r\) | \(-\frac{Q}{2\pi}\theta\) | 流体流向一点 |
| 点涡 | \(\frac{\Gamma}{2\pi}\theta\) | \(-\frac{\Gamma}{2\pi}\ln r\) | 环量、升力 |
| 偶极子 | \(\frac{M\cos\theta}{r}\) | \(-\frac{M\sin\theta}{r}\) | 圆柱绕流 |

### 考法

通常不是让你从零证明拉普拉斯方程，而是：

1. 给基本流组合；
2. 让你写总 \(\varphi\) 或 \(\psi\)；
3. 求速度；
4. 用伯努利方程求压强；
5. 判断驻点、边界、环量或升力。

## 3. 图 02：激波总览

![激波总览](02_激波总览.jpg)

### 课件核心

激波条件：

- 来流超声速；
- 波前后绝热；
- 气流被压缩；
- 压缩前后参数突变；
- 坐标系固结在激波上，属于驻激波理论。

### 三种激波

| 类型 | 什么时候出现 | 计算工具 |
|---|---|---|
| 正激波 | 气流正对压缩面，或一维管内突变 | 正激波关系式 |
| 斜激波 | 超声速气流遇到小偏转压缩角 | 斜激波表、\(\theta-\beta-M\) 关系 |
| 脱体激波 | 偏转角太大，附体斜激波不能成立 | 正斜激波组合，通常定性判断 |

### 激波后变化

| 量 | 变化 |
|---|---|
| \(p,T,\rho\) | 升高 |
| \(V,Ma\) | 降低 |
| \(T_0\) | 不变 |
| \(p_0\) | 下降 |
| 熵 | 增加 |

### 考法

高概率考：

1. 已知 \(Ma_1\)，求正激波后 \(Ma_2,p_2/p_1,T_2/T_1,\rho_2/\rho_1,p_{02}/p_{01}\)；
2. 已知 \(Ma_1\) 和偏转角，查斜激波表求激波角；
3. 判断是斜激波、膨胀波还是脱体激波。

## 4. 图 03：膨胀波与 Prandtl-Meyer 角

![膨胀波](03_膨胀波_Prandtl_Meyer.jpg)

### 课件核心

小扰动下的膨胀和压缩波：

- 小扰动过程是连续等熵的；
- 膨胀加速偏转气流；
- 压缩减速偏转气流。

Prandtl-Meyer 函数：

\[
\nu(M)=
\sqrt{\frac{\gamma+1}{\gamma-1}}
\tan^{-1}\sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)}
-
\tan^{-1}\sqrt{M^2-1}
\]

空气中 \(\gamma=1.4\)：

\[
\nu(M)=
\sqrt6\tan^{-1}\sqrt{\frac{M^2-1}{6}}
-\tan^{-1}\sqrt{M^2-1}
\]

### 做题关系

从 \(Ma_1\) 到 \(Ma_2\)，膨胀角：

\[
\delta=\nu(Ma_2)-\nu(Ma_1)
\]

如果给偏转角 \(\delta\)，则：

\[
\nu(Ma_2)=\nu(Ma_1)+\delta
\]

再反查或计算 \(Ma_2\)。

### 关键判断

| 几何情况 | 现象 |
|---|---|
| 超声速气流被压缩 | 激波 |
| 超声速气流沿凸角扩张 | 膨胀波 |
| 偏转角太大 | 可能出现脱体激波 |

## 5. 图 04：Laval 喷管中的流动状态

![Laval喷管](04_Laval喷管流动状态.jpg)

### 课件核心

几何条件 \(A_e/A_t\) 固定后，随着背压 \(p_b\) 改变，Laval 喷管会出现多种状态。

图中重点是：

- 喉部 \(t\)；
- 出口 \(e\)；
- 临界压力约 \(0.528p_0\)；
- 质量流量可能阻塞；
- 管内正激波、管外斜激波、出口膨胀波。

### 重要概念

| 符号 | 意思 |
|---|---|
| \(p_0\) | 滞止压力 |
| \(p_b\) | 背压，即喷管外部环境压力 |
| \(p_e\) | 喷管出口内侧流体静压 |
| \(A_t\) | 喉部面积 |
| \(A_e\) | 出口面积 |
| \(Ma=1\) | 临界/声速状态 |

### 关键判断

| 背压情况 | 状态 |
|---|---|
| \(p_b\) 很高 | 全管亚声速，未阻塞 |
| 喉部达到 \(Ma=1\) | 阻塞，质量流量最大 |
| 扩张段内出现正激波 | 管内激波 |
| 出口压力与背压不匹配 | 管外斜激波或膨胀波 |
| \(p_e>p_b\) | 欠膨胀，出口外继续膨胀 |
| \(p_e<p_b\) | 过膨胀，出口外压缩/斜激波 |

### 你之前容易混的地方

\[
\frac{p^*}{p_0}=0.528
\]

这只表示**临界状态静压与滞止压之比**，不是说“只要 \(p_b/p_0<0.528\) 就出口一定超声速”。  
是否超声速还要看喷管形状、喉部是否阻塞、出口面积比、是否有激波。

## 6. 图 05：粘性流动总览

![粘性流动总览](05_粘性流动总览_NS_Re_管内外绕流.jpg)

### 课件核心

粘性流动由 \(Re\) 决定状态：

\[
Re=\frac{\rho VL}{\mu}=\frac{VL}{\nu}
\]

其中：

| 符号 | 意思 |
|---|---|
| \(V\) | 特征速度 |
| \(L\) | 特征长度 |
| \(\mu\) | 动力黏度 |
| \(\nu=\mu/\rho\) | 运动黏度 |

### 总框架

| 分支 | 内容 |
|---|---|
| 简单层流 | N-S 方程有解析解，如 H-P 流、Couette 流 |
| 管内流 | 层流可解析，湍流用经验公式和 Moody 图 |
| 外绕流 | 中等 Re 多分离，大 Re 远离物面可视无粘，壁面附近用边界层 |

### 必会公式

层流圆管：

\[
\lambda=\frac{64}{Re}
\]

沿程压损：

\[
\Delta p_f=\lambda\frac{L}{d}\frac{\rho V^2}{2}
\]

修正伯努利方程：

\[
\frac{p_1}{\rho g}+\frac{V_1^2}{2g}+z_1+H_p
=
\frac{p_2}{\rho g}+\frac{V_2^2}{2g}+z_2+h_f+\sum h_\zeta
\]

## 7. 图 06：边界层理论

![边界层理论](06_边界层理论总览.jpg)

### 课件核心

边界层理论用于：

> 高 \(Re\)、无或很小分离的绕流问题。

分两部分：

1. 边界层外场：用 Euler 方程；
2. 边界层内流动：用 Prandtl 边界层方程或 Von Karman 动量积分方程。

### 考试重点

| 方法 | 用途 |
|---|---|
| Blasius 层流边界层相似解 | 平板层流边界层 |
| Von Karman 动量积分方程 | 用假设速度剖面求厚度和摩擦阻力 |
| 层流/湍流经验公式 | 算平板摩擦阻力、边界层厚度 |

### 平板常用公式

层流：

\[
Re_x=\frac{Ux}{\nu}
\]

\[
\delta(x)\approx\frac{5x}{\sqrt{Re_x}}
\]

\[
\bar C_f=\frac{1.328}{\sqrt{Re_L}}
\]

湍流：

\[
\bar C_f\approx\frac{0.074}{Re_L^{1/5}}
\]

考虑转捩：

\[
\bar C_f\approx\frac{0.074}{Re_L^{1/5}}-\frac{1742}{Re_L}
\]

## 8. 图 07：守恒律与连续介质假设

![守恒律](07_守恒律与连续介质假设.jpg)

### 课件核心

流体力学的起点：

1. 连续介质假设；
2. 质量守恒；
3. 动量守恒；
4. 动量矩守恒；
5. 能量守恒。

它们可以写成随体物质量 \(F(t)\)，也可以写成空间变量：

\[
F(x,y,z,t)
\]

### 考试意义

这张图主要服务概念题：

| 问法 | 答法 |
|---|---|
| 为什么可以用场变量描述流体？ | 因为采用连续介质假设 |
| 欧拉描述是什么？ | 在空间固定点研究 \(F(x,y,z,t)\) |
| 拉格朗日描述是什么？ | 跟踪某个流体质点随时间运动 |
| 控制体方法来自哪里？ | 守恒律在空间区域上的积分形式 |

## 9. 图 08：物质模型与核心知识

![物质模型](08_物质模型与核心知识.jpg)

### 课件核心

老师把全课程分成几种物质模型：

| 模型 | 核心知识 |
|---|---|
| 静止流体 | 表面力垂直表面，大小与方向无关，受平衡微分方程约束 |
| 不可压、无粘 | Euler 方程、伯努利方程、势函数/流函数 |
| 可压、无粘 | 马赫数、声速、激波、膨胀波、等熵/非等熵 |
| 不可压、有粘 | Re、层流/湍流、N-S 方程、低 Re/高 Re 近似、管流、边界层、阻力 |

### 这张图的意义

这张图是全课程地图。你复习时不要按“第几章”死记，而应该按模型判断：

1. 静止还是运动？
2. 可压还是不可压？
3. 有粘还是无粘？
4. 是管内流还是外绕流？
5. 是低 \(Re\) 还是高 \(Re\)？

## 11. 按这组课件重排后的复习优先级

### 第一优先级：可压缩流动

必须会：

1. 等熵关系；
2. 正激波关系；
3. 斜激波查表；
4. 膨胀波 Prandtl-Meyer 函数；
5. Laval 喷管背压状态判断。

理由：老师最后课件中可压缩部分给了三张图，且考试指南明确提到气动函数和激波表。

### 第二优先级：粘性流动

必须会：

1. \(Re\) 判断；
2. H-P 圆管流；
3. Couette 流；
4. 管路修正伯努利；
5. 平板边界层层流/湍流公式；
6. 分离和阻力概念。

理由：老师最后课件中粘性流动给了两张总览图，范围很大，但计算题通常落在管流和边界层。

### 第三优先级：势流叠加

必须会：

1. 均匀流、源汇、点涡、偶极子；
2. \(\varphi,\psi\) 与速度关系；
3. 叠加法；
4. 伯努利求压力。

理由：老师最后课件明确列出“典型叠加流动解”，但相比可压缩和粘性流，计算复杂度可能低一些。

### 第四优先级：概念总图

必须会判断：

1. 连续介质假设；
2. 欧拉/拉格朗日；
3. 静止/不可压无粘/可压无粘/不可压有粘；
4. 守恒律对应控制方程。

理由：概念题约 30 分，这些图很可能直接变成判断题。
