# MotionTwin 关键图生成提示词

以下提示词可直接用于 image_gen。每组都提供中文和英文版本。建议生成 16:9 横图，用作 PPT 背景或主视觉。所有图都要求无文字、无水印、无伪 UI 字符，避免后期出现错字。

## 01 真实人与蓝色 XR 影分身并排/重叠训练

### 中文提示词

用途：PPT 主视觉 / 产品概念页 / 技术方案页。

提示词：

一张写实但略带未来科技感的 16:9 横版场景图，室内运动训练空间，一名年轻训练者正在做标准深蹲或挥拍动作，身旁和身体半重叠位置出现一个半透明蓝色 XR 动作影分身。真实人与蓝色影分身姿态相近但有细微偏差，影分身由发光骨架、半透明体积轮廓、浅蓝色运动轨迹线组成。画面体现实时动作对齐训练、动作镜像反馈、沉浸式 XR 指导。背景干净，有柔和空间网格和少量传感器光点，但不要出现任何可读文字、数字、logo、界面标签或水印。构图：真实人略偏左，蓝色 XR 影分身略偏右并与身体局部重叠，右上方保留干净负空间供 PPT 放标题。风格：高质量产品概念渲染，真实摄影质感，蓝色发光科技视觉，清晰人物姿态，专业但不夸张。

负面约束：

不要任何文字、不要乱码、不要品牌标志、不要复杂 UI 面板、不要多人混乱、不要赛博朋克过暗背景、不要人物肢体畸形、不要把影分身画成实体机器人、不要过度卡通化。

### English Prompt

Use case: photorealistic-natural / product concept hero image.
Asset type: 16:9 slide visual for an XR motion-shadow training product.

Prompt:

A photorealistic but slightly futuristic indoor sports training scene. One young trainee is performing a clear squat or racket swing pose. Next to the real person, partly overlapping the body, there is a translucent blue XR motion twin. The XR twin has a glowing skeletal structure, semi-transparent volumetric body outline, and subtle blue motion trails. The real person and the blue twin are almost aligned but show a small pose difference, suggesting real-time motion comparison and coaching. Clean training studio background, soft spatial grid, a few subtle sensor light points. Composition: real person slightly left, blue XR twin slightly right and partially overlapping, with clean negative space in the upper-right area for editable slide text. High-quality product concept render, realistic camera look, crisp body pose, professional blue tech aesthetic.

Avoid:

No text, no numbers, no UI labels, no logos, no watermark, no gibberish characters, no crowded groups, no dark cyberpunk scene, no distorted limbs, do not make the twin a solid robot, no cartoon style.

## 02 动作误差热力图 / 姿态评分视觉

### 中文提示词

用途：问题页 / 核心交互页 / 预期成效页。

提示词：

一张 16:9 横版科技训练分析图，画面中心是一名运动者的半透明人体姿态轮廓，叠加一个蓝色标准动作骨架和一个橙红色偏差骨架。肩、膝、腰、手腕等关键关节附近出现柔和热力图光晕，误差大的部位显示橙红色，误差小的部位显示蓝绿色。画面右侧有抽象的评分仪表和进度条形状，但不能有任何数字、文字、字母或可读 UI 标签。整体表达“动作误差可视化、姿态评分、实时纠错”。背景为干净深灰到浅灰的训练空间或抽象技术背景，避免复杂文字界面。构图清晰，人体和骨架占画面中部，右侧留给后期 PPT 可编辑说明文字。

负面约束：

不要生成任何文字、数字、英文字母、乱码、logo、水印；不要医学恐怖感；不要红色过量导致像受伤警报；不要骨架错位到不可理解；不要复杂不可编辑仪表盘。

### English Prompt

Use case: productivity-visual / scientific-educational concept image.
Asset type: 16:9 slide visual for motion error heatmap and posture scoring.

Prompt:

A clean futuristic training analytics visual in a 16:9 landscape format. In the center, show a semi-transparent human body pose silhouette with two overlaid skeletons: a blue reference motion skeleton and a warm orange-red deviation skeleton. Around key joints such as shoulders, knees, waist, and wrists, show soft heatmap glows: orange-red for larger error areas, blue-green for well-aligned areas. On the right side, include abstract score gauge shapes and progress bar shapes only, with no readable text, no numbers, and no letters. The image should communicate motion error visualization, posture scoring, and real-time correction. Background: clean gray training studio or subtle abstract tech backdrop. Composition: human pose and skeletons centered, right side has clean space for editable PPT text.

Avoid:

No text, no numbers, no letters, no gibberish, no logos, no watermark, no medical horror mood, no excessive red injury-like warning, no confusing broken skeleton, no dense UI dashboard.

## 03 多场景应用矩阵

### 中文提示词

用途：应用场景页 / 预期成效页。

提示词：

一张 16:9 横版产品应用矩阵概念图，画面由 2 行 3 列六个无文字场景缩略格组成，但每个格子之间的边界简洁、不像复杂 UI。六个场景分别表现：体育训练、舞蹈练习、康复训练、校园体育课、工业安全动作训练、居家健身。每个场景中都有一个真实人物和一个半透明蓝色 XR 动作影分身，用同一种蓝色视觉语言连接。每个格子只用场景和动作表达含义，不出现文字、数字、图标标签、logo 或水印。整体风格统一、明亮、现代、专业，适合课程结课 PPT。构图需要干净，单个格子内不要塞太多细节，方便主 agent 在 PPT 中覆盖可编辑标题。

负面约束：

不要任何文字、不要场景标题、不要乱码、不要品牌标志、不要医疗器械恐怖感、不要人物过多、不要风格混杂、不要将蓝色影分身画成六种不同角色。

### English Prompt

Use case: productivity-visual / product application matrix.
Asset type: 16:9 slide visual showing use cases for XR motion twin training.

Prompt:

A 16:9 landscape product application matrix concept image with six clean thumbnail panels arranged in a 2 by 3 grid. Each panel has no text and uses visual scenes only. The six scenes are: sports coaching, dance practice, rehabilitation exercise, school physical education class, industrial safety movement training, and home fitness. In every panel, show one real person and one translucent blue XR motion twin using a consistent blue glowing visual language. Keep each scene simple and readable, with clean panel boundaries that do not look like a dense UI dashboard. Bright modern professional style, coherent lighting and color palette, suitable for a university final presentation.

Avoid:

No text, no captions, no numbers, no letters, no gibberish, no logos, no watermark, no scary medical equipment, no crowded scenes, no mixed art styles, do not make the blue twin look like different characters in each panel.
