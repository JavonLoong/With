课程：智能电子产品创新实践  
主题：MotionTwin - XR 动作影分身训练系统  
定位：非医疗、年轻化、演示感强的智能训练产品  
建议页数：9 页  
汇报节奏：10 分钟汇报 + 5 分钟问答

## 01. 封面：MotionTwin，和自己的动作影分身一起训练

**页面目标**  
用一句话让老师知道产品是什么、面向谁、为什么适合课程展示。

**画面建议**  
左侧是真人做网球挥拍/舞蹈动作，右侧是半透明 XR 影分身重叠在身体旁边；下方放四个场景图标：舞蹈、网球、健身、武术。

**页内文案**

- MotionTwin：XR 动作影分身训练系统
- 面向舞蹈、网球、健身、武术、体能训练等年轻化运动场景
- 用 XR 可视化、可穿戴动捕、讯飞智能体和 3D 打印外设，把“看不见的动作差异”变成可看、可听、可纠正的训练反馈
- 产品边界：训练辅助与兴趣提升，不做医疗诊断、康复评估或疾病治疗

**讲稿提示**  
我们不是做“医疗康复设备”，而是做一个更像运动游戏和训练搭子的产品。用户戴上 PICO 或 Apple Vision Pro，系统把标准动作、自己的实时动作和上一轮动作做成“影分身”，让训练者像对着未来版本的自己练习。

**答辩锚点**  
如果被问“为什么叫 MotionTwin”，回答：Twin 是动作数字孪生，不是复制一个人，而是把动作轨迹、节奏、稳定性做成可对比的 XR 训练对象。

## 02. 背景：年轻人的训练正在从“看视频模仿”走向“实时互动反馈”

**对应五段式：背景**

**画面建议**  
三栏对比：短视频跟练、线下教练、XR/智能硬件训练。用箭头指向“实时、沉浸、可量化”。

**页内文案**

- 运动兴趣更碎片化：舞蹈挑战、网球入门、居家健身、武术/体能训练都在被短视频带火
- 训练方式却仍然依赖“看视频 + 自己感觉”，动作是否标准很难即时判断
- XR 设备、可穿戴传感器和智能体技术已经具备课程级原型条件
- 课程技术可以形成完整闭环：
  - XR/动捕：呈现动作影分身与实时轨迹
  - 讯飞智能体：语音教练、动作复盘、训练计划
  - 可穿戴传感器/BrainCo：采集动作和专注度反馈
  - 混元 3D/拓竹 3D 打印：快速制作传感器外壳和训练道具

**讲稿提示**  
现在很多人会跟着视频学舞蹈、练网球挥拍或者做健身动作，但视频只能告诉你“别人怎么做”，不能告诉你“你错在哪里”。MotionTwin 的背景是把课程里接触到的 XR、智能体、可穿戴和 3D 打印串成一个可演示的训练产品。

**答辩锚点**  
市场逻辑不强调医疗刚需，而强调兴趣运动、校园社团、健身房体验课、运动品牌快闪活动等轻量场景。

## 03. 问题：动作训练的痛点不是“没有教程”，而是缺少即时纠错

**对应五段式：问题**

**画面建议**  
做一个“训练黑箱”示意：用户输入努力训练，输出结果不稳定；旁边列出三个黑箱原因。

**页内文案**

- 痛点 1：动作差异不可见  
  角度、发力顺序、重心转移、节奏延迟很难只靠肉眼感知
- 痛点 2：反馈不及时  
  录视频回看太慢，线下教练又成本高、时间不灵活
- 痛点 3：训练不够有趣  
  很多跟练 App 只给分数，缺少游戏化挑战和陪伴感
- 痛点 4：硬件体验割裂  
  XR、手环、传感器、道具常常各玩各的，缺少一个课程原型级的整合方案

**讲稿提示**  
我们把问题定义为：训练者不是缺教程，而是缺一个“实时告诉我身体哪里和标准动作不一样”的系统。因此 MotionTwin 的重点不是泛泛地说 AI 赋能，而是把动作差异变成 XR 中可以观察、可以比较、可以被语音提示的反馈。

**答辩锚点**  
如果被问“为什么不用手机摄像头就够了”，回答：手机视觉适合低成本入门，但 XR 叠加显示和可穿戴传感器能解决遮挡、视角单一、身体局部运动不可见的问题，演示感也更强。

## 04. 产品设想：一个可进入校园和社团的 XR 训练搭子

**对应五段式：技术方案概览**

**画面建议**  
展示典型使用流程：选择课程 -> 戴上传感器 -> 进入 XR 场景 -> 跟随影分身 -> 语音纠错 -> 生成复盘卡。

**页内文案**

- 核心体验：用户看到三个动作层
  - 标准影分身：教练/模板动作
  - 实时影分身：自己的当前动作
  - 回放影分身：上一轮训练动作
- 适配场景
  - 舞蹈：节奏卡点、肢体幅度、左右对称
  - 网球：引拍、挥拍轨迹、击球点、随挥完成度
  - 健身：深蹲角度、核心稳定、动作节奏
  - 武术/体能：步法、重心、爆发节奏、连续动作流畅度
- 产品风格
  - 非医疗：不输出诊断结论
  - 年轻化：挑战赛、好友榜、动作贴纸、训练高光片段
  - 演示感强：现场 30 秒即可看见影分身叠加和语音反馈

**讲稿提示**  
MotionTwin 最核心的视觉是“三个自己”：标准动作、实时动作、上一轮动作。它不是把训练做成冷冰冰的数据表，而是把动作差距做成你眼前的影分身。

**答辩锚点**  
MVP 可以只选一个场景做深，例如“网球挥拍”或“舞蹈 8 拍跟练”。答辩时强调系统可扩展，但原型聚焦一个动作闭环。

## 05. 技术架构：四类课程技术组成一个训练闭环

**对应五段式：技术方案**

**画面建议**  
中间放 MotionTwin 引擎，四周环绕：XR/动捕、讯飞智能体、可穿戴/BrainCo、混元 3D + 3D 打印。

**页内文案**

1. XR 与动捕层
   - PICO/Apple Vision Pro 展示标准动作骨架、实时骨架和轨迹线
   - 视觉骨架识别 + IMU 传感器融合，提升遮挡场景下的稳定性
2. 可穿戴采集层
   - 手腕、脚踝、腰部 IMU 采集加速度、角速度和姿态
   - 可选压力鞋垫采集重心转移
   - 可选 BrainCo 头环采集专注度趋势，用于训练状态提醒
3. 讯飞智能体层
   - 语音交互：“帮我看一下挥拍哪里不对”
   - 训练提示：“左脚落地晚了 0.2 秒，下一轮先放慢节奏”
   - 复盘总结：生成本轮动作得分、主要问题和下一轮目标
4. 3D 建模与打印层
   - 混元 3D 生成传感器外壳、腕带卡扣、球拍夹具、武术训练标记物概念模型
   - 拓竹 3D 打印快速验证佩戴舒适度和固定稳定性

**讲稿提示**  
这页要强调“闭环”：采集动作 -> XR 显示差异 -> 智能体解释问题 -> 用户重新训练 -> 复盘生成下一轮目标。每个课程技术都有明确位置，不是为了堆概念。

**答辩锚点**  
如果被问“BrainCo 必须吗”，回答：不是必须项。基础版用 IMU 和 XR 就能完成动作训练；BrainCo 是增强模块，用来判断专注度下降或训练疲劳时提醒用户休息。

## 06. 关键实现：动作差异如何被计算和呈现

**对应五段式：技术方案细化**

**画面建议**  
左侧是传感器数据流，右侧是 XR 中的红黄绿误差可视化：绿色表示达标，黄色表示轻微偏差，红色表示需要纠正。

**页内文案**

- 动作模板建立
  - 录入教练动作或优质示范视频
  - 提取关节点序列：肩、肘、腕、髋、膝、踝
  - 生成节奏点：起势、发力、峰值、收势
- 实时动作采集
  - XR 摄像头/空间计算获取人体骨架
  - IMU 补充手腕、脚踝、腰部姿态，降低遮挡影响
- 动作对齐与评分
  - 时间对齐：把用户动作与标准动作按关键帧匹配
  - 空间对齐：以腰部/髋部为基准统一身体坐标
  - 评分维度：角度误差、节奏误差、轨迹平滑度、重心稳定性
- 反馈呈现
  - XR 中显示轨迹偏差线和关键关节高亮
  - 讯飞智能体把数据翻译成一句可执行建议

**示例反馈文案**

> “你的右腕轨迹比标准动作低 12 厘米，发力峰值提前 0.18 秒。下一轮先降低速度，注意右肩带动手腕完成随挥。”

**讲稿提示**  
这里要讲清楚“AI”不是一个黑盒。我们先把动作拆成关节点、轨迹和节奏，再把偏差转成用户听得懂的训练语言。老师问实现细节时，就围绕时间对齐、空间对齐、评分维度来答。

**答辩锚点**  
若原型难以实现完整人体动捕，可先用 3 个 IMU 传感器完成网球挥拍/健身深蹲的局部动作评估，再逐步扩展。

## 07. 现场演示设计：30 秒看到影分身，2 分钟完成一次训练闭环

**对应五段式：技术方案 + 演示感**

**画面建议**  
用时间轴表现演示流程，旁边放“可现场展示/可视频展示/可模型展示”标签。

**页内文案**

- 演示动作建议：网球正手挥拍或舞蹈 8 拍
- 0:00-0:20 选择训练模式
  - 语音：“MotionTwin，开始网球正手入门训练”
  - 讯飞智能体确认训练目标和安全提醒
- 0:20-0:50 佩戴传感器
  - 手腕 IMU + 腰部 IMU + 可选脚踝 IMU
  - 展示 3D 打印外壳和球拍夹具
- 0:50-1:30 XR 跟练
  - 标准影分身在前方做动作
  - 用户实时影分身叠加，偏差用红黄绿轨迹显示
- 1:30-2:00 智能反馈
  - 智能体给出一句主问题和一个下一轮目标
  - 自动生成训练复盘卡：本轮得分、最大偏差、改进建议

**讲稿提示**  
汇报时可以明确说：真正答辩展示不需要把所有场景都做完，只要把“选择动作、佩戴传感器、XR 影分身、智能体反馈、复盘卡”这条链路跑通，就能证明产品设想和课程技术结合是可落地的。

**答辩锚点**  
如果现场没有 XR 设备，可用录屏或手机拍摄视角模拟 XR 界面；3D 打印外壳和传感器夹具作为实体展品增强可信度。

## 08. 预期成效：让训练反馈更即时、更可视、更愿意坚持

**对应五段式：预期成效**

**画面建议**  
用四个指标卡：即时反馈、动作提升、训练坚持、课程原型完整度。右侧放一张训练复盘卡样例。

**页内文案**

- 对用户
  - 更快知道自己错在哪里：从“感觉不对”变成“右腕轨迹偏低”
  - 更容易坚持：影分身挑战、训练打卡和好友榜提升趣味性
  - 更适合入门者：语音提示只给一个下一步目标，避免信息过载
- 对训练场景
  - 校园社团：舞蹈社、网球社、武术社可做体验活动
  - 健身房/运动品牌：适合做互动快闪和新人教学
  - 家庭训练：用轻量设备完成基础动作纠错
- 对课程成果
  - 覆盖 XR/动捕、讯飞智能体、可穿戴、3D 建模与打印
  - 有虚拟界面、有实体硬件、有可演示流程
  - 非医疗边界清晰，降低伦理和合规风险

**建议量化指标**

- 反馈延迟：目标小于 2 秒给出主要动作偏差
- 动作评分：角度误差、节奏误差、轨迹平滑度三项组成 100 分
- 用户体验：完成一次训练闭环小于 3 分钟
- 原型完成度：至少完成 1 个动作模板、1 个可穿戴外壳、1 条智能体反馈流程

**讲稿提示**  
预期成效不要说成“改变世界”，而是说“让入门训练反馈变得即时、可视、可坚持”。这更像一个课程项目能答辩的尺度。

**答辩锚点**  
如果被问“如何验证有效”，回答：可以做 A/B 测试，一组只看视频跟练，一组使用 MotionTwin，比较动作评分提升、完成率和主观兴趣评分。

## 09. 课程收获与问答准备：从技术体验到产品闭环

**对应五段式：课程收获**

**画面建议**  
左侧是课程技术拼图，右侧是 MotionTwin 产品闭环；底部放 5 个高频答辩问题。

**页内文案**

- 课程收获 1：理解智能电子产品不只是算法，还包括硬件、交互、场景和用户体验
- 课程收获 2：XR 的价值不只是“炫酷显示”，而是把抽象数据变成空间中的可观察反馈
- 课程收获 3：智能体要服务具体任务，MotionTwin 中的智能体负责“把动作数据翻译成训练建议”
- 课程收获 4：3D 打印让电子产品原型更完整，可以快速验证佩戴方式、传感器固定和道具形态
- 课程收获 5：人机共融不是让机器替代教练，而是让机器成为训练过程中的实时陪伴和反馈接口

**5 分钟问答备答**

- Q1：这是不是医疗康复产品？  
  A：不是。MotionTwin 定位为运动训练和兴趣提升，只提供动作训练反馈，不做诊断、治疗或康复结论。
- Q2：为什么一定要 XR？  
  A：XR 能把标准动作和用户动作叠加到同一空间，用户不用在屏幕和身体之间切换注意力，现场演示效果也更直观。
- Q3：动作识别不准怎么办？  
  A：原型阶段聚焦单个动作，并用 IMU 做局部姿态补充；评分不追求医学精度，而追求训练场景中可理解、可改进的反馈。
- Q4：讯飞智能体具体做什么？  
  A：负责语音控制、动作复盘、个性化训练建议，把“角度误差/节奏误差”转换成自然语言提示。
- Q5：混元 3D 和 3D 打印如何落地？  
  A：用混元 3D 快速生成腕带外壳、传感器卡扣、球拍夹具或训练标记物，再用拓竹打印，验证佩戴舒适度和固定稳定性。

**结束语**

MotionTwin 的价值不是把所有运动都自动教会，而是把“动作差一点点”的瞬间变成用户看得见、听得懂、愿意继续练的反馈。
