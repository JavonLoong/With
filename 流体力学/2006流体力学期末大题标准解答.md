## 🚰 【第一题】 粗糙圆管出流与层流/湍流判定

### 1. 原题重现与几何参数提取
* **原题**：一水池有 $20^\circ\text{C}$ 的水 $1\text{ m}^3$，其底部接一 $\epsilon$ 约为 $0.0012$ 的粗糙圆管（见右图）。求此时的出口流量 $Q\text{ (m}^3\text{/h)}$。如果流体为 SAE 10W30 号油，问圆管出口为湍流还是层流？（提示：本题若需迭代，初始值 $Re_D = 100000$，迭代步数 $\le 3$）
* **图纸几何参数**：
  * 水池水深（液面至池底）：$H_1 = 1\text{ m}$
  * 圆管长度（垂直向下）：$L = 80\text{ cm} = 0.8\text{ m}$
  * 圆管内径：$D = 4\text{ cm} = 0.04\text{ m}$
  * 总驱动水头（从自由液面到出口）：$H = H_1 + L = 1.8\text{ m}$

### 2. 物理分析与控制方程
以出口截面为基准面，对自由液面与出口截面列伯努利方程，总驱动水头 $H$ 平衡出口动能与管路水头损失：
$$H = \frac{v^2}{2g} + h_f + h_{\text{local}}$$
其中沿程阻力损失 $h_f = f \frac{L}{D} \frac{v^2}{2g}$，局部损失 $h_{\text{local}}$：
* **方法一（工程标准法：考虑局部损失）**：考虑进口突缩局部阻力损失（取 $K_{\text{in}} = 0.5$），则 $h_{\text{local}} = 0.5 \frac{v^2}{2g}$。控制方程为：
  $$H = \left( 1.5 + f \frac{L}{D} \right) \frac{v^2}{2g} \implies 1.8 = (1.5 + 20f)\frac{v^2}{2g}$$
* **方法二（简化计算法：忽略局部损失）**：仅考虑沿程阻力损失与出口动能（即控制方程为 $H = (1.0 + 20f)\frac{v^2}{2g}$）或完全忽略局部损失与出口动能（即控制方程为 $H = h_f = 20f\frac{v^2}{2g}$）。

### 3. 水流出口流量 $Q$ 的迭代计算（水 $20^\circ\text{C}$：$\nu = 1.005 \times 10^{-6}\text{ m}^2/\text{s}$，$g = 9.81\text{ m/s}^2$）

#### 情形 A：若给定的 $\epsilon$ 为相对粗糙度 $\epsilon/D = 0.0012$
* **方法一（考虑局部损失：控制方程 $1.8 = (1.5 + 20f)\frac{v^2}{2g}$）**：
  * **第 1 步**：以 $Re^{(0)} = 100000$ 为初值。由 Colebrook 方程解得摩擦因子 $f^{(0)} = 0.02283$。
    代入控制方程求流速 $v^{(1)}$：
    $$v^{(1)} = \sqrt{\frac{2 \times 9.81 \times 1.8}{1.5 + 20 \times 0.02283}} \approx 4.2486\text{ m/s}$$
    更新雷诺数：$Re^{(1)} = \frac{v^{(1)}D}{\nu} = \frac{4.2486 \times 0.04}{1.005 \times 10^{-6}} \approx 169097$。
    此时流量：$Q^{(1)} = v^{(1)} \frac{\pi}{4}D^2 \times 3600 \approx 19.22\text{ m}^3\text{/h}$。
  * **第 2 步**：以 $Re^{(1)} = 169097$。解得 $f^{(1)} = 0.02198$。
    代入方程求流速 $v^{(2)}$：
    $$v^{(2)} = \sqrt{\frac{2 \times 9.81 \times 1.8}{1.5 + 20 \times 0.02198}} \approx 4.2670\text{ m/s}$$
    更新雷诺数：$Re^{(2)} \approx 169830$。
    此时流量：$Q^{(2)} \approx 19.30\text{ m}^3\text{/h}$。
  * **第 3 步**：以 $Re^{(2)} = 169830$。解得 $f^{(2)} = 0.02198$（已收敛）。
    流速收敛于 **$4.267\text{ m/s}$**，出口流量收敛于 **$Q = 19.30\text{ m}^3\text{/h}$**。
* **方法二（忽略局部损失与出口动能：控制方程 $1.8 = 20f\frac{v^2}{2g}$）**：
  * 初始：$Re^{(0)} = 100000 \implies f^{(0)} = 0.02283 \implies v^{(1)} = 8.7953\text{ m/s} \implies Re^{(1)} = 350061$。
  * 步2：$Re^{(1)} = 350061 \implies f^{(1)} = 0.02128 \implies v^{(2)} = 9.1098\text{ m/s} \implies Re^{(2)} = 362578$。
  * 步3：$Re^{(2)} = 362578 \implies f^{(2)} = 0.02125 \implies v^{(3)} = 9.1150\text{ m/s} \implies Re^{(3)} = 362784$。
    流速收敛于 **$9.115\text{ m/s}$**，出口流量收敛于 **$Q = 41.24\text{ m}^3\text{/h}$**。

#### 情形 B：若给定的 $\epsilon$ 为绝对粗糙度 $\epsilon = 0.0012\text{ m}$，相对粗糙度 $\epsilon/D = 0.03$
* **方法一（考虑局部损失：控制方程 $1.8 = (1.5 + 20f)\frac{v^2}{2g}$）**：
  * **第 1 步**：$Re^{(0)} = 100000 \implies f^{(0)} = 0.05748 \implies v^{(1)} = 3.6509\text{ m/s} \implies Re^{(1)} = 145308 \implies Q^{(1)} = 16.52\text{ m}^3\text{/h}$。
  * **第 2 步**：$Re^{(1)} = 145308 \implies f^{(1)} = 0.05738 \implies v^{(2)} = 3.6522\text{ m/s} \implies Re^{(2)} = 145360 \implies Q^{(2)} \approx 16.52\text{ m}^3\text{/h}$。
  * **第 3 步**：以 $Re^{(2)} = 145360 \implies f^{(2)} = 0.05738$（已收敛）。
    流速收敛于 **$3.652\text{ m/s}$**，出口流量收敛于 **$Q = 16.52\text{ m}^3\text{/h}$**。
* **方法二（忽略局部损失与出口动能：控制方程 $1.8 = 20f\frac{v^2}{2g}$）**：
  * 经过 3 步迭代后，流速收敛于 **$5.551\text{ m/s}$**，出口流量收敛于 **$Q = 25.11\text{ m}^3\text{/h}$**。

### 4. SAE 10W30 号油的流态判定
* **物性参数**：$20^\circ\text{C}$ 时，SAE 10W30 号油的动力粘度 $\mu \approx 0.17\text{ Pa}\cdot\text{s}$，密度 $\rho \approx 880\text{ kg/m}^3$，运动粘度 $\nu = \mu/\rho \approx 1.93 \times 10^{-4}\text{ m}^2/\text{s}$。
* **层流控制方程**（若为层流，阻力系数 $f = 64/Re$，沿程损失 $h_f = \frac{32 \nu L v}{g D^2}$）：
  * **考虑局部损失时**：
    $$\frac{1.5}{2g} v^2 + \frac{32 \nu L}{g D^2} v - H = 0 \implies 0.07645 v^2 + 0.31508 v - 1.8 = 0 \implies v \approx 3.211\text{ m/s}$$
    计算雷诺数：$$Re = \frac{v D}{\nu} = \frac{3.211 \times 0.04}{1.93 \times 10^{-4}} \approx \mathbf{665.0}$$
  * **忽略局部损失时**：
    $$v = \frac{H g D^2}{32 \nu L} = \frac{1.8 \times 9.81 \times (0.04)^2}{32 \times 1.93 \times 10^{-4} \times 0.8} \approx 5.713\text{ m/s}$$
    计算雷诺数：$$Re = \frac{v D}{\nu} = \frac{5.713 \times 0.04}{1.93 \times 10^{-4}} \approx \mathbf{1182.9}$$
* **结论**：无论是否考虑局部损失，其雷诺数均远小于临界雷诺数 $2300$。因此圆管出口流动为**层流（Laminar Flow）**。

## 🎈 【第二题】 气球在风中的系留角度分析

### 1. 原题重现
一充满氦气的气球由一细线栓于地面，细线重力与阻力忽略。环境空气为 $20^\circ\text{C}$ 和 $1\text{ atm}$ ($101.3\text{ kPa}$)。气球材料自重（不含氦气）为 $0.2\text{ N}$。气球内氦气压力为 $120\text{ kPa}$，直径 $D = 50\text{ cm}$。求风速分别为 (a) $4\text{ m/s}$ 和 (b) $24\text{ m/s}$ 时，系线与垂直方向的夹角 $\theta$。

### 2. 受力分析与控制方程
气球静止平衡时满足：
* **水平平衡**：$F_D = T \sin\theta$
* **垂直平衡**：$F_y = F_B - W_{\text{He}} - W_{\text{mat}} = T \cos\theta$
* **夹角公式**：$$\tan\theta = \frac{F_D}{F_y} = \frac{F_D}{F_B - W_{\text{He}} - W_{\text{mat}}}$$

### 3. 静力学计算 ($T = 20^\circ\text{C} = 293.15\text{ K}$)
* **空气与氦气密度**：
  $$\rho_{\text{air}} = \frac{p_{\text{air}}}{R_{\text{air}}T} = \frac{101300}{287 \times 293.15} \approx 1.204\text{ kg/m}^3, \quad \rho_{\text{He}} = \frac{p_{\text{He}}}{R_{\text{He}}T} = \frac{120000}{2077 \times 293.15} \approx 0.197\text{ kg/m}^3$$
* **气球体积与投影面积**（$D = 0.5\text{ m}$）：
  $$V = \frac{\pi}{6}D^3 = 0.06545\text{ m}^3, \quad A_p = \frac{\pi}{4}D^2 = 0.1963\text{ m}^2$$
* **垂直合力 $F_y$**：
  * 浮力：$F_B = \rho_{\text{air}}gV = 1.204 \times 9.81 \times 0.06545 \approx 0.773\text{ N}$
  * 氦气自重：$W_{\text{He}} = \rho_{\text{He}}gV = 0.197 \times 9.81 \times 0.06545 \approx 0.126\text{ N}$
  * 垂直净拉力：$F_y = F_B - W_{\text{He}} - W_{\text{mat}} = 0.773 - 0.126 - 0.2 = \mathbf{0.447\text{ N}}$

### 4. 风速工况计算 ($\mu_{\text{air}} = 1.81 \times 10^{-5}\text{ Pa}\cdot\text{s}$)
* **工况 (a)：风速 $U = 4\text{ m/s}$**
  * 雷诺数：$Re_D = \frac{\rho_{\text{air}}UD}{\mu_{\text{air}}} = \frac{1.204 \times 4 \times 0.5}{1.81 \times 10^{-5}} \approx 1.33 \times 10^5$
  * 查球体阻力系数曲线得 $C_D \approx \mathbf{0.47}$（处于亚临界区）。
  * 阻力：$F_D = C_D \frac{1}{2}\rho_{\text{air}}U^2 A_p = 0.47 \times 0.5 \times 1.204 \times 4^2 \times 0.1963 \approx \mathbf{0.889\text{ N}}$
  * 系留角：$\tan\theta = \frac{0.889}{0.447} \approx 1.989 \implies \theta \approx \mathbf{63.3^\circ}$
* **工况 (b)：风速 $U = 24\text{ m/s}$**
  * 雷诺数：$Re_D = \frac{\rho_{\text{air}}UD}{\mu_{\text{air}}} = \frac{1.204 \times 24 \times 0.5}{1.81 \times 10^{-5}} \approx 8.0 \times 10^5$
  * 由于 $Re_D$ 超过临界雷诺数（$\approx 3 \times 10^5$），发生**阻力危机**（边界层由层流转捩为湍流，分离点后移，阻力系数剧降），查曲线得 $C_D \approx \mathbf{0.20}$（或 $0.15 \sim 0.20$ 均可）。
  * 阻力：$F_D = C_D \frac{1}{2}\rho_{\text{air}}U^2 A_p = 0.20 \times 0.5 \times 1.204 \times 24^2 \times 0.1963 \approx \mathbf{13.62\text{ N}}$
  * 系留角：$\tan\theta = \frac{13.62}{0.447} \approx 30.47 \implies \theta \approx \mathbf{88.1^\circ}$

## 🌀 【第三题】 势流理论：水流绕圆柱流动分析

### 1. 原题重现
考虑 $20^\circ\text{C}$ 的水以 $5\text{ m/s}$ 的速度流过直径 $1.2\text{ m}$ 的圆柱。远处来流静压为 $150\text{ kPa}$。应用无粘理论，求：
1. 模拟这一流动所需的偶极子强度。
2. 角度 $\theta$ 分别为 (a) $180^\circ$、 (b) $135^\circ$、和 (c) $90^\circ$ 时圆柱表面的压力。
3. 若该圆柱有环量 $\Gamma$，求驻点位于 $\theta = 35^\circ$ 和 $145^\circ$ 处所需的环量 $\Gamma$ 大小。

### 2. 详细步骤解答

* **第一问：偶极子强度计算**（$U_\infty = 5\text{ m/s}$，圆柱半径 $R = 0.6\text{ m}$）
  * **定义一（国外教材标准，强度 $\mu = U_\infty R^2$）**：
    $$\mu = 5 \times (0.6)^2 = \mathbf{1.80\text{ m}^3/\text{s}}$$
  * **定义二（国内教材标准，强度 $\lambda = 2\pi U_\infty R^2$）**：
    $$\lambda = 2\pi \times 5 \times (0.6)^2 = 3.6\pi \approx \mathbf{11.31\text{ m}^3/\text{s}}$$

* **第二问：圆柱表面静压计算**（取水密度 $\rho \approx 1000\text{ kg/m}^3$）
  * 无粘圆柱表面切向流速为 $V_\theta = -2 U_\infty \sin\theta = -10 \sin\theta$。
  * 根据伯努利方程，圆柱表面静压 $p(\theta)$ 满足：
    $$p(\theta) = p_\infty + \frac{1}{2}\rho \left(U_\infty^2 - V_\theta^2\right) = p_\infty + \frac{1}{2}\rho U_\infty^2 \left(1 - 4\sin^2\theta\right)$$
    代入来流静压 $p_\infty = 150\text{ kPa}$ 和无粘动压 $\frac{1}{2}\rho U_\infty^2 = 12.5\text{ kPa}$：
    * **(a) $\theta = 180^\circ$** ($\sin^2\theta = 0$)：
      $$p = 150 + 12.5 \times (1 - 0) = \mathbf{162.5\text{ kPa}}$$
    * **(b) $\theta = 135^\circ$** ($\sin^2\theta = 0.5$)：
      $$p = 150 + 12.5 \times (1 - 2) = \mathbf{137.5\text{ kPa}}$$
    * **(c) $\theta = 90^\circ$** ($\sin^2\theta = 1$)：
      $$p = 150 + 12.5 \times (1 - 4) = \mathbf{112.5\text{ kPa}}$$
    *(注：若水密度取 $998.2\text{ kg/m}^3$，则三处压力值分别为 $162.48\text{ kPa}$, $137.52\text{ kPa}$, $112.57\text{ kPa}$)*

* **第三问：驻点位于 $\theta = 35^\circ$ 和 $145^\circ$ 时所需的环量 $\Gamma$**
  * 带环量的圆柱表面切向速度公式为 $V_\theta = -2 U_\infty \sin\theta - \frac{\Gamma}{2\pi R}$。
  * 驻点处 $V_\theta = 0 \implies \Gamma = -4\pi R U_\infty \sin\theta$。
  * 由于两个驻点分别在 $\theta = 35^\circ$ 和 $145^\circ$（两者 $\sin\theta = \sin 35^\circ \approx 0.5736$ 相同，满足对称性），代入数据：
    $$\Gamma = -4\pi \times 0.6 \times 5 \times \sin 35^\circ \approx \mathbf{-21.62\text{ m}^2/\text{s}}$$
  * 环量大小为 **$21.62\text{ m}^2/\text{s}$**（负号代表顺时针旋转）。

## 🚀 【第四题】 Laval 喷管与正激波判定

### 1. 原题重现与几何参数提取
* **原题**：空气流过一连接两大型气源的 Laval 喷管，连接喉部和下游气源的水银测压计示数差 $h = 15\text{ cm}$，左侧低（如右图）。估算下游气源压力。喷管中有正激波吗？如果有，它是在喷管出口还是出口上游一些？如果该喷管精确地运行于超音速的设计条件，水银柱高应为多少？
* **图纸滞止参数与几何尺寸**：
  * 上游滞止压力：$p_0 = 300\text{ kPa}$
  * 上游滞止温度：$T_0 = 100^\circ\text{C}$（在压力比与测压计高度计算中不影响结果）
  * 喉部面积：$A_t = 10\text{ cm}^2$
  * 出口面积：$A_e = 30\text{ cm}^2$
  * 出口与喉部面积比：$\frac{A_e}{A_t} = 3.0$

### 2. 详细解题步骤

* **第一问：估算下游气源压力 $p_b$**
  1. 假设喷管喉部达到阻塞状态（$Ma_t = 1$），则喉部静压等于临界静压 $p^*$：
     $$p_t = p^* = 0.5283 \times p_0 = 0.5283 \times 300\text{ kPa} = \mathbf{158.48\text{ kPa}}$$
  2. 计算水银柱压差 $\Delta p$（水银密度 $\rho_{\text{Hg}} = 13600\text{ kg/m}^3$，$g = 9.81\text{ m/s}^2$）：
     $$\Delta p = \rho_{\text{Hg}} g h = 13600 \times 9.81 \times 0.15 \text{ Pa} \approx \mathbf{20.01\text{ kPa}}$$
  3. 反推背压 $p_b$：
     由于测压计左侧（喉部端）水银面较低，说明喉部压力大于下游背压（$p_t > p_b$）：
     $$p_b = p_t - \Delta p = 158.48 - 20.01 = \mathbf{138.47\text{ kPa}}$$

* **第二问：正激波判定与定位**
  1. 面积比 $\frac{A_e}{A_t} = 3.0$，代入等熵面积-马赫数公式求出口对应的等熵马赫数：
     $$\frac{A_e}{A_t} = \frac{1}{Ma_e}\left( \frac{5 + Ma_e^2}{6} \right)^3 = 3.0 \implies Ma_{e1} \approx 0.1974 \text{ (等熵亚声速)}, \quad Ma_{e2} \approx 2.6374 \text{ (等熵超声速)}$$
  2. 计算喷管出口可能处于的三个临界背压：
     * **第一临界背压 $p_{b1}$**（喉部刚好达到声速，渐扩段内全为亚声速等熵膨胀）：
       $$p_{b1} = p_0 (1 + 0.2 \times Ma_{e1}^2)^{-3.5} = 300 \times (1 + 0.2 \times 0.1974^2)^{-3.5} \approx \mathbf{291.95\text{ kPa}}$$
       *(自洽校验：实际背压 $p_b = 138.47\text{ kPa} < p_{b1} = 291.95\text{ kPa}$，说明喉部必然阻塞，上述 $Ma_t=1$ 假设完全正确)*
     * **第三临界背压 $p_{b3}$**（超声速设计出口压力）：
       $$p_{b3} = p_0 (1 + 0.2 \times Ma_{e2}^2)^{-3.5} = 300 \times (1 + 0.2 \times 2.6374^2)^{-3.5} \approx \mathbf{14.19\text{ kPa}}$$
     * **第二临界背压 $p_{b2}$**（正激波恰好位于出口截面时，激波后的静压）：
       由正激波前后压力关系（其中 $\gamma = 1.4$, 波前 $Ma = Ma_{e2} \approx 2.6374$）：
       $$p_{b2} = p_{b3} \left[ 1 + \frac{2\gamma}{\gamma+1}(Ma_{e2}^2 - 1) \right] = 14.19 \times \left[ 1 + 1.1667 \times (2.6374^2 - 1) \right] \approx \mathbf{112.79\text{ kPa}}$$
  3. **激波判定与定位**：
     * 由于实际背压满足：$$112.79\text{ kPa} < 138.47\text{ kPa} < 291.95\text{ kPa} \quad (\text{即 } p_{b2} < p_b < p_{b1})$$
     * **结论**：**喷管内部存在正激波**。
     * **位置**：由于背压 $p_b > p_{b2}$，下游高压会将正激波往喷管内部“推”，因此正激波位于**出口上游一些**（即渐扩段内部）。

* **第三问：精确超音速设计条件下的水银柱高度**
  1. 当喷管精确运行于超音速设计工况时，出口压力等于第三临界背压：$$p_b = p_{b3} = \mathbf{14.19\text{ kPa}}$$
  2. 此时喉部依然保持临界阻塞压力：$$p_t = p^* = \mathbf{158.48\text{ kPa}}$$
  3. 喉部与下游大气的压差为：$$\Delta p' = p_t - p_b = 158.48 - 14.19 = \mathbf{144.29\text{ kPa}} = 144290\text{ Pa}$$
  4. 设计水银柱高度差为：$$h' = \frac{\Delta p'}{\rho_{\text{Hg}} g} = \frac{144290}{13600 \times 9.81} \approx \mathbf{1.082\text{ m}} = \mathbf{108.2\text{ cm}}$$
