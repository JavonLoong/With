## 1. 双缝干涉条纹间距公式

*   **你的原声口诀：** *“等于大D拉姆比小d，大D拉姆比上小d。拉拉姆像一个人、进入的入。”*
*   **公式修正与精确表达：**
    $$\Delta x = \frac{D}{d} \lambda$$
    *   **$\lambda$（希腊字母 Lambda）：** 你提到的“拉拉姆”或“像入字的东西”是波长 $\lambda$。
    *   **$d$：** 双缝之间的距离（缝间距）。
    *   **$D$：** 双缝到屏幕的距离。
    *   **$\Delta x$：** 相邻明条纹（或暗条纹）中心之间的距离。

> [!TIP]
> 填空题中常考**条纹间距的变化**：若把整个干涉装置放入折射率为 $n$ 的水中，波长变为 $\lambda_n = \frac{\lambda}{n}$，则条纹间距 $\Delta x$ 会变为原来的 $\frac{1}{n}$（条纹变密）。

## 2. 薄膜干涉光程差与半波损失

*   **你的原声口诀：** *“薄膜干涉是2n222，因为进去进去再出来嘛。”*
*   **公式修正与精确表达：**
    对于折射率为 $n_2$、厚度为 $d$ 的薄膜，光线以折射角 $r$ 在膜内传播时，上下表面的反射光在相遇时的**光程差 $\delta$** 为：
    $$\delta = 2n_2 d \cos r \pm \frac{\lambda}{2}$$
    *(若光线为垂直入射，则 $r = 0$，$\cos r = 1$，光程差简化为 $\delta = 2n_2 d \pm \frac{\lambda}{2}$)*

*   **为什么有 $\pm \frac{\lambda}{2}$（半波损失）？**
    *   当光从**光疏介质**（折射率小）射向**光密介质**（折射率大）的界面反射时，反射光的相位会突变 $\pi$（相当于光程突变了半个波长 $\frac{\lambda}{2}$）。
    *   如果光在薄膜上表面反射有半波损失，而在下表面反射没有（或者反之），光程差公式中就必须加上或减去 $\frac{\lambda}{2}$。

## 3. 光栅衍射主极大公式

*   **你的原声口诀：** *“光栅峰衍射，他们在考试中也是这么样的。”*
*   **公式修正与精确表达：**
    光栅衍射的主极大（Grating peaks）公式（即光栅方程）为：
    $$(a + b) \sin \theta = \pm k \lambda \quad (k = 0, 1, 2, \dots)$$
    *   **$(a + b)$（或用 $d$ 表示）：** 光栅常数（透光缝宽 $a$ + 不透光缝宽 $b$）。
    *   **$\theta$：** 衍射角。
    *   **$k$：** 衍射级数。

> [!WARNING]
> **缺级现象（Missing orders）：** 
> 考试中常考由于单缝衍射暗极小与光栅干涉主极大重合导致的缺级。
> 缺级条件：当 $\frac{a+b}{a} = \frac{k}{k'}$（$k'$ 为单缝暗极小级数，是整数）时，该 $k$ 级主极大消失。

## 4. 布儒斯特定律与布儒斯特角的微观本质

*   **你的原声口诀：** *“布鲁斯角布鲁等于这个N21t等于加r等于90度。它们两个角是互的，所以正切等于这个。”*
*   **公式修正与精确表达：**
    当入射角为布儒斯特角 $\theta_p$ 时，反射光和折射光互相垂直，且反射光为纯 s 偏振光（光振动垂直于入射面）：
    $$\theta_p + \gamma = 90^\circ$$
    结合折射定律 $n_1 \sin \theta_p = n_2 \sin \gamma$，由于 $\sin \gamma = \sin(90^\circ - \theta_p) = \cos \theta_p$，可推导出**布儒斯特定律**：
    $$\tan \theta_p = \frac{n_2}{n_1} = n_{21}$$

*   **为什么反射光与折射光垂直时，p 分量会完全消失？（物理本质）**
    1.  **受迫振动与电偶极子：** 入射光进入第二介质形成折射光，折射光驱动介质中的电子做受迫振动。这些电子在微观上表现为不断振荡的**电偶极子**。
    2.  **偶极子的辐射特性：** 振荡的电偶极子向外辐射电磁波（即反射光），但**在其振动轴方向上辐射强度为 0**。
    3.  **几何垂直导致零辐射：** 折射光中 p 分量的电场方向垂直于折射方向。当反射方向与折射方向恰好成 $90^\circ$ 夹角时，反射方向恰好落在了这些受迫振动偶极子的振动轴线上。因此，偶极子在反射方向上无法产生任何 p 分量的辐射。
    4.  **结果：** 反射光中完全没有 p 分量，只剩下了电场振动垂直于入射面的 s 分量（完全线偏振光）。

## 5. 康普顿散射公式与波长改变量

*   **你的原声口诀：** *“散射角波长改变量，波长量等于 1-1减，一减，这个我还真不知道。”*
*   **公式修正与精确表达：**
    康普顿散射中，光子在被自由电子散射后，波长变长，改变量 $\Delta \lambda$ 为：
    $$\Delta \lambda = \lambda' - \lambda = \lambda_c (1 - \cos \theta)$$
    *   **$\theta$：** 光子的散射角（偏离原方向的角度）。
    *   **$\lambda_c = \frac{h}{m_0 c} \approx 0.00243 \text{ nm}$（或 $2.43 \times 10^{-12} \text{ m}$）：** 电子的康普顿波长（一个普适物理常数）。

> [!NOTE]
> 康普顿散射是**光子与自由电子的弹性碰撞**。因为碰撞过程中光子将部分能量传递给电子，导致散射光子的能量降低（频率降低，波长变长）。这个公式通过守恒定律直接导出，且**波长增量只与散射角 $\theta$ 有关，与入射光波长以及散射物质无关**。

## 6. 圆孔衍射与瑞利判据中的系数

*   **你的原声口诀：** *“圆孔用 c 等于 1.2，1.2。”*
*   **公式修正与精确表达：**
    圆孔衍射的最小分辨角（艾里斑第一级暗环的角半径）为：
    $$\theta_{min} = 1.22 \frac{\lambda}{D}$$
    *   **$D$：** 圆孔的直径（如透镜的孔径）。
    *   **$\lambda$：** 光的波长。
    *   **$1.22$：** 你提到的“1.2”，在物理学和工程计算中精确值是 **$1.22$**。它来源于第一类一阶贝塞尔函数的第一零点。

*   **瑞利判据：**
    对于两个等强度的非相干点光源，若其中一个光源的衍射中央最大值（艾里斑中心）刚好重合在另一个光源的第一暗环上，则此时对应的角距离即为最小分辨角 $\theta_{min}$。

## 7. 多缝干涉主极大振幅与光强的关系

*   **你的原声口诀：** *“主振幅是 N 倍，强度是方倍。”*
*   **公式修正与精确表达：**
    设单缝光波在中央极大处的电场振幅为 $E_0$，光强为 $I_0$：
    *   在多缝相干叠加的主极大方向上，各单缝光波相位完全一致，电场同相叠加：
        $$E = N E_0$$
    *   由于光强正比于振幅的平方（$I \propto E^2$），故主极大处的光强为：
        $$I = N^2 I_0$$
    （你口诀中的“方倍”即指 **$N$ 的平方倍**，这是完全正确的）。

## 8. 偏振度与条纹可见度（对比度/“凸显度”）

*   **你的原声口诀：** *“偏振的偏振度又叫这个凸显度，好像叫凸显度吧。”*
*   **概念解析与公式对比：**
    这二者在光学中虽然物理意义不同，但其**数学形式完全一致**，都用于描述某种“亮暗/强弱对比的凸显程度”：

### 1. 偏振度（Degree of Polarization, $P$）
用于衡量混合光（部分偏振光）中，偏振光强度占总光强的比例：
$$P = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$$
*   $P = 1$：完全线偏振光（极度偏振）。
*   $P = 0$：自然光（无偏振）。

### 2. 相干条纹可见度（Visibility, $V$，常称对比度或“条纹凸显度”）
用于描述干涉条纹的明暗对比清晰度（即条纹的凸显程度）：
$$V = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$$
*   $V = 1$：条纹对比极度明显（暗纹处光强为 0，条纹最“凸显”）。
*   $V = 0$：完全没有条纹（均匀光强）。

## 9. 介质板插入时光程与光程差分析（真题第1题）

*   **题目背景**：两个相干光源 $S_1$ 和 $S_2$ 到 $P$ 点的几何距离分别为 $r_1$ 和 $r_2$。$S_1P$ 路径上垂直穿过厚度为 $t_1$、折射率为 $n_1$ 的介质板，其余部分为真空；$S_2P$ 路径上垂直穿过厚度为 $t_2$、折射率为 $n_2$ 的介质板，其余部分为真空。求光程差。
*   **你的回答与疑问**：
    *   $S_1 \to P$ 的光程应该是包含介质段和真空段相加的。
    *   **疑问**：光程差如果是半波损失的话，光程差会有改变吗？会有 $\lambda/2$ 的改变吗？
*   **物理原理解析**：
    1.  **光程 (Optical Path Length, OPL)**：光在折射率为 $n$ 的介质中传播几何路程 $L$ 时，折合为真空中传播的等效路程为 $nL$。当光路中一部分为介质、一部分为真空时，各段光程直接代数相加：
        *   路径 1 ($S_1 \to P$) 的总光程为：$\delta_1 = n_1 t_1 + (r_1 - t_1) \cdot 1 = r_1 + (n_1 - 1)t_1$
        *   路径 2 ($S_2 \to P$) 的总光程为：$\delta_2 = n_2 t_2 + (r_2 - t_2) \cdot 1 = r_2 + (n_2 - 1)t_2$
    2.  **两路光程差 (Optical Path Difference, OPD)**：
        $$\Delta = \delta_2 - \delta_1 = [r_2 + (n_2 - 1)t_2] - [r_1 + (n_1 - 1)t_1]$$
        此公式精确对应真题中的选项 **(B)**。
    3.  **关于半波损失的疑问解答**：
        *   **什么是半波损失**：只有当光在**光疏介质射向光密介质的界面反射**时，反射光才会产生 $\pi$ 相位跃变，等效于产生半个波长 $\pm \lambda/2$ 的光程差改变。
        *   **本题为何没有半波损失**：因为此题物理过程是光的**透射**（光直接穿过介质板到达 $P$ 点），并未在界面发生反射。透射光在界面相位连续，无相位跃变，因此**完全不需要考虑半波损失 $\pm \lambda/2$**。

## 10. 迈克耳孙干涉仪插入介质薄膜的光程改变量（真题第2题）

*   **题目背景**：在 Michelson 干涉仪的一条光路中，放入一折射率为 $n$，厚度为 $d$ 的透明薄膜，放入后，这条光路的光程改变了多少？
*   **你的回答**：选 (C) 还是 (A)？迈克耳孙干涉仪里光速走了两次（往返），因此应该是 $2(n-1)d$。但不确定是否需要加 $\lambda/2$（半波损失）。
*   **物理原理解析**：
    1.  **往返光程分析**：迈克耳孙干涉仪的一条光路是往返式的（光射向平面镜然后被反射回来）。因此，光线会**穿过该薄膜两次**。
    2.  **改变量计算**：
        *   未插入薄膜时，该厚度为 $d$ 的空间为空气/真空，往返光程为 $2 \times 1 \times d = 2d$。
        *   放入折射率为 $n$ 的薄膜后，往返光程变为 $2 \times n \times d = 2nd$。
        *   因此，光程改变量（即放入后的光程减去放入前的光程）为：
            $$\Delta L = 2nd - 2d = 2(n - 1)d$$
    3.  **关于半波损失的解答**：
        *   这里考察的是**薄膜透射**带来的光程改变量（前后状态对比），尽管在干涉仪末端有反射镜，但放入薄膜前后，末端反射镜的反射性质完全没有改变。
        *   光在透过薄膜两端面时，都是**透射**过程，没有反射产生的相位突变。
        *   因此，**这里绝对不含半波损失 $\lambda/2$ 项**，正确答案为 **(A)** $2(n - 1)d$，而非 (C) $2(n - 1)d + \lambda/2$。

*   **迈克耳孙干涉仪的核心通用公式：反射镜移动与条纹移动数的关系**：
    $$2\Delta d = N\lambda \quad \text{或} \quad 2\Delta x = k\lambda$$
    *   **$\Delta d$ (或 $\Delta x$)**：干涉仪中某一条支路反射镜移动的距离。
    *   **$N$ (或 $k$)**：屏幕上视场中心干涉条纹移动的数目（或涌出/消逝的条纹个数）。
    *   **$\lambda$**：工作光波长。
    *   **为什么是 $2$ 倍关系？**：因为移动反射镜 $\Delta d$ 距离，光在这一条支路里是**往返传播**的，导致光程差的改变是反射镜实际位移的 **$2$ 倍**。
    *   这个公式也是期末必考的经典公式，只要题目提到“反射镜移动了多少距离，条纹移动了多少个”，直接带入该公式即可。

## 11. 狭义相对论总能量与速度关系（真题第4题）

*   **题目背景**：设某微观粒子的总能量是它静止能量的 $K$ 倍，求其运动速度的大小（以 $c$ 表示真空中的光速）。
*   **物理原理解析与严密推导**：
    1.  **定义能量公式**：
        *   粒子的静止能量（Rest Energy）：
            $$E_0 = m_0 c^2$$
        *   粒子的相对论总能量（Total Relativistic Energy）：
            $$E = m c^2 = \gamma m_0 c^2$$
            其中洛伦兹因子（Lorentz factor）为：
            $$\gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}$$
    2.  **建立方程**：
        根据题意，总能量是静止能量的 $K$ 倍，即：
        $$E = K E_0 \implies \gamma m_0 c^2 = K m_0 c^2 \implies \gamma = K$$
    3.  **求解速度 $v$**：
        将 $\gamma$ 的表达式代入：
        $$\frac{1}{\sqrt{1 - \frac{v^2}{c^2}}} = K$$
        两边平方：
        $$\frac{1}{1 - \frac{v^2}{c^2}} = K^2$$
        取倒数：
        $$1 - \frac{v^2}{c^2} = \frac{1}{K^2}$$
        移项整理：
        $$\frac{v^2}{c^2} = 1 - \frac{1}{K^2} = \frac{K^2 - 1}{K^2}$$
        开平方：
        $$\frac{v}{c} = \frac{\sqrt{K^2 - 1}}{K}$$
        两边乘以光速 $c$，得到速度大小：
        $$v = \frac{c}{K} \sqrt{K^2 - 1}$$
    4.  **结论**：
        此推导结果完全对应本题选项中的 **(C)** $\frac{c}{K}\sqrt{K^2 - 1}$。这也是狭义相对论质能关系中非常典型且常考的选择/填空推导。

## 12. 海森堡不确定关系物理本质理解（真题第5题）

*   **题目背景**：关于不确定关系 $\Delta p_x \Delta x \ge \hbar$，判断以下理解是否正确：
    1.  粒子的动量不可能确定
    2.  粒子的坐标不可能确定
    3.  粒子的动量和坐标不可能同时准确地测定
    4.  不确定关系不仅适用于电子和光子，也适用于其他粒子
*   **你的回答**：选 (C)，即 (3) 和 (4) 正确。认为不仅适用于电子和光子，也适用于中子、原子等其他微观实物粒子。
*   **物理原理解析**：
    1.  **为什么 (1) 和 (2) 是错误的**：
        *   量子力学中，粒子的单个物理量**可以具有完全确定的值**。
        *   若粒子处于动量本征态（如德布罗意平面单色波），其动量是完全确定的（$\Delta p_x = 0$），代价是位置完全不确定（$\Delta x \to \infty$）。
        *   若粒子处于位置本征态（如极窄的脉冲波包），其空间坐标是完全确定的（$\Delta x = 0$），代价是动量完全不确定（$\Delta p_x \to \infty$）。
        *   因此，并非“单个动量”或“单个坐标”绝对无法确定，限制在于两者**同时**确定。
    2.  **为什么 (3) 是正确的**：
        *   $\Delta p_x \Delta x \ge \hbar$（或者更精确的 $\ge \frac{\hbar}{2}$）表明，同一个粒子在同一个方向上的**动量不确定度与位置不确定度的乘积有一个下限**。这二者此消彼长，不能**同时**测准。
    3.  **为什么 (4) 是正确的**：
        *   不确定关系是**波粒二象性**（德布罗意关系 $\lambda = h/p$）的必然数学推论。任何实物粒子（电子、质子、中子、原子、分子，甚至宏观物体）都具有波动性。
        *   因此，它适用于**宇宙中的所有物质**。只是宏观物体的质量 $m$ 极大，其德布罗意波长极短，不确定性尺度小到无法被微观探测出来，可以忽略，但在原理上它绝对成立。
    4.  **结论**：
        你的判断完全正确，应当选择 **(C)**。评分 100% 满分。

## 13. 氢原子电子轨道量子数取值规则（真题第6题）

*   **物理要点与取值规则**：

## 14. 半导体与绝缘体能带结构特征区别（真题第7题）

*   **题目背景**：与绝缘体相比，半导体能带结构的特点是什么？
*   **物理要点解析**：
    1.  **能带基本结构**：固体中的电子能量只能处于一系列能带中。
        *   **满带（价带）**：在绝对零度时，被电子填满的能量较低的能带。
        *   **导带**：在绝对零度时，没有被电子填满（空带）的能量较高的能带。
        *   **禁带（能隙/带隙 $E_g$）**：满带与导带之间，不允许电子存在的能量区域。
    2.  **绝缘体 vs. 半导体**：
        *   **绝缘体**：禁带宽度 $E_g$ 很大（通常 $E_g > 3\text{ eV}$，有的高达 $5-6\text{ eV}$ 以上）。室温下的热运动能量无法把满带中的电子激发到导带中去，因而无法导电。
        *   **半导体**：结构上和绝缘体一样，满带全满，导带全空。但其**禁带宽度 $E_g$ 较窄**（通常 $E_g < 3\text{ eV}$，例如硅 $\text{Si}$ 仅有 $1.1\text{ eV}$，锗 $\text{Ge}$ 仅有 $0.67\text{ eV}$）。因此，室温下部分电子可以轻易跨越禁带受热激发到导带，产生导电性。
    3.  **其他选项为什么错**：
        *   (A) 导带也是空带：两者在绝对零度下都是空带，但这不是半导体的特殊区别点。
        *   (B) 满带与导带重合：这是导体（如金属）的特点（无禁带，$E_g=0$）。
        *   (C) 满带中总是有空穴，导带中总是有电子：只有在温度高于绝对零度（或有光照等激发）时才有，不是“总是”有。
    4.  **结论**：
        正确选项为 **(D)**。

## 15. 自发辐射与受激辐射的发光干涉特征（真题第8题）

*   **题目背景**：原子通过自发辐射和受激辐射的方式发光，它们所产生的光的相干性特点是什么？
*   **物理要点解析**：
    1.  **自发辐射（Spontaneous Emission）**：
        *   处于激发态的原子在不受外界影响下，自发地跃迁到低能级并释放光子。
        *   因为每个原子都是**独立、随机**跃迁的，所以不同原子自发辐射出的光子，其相位、偏振方向、传播方向全都是随机、无规则的。
        *   因此，两个原子自发辐射的同频率光是**不相干**的。
    2.  **受激辐射（Stimulated Emission）**：
        *   处于激发态的原子受到一个外来光子的诱导（刺激），跃迁到低能级并释放一个新光子。
        *   关键性质：受激发射出的新光子与外来的入射光子**在频率、相位、偏振方向、传播方向上完全相同**（克隆光子）。
        *   因此，原子受激辐射的光与入射光是**高度相干**的（这是激光 $\text{Laser}$ 的核心工作机制）。
    3.  **结论**：
        正确选项为 **(B)**。

## 17. 杨氏双缝干涉与薄膜覆盖的定量分析大题（真题第17题）

*   **题目背景**：双缝干涉实验装置中，双缝与屏之间的距离 $D = 120\text{ cm}$，两缝之间的距离 $d = 0.50\text{ mm}$，用波长 $\lambda = 500\text{ nm}$ 的单色光垂直照射双缝。

        *   零级明纹中心正好在原点 $x_0 = 0$。
        *   第一级明纹中心在 $x_1 = 1 \cdot \Delta x$；
        *   第二级明纹中心在 $x_2 = 2 \cdot \Delta x$……
        *   **第五级明纹中心就正好在 $x_5 = 5 \cdot \Delta x$**。完全没有半个或两倍的偏移！直接乘 5 即可。

            $$\Delta x_{shift} = \frac{D}{d}(n-1)l$$

            $$\Delta x_{shift} = \frac{1.20\text{ m}}{0.50 \times 10^{-3}\text{ m}} \times (1.58 - 1) \times (1.0 \times 10^{-5}\text{ m}) = 2400 \times 0.58 \times 1.0 \times 10^{-5}\text{ m} = 0.01392\text{ m} = 13.92\text{ mm}$$

               $$\text{移动的条纹数 } N = \frac{\Delta L}{\lambda} = \frac{(n-1)l}{\lambda}$$
            3. 因为每移动一个条纹，在屏幕上的物理位移就是一条条纹间距 $\Delta x$，所以总位移为：
               $$\Delta x_{shift} = N \times \Delta x = \frac{(n-1)l}{\lambda} \times \Delta x$$
            4. 把第一问算出的 $\Delta x = \frac{D}{d}\lambda$ 代入（或者直接代入数值 $\Delta x = 1.2\text{ mm}$）：
               $$\Delta x_{shift} = \frac{(1.58-1) \times 1.0 \times 10^{-5}\text{ m}}{500 \times 10^{-9}\text{ m}} \times 1.2\text{ mm} = \frac{0.58 \times 10^{-5}}{5 \times 10^{-7}} \times 1.2\text{ mm} = 11.6 \times 1.2\text{ mm} = 13.92\text{ mm}$$
            这两种方法殊途同归，但你的推导方法**物理图像更清晰**：先算它相当于几个波长（$11.6$ 个波长），再乘以每个波长对应的条纹间距 $\Delta x$。
        *   **求第五级明纹的新坐标 $x'$**：
            由于条纹向上整体移动了 $13.92\text{ mm}$：
            $$x' = x_5 + \Delta x_{shift} = 6.0\text{ mm} + 13.92\text{ mm} = 19.92\text{ mm} = 1.99 \times 10^{-2}\text{ m}$$

### 📝 考场标准大题书写规范模板（直接抄即可拿满分）

> **解：**
> (1) 平面光栅的光栅常数为：
> $$d = \frac{W}{N_{total}} = \frac{2 \times 10^{-2}\text{ m}}{8000} = 2.5 \times 10^{-6}\text{ m}$$
> 
> (2) 根据光栅方程，主极大的衍射角 $\theta$ 满足：
> $$d \sin \theta = k \lambda \quad (k = 0, \pm 1, \pm 2, \dots)$$
> 
> 由于主极大的衍射角最大范围为 $|\sin \theta| \le 1$，所以级数 $k$ 必须满足：
> $$|k| \le \frac{d}{\lambda}$$
> 
> 代入数据：
> $$|k| \le \frac{2.5 \times 10^{-6}\text{ m}}{589.3 \times 10^{-9}\text{ m}} \approx 4.24$$
> 
> 因为 $k$ 为整数，所以可能出现的各个主极大的级数为：$k = 0, \pm 1, \pm 2, \pm 3, \pm 4$。
> 
> (3) 各级主极大对应的衍射角 $\theta_k$ 分别为：
> *   当 $k = 0$ 时，$\sin \theta_0 = 0 \implies \theta_0 = 0^\circ$
> *   当 $k = \pm 1$ 时，$\sin \theta_{\pm 1} = \pm \frac{\lambda}{d} = \pm 0.236 \implies \theta_{\pm 1} = \pm 13.6^\circ$（或 $\pm 13^\circ 38'$）
> *   当 $k = \pm 2$ 时，$\sin \theta_{\pm 2} = \pm \frac{2\lambda}{d} = \pm 0.471 \implies \theta_{\pm 2} = \pm 28.1^\circ$（或 $\pm 28^\circ 8'$）
> *   当 $k = \pm 3$ 时，$\sin \theta_{\pm 3} = \pm \frac{3\lambda}{d} = \pm 0.707 \implies \theta_{\pm 3} = \pm 45.0^\circ$（或 $\pm 45^\circ$）
> *   当 $k = \pm 4$ 时，$\sin \theta_{\pm 4} = \pm \frac{4\lambda}{d} = \pm 0.943 \implies \theta_{\pm 4} = \pm 70.5^\circ$（或 $\pm 70^\circ 32'$）
> 
> **答：**
> 可能出现的各个主极大对应的衍射角分别为：$0^\circ$、$\pm 13.6^\circ$、$\pm 28.1^\circ$、$\pm 45.0^\circ$、$\pm 70.5^\circ$。
