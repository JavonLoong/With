## 1. 封面：SenseLimb 智能假肢训练系统

### 页面主标题
SenseLimb：让智能假肢先在虚拟世界里学会“被使用”

### 页面可见内容
- 面向上肢假肢初用者的训练与适配系统
- 组合技术：意图识别 + XR 训练反馈 + AI 教练 + 3D 定制化部件
- 课程原型目标：证明“可感知、可训练、可迭代”的产品闭环

### 演讲提示
开场先明确这不是一个宣称治疗效果的医疗产品，而是一个智能电子产品设想：把假肢控制训练、反馈和个性化外形适配做成一个可演示的闭环。SenseLimb 的重点不是“替代临床康复”，而是把课程里接触到的 BrainCo / 可穿戴、XR、讯飞智能体、混元 3D 与拓竹打印连接成一个合理的产品原型。

### 画面建议

## 2. 背景：智能义肢不只是机械替代

### 页面主标题
从“能动的手”到“会被用户学会使用的系统”

### 页面可见内容
- 上肢假肢的难点不只在机械结构，还在持续的人机适配
- 用户需要学习：如何发出稳定控制意图，如何理解反馈，如何建立日常动作信心
- 课程技术提供了新机会：可穿戴信号、XR 场景、智能体陪练、3D 快速制造

### 演讲提示
传统想象里，假肢像一个机械替代件，只要做得灵巧就可以。但真实使用中，用户还要学习控制方式、佩戴舒适度也需要迭代，不同日常任务对端部形态的要求也不同。所以本项目把假肢看成一个“人机共融”的训练系统，而不是单个硬件。

### 画面建议
用一条横向链路表达“佩戴适配 → 意图控制 → 训练反馈 → 场景迁移 → 继续迭代”。背景可以用低饱和的义肢轮廓或手部动作线稿。

## 3. 问题：初用者的三重断点

### 页面主标题
为什么“有设备”不等于“会使用”

### 页面可见内容
1. 控制断点：肌电 / 脑电信号容易受位置、疲劳、噪声影响，用户不知道自己“发力对不对”
2. 训练断点：真实物体练习成本高，失败反馈不够量化，也不容易重复
3. 适配断点：残肢形态、外壳审美、握持任务差异大，单一端部难覆盖所有场景

### 边界提示
- 本项目关注训练辅助、交互体验和原型验证
- 不宣称改善疾病、恢复功能或提供临床康复效果

### 演讲提示
这里要把问题讲清楚：不是“假肢不够智能”，而是“用户、设备和训练环境之间缺少闭环”。如果控制信号不稳定，用户不知道问题来自自己发力、传感器位置还是算法判断；如果训练只能靠真实物体，失败成本会更高；如果端部不适合日常任务，使用意愿也会下降。

### 画面建议
三栏问题结构，每栏一个关键词：控制、训练、适配。底部用小字标出“课程原型边界：训练辅助，不替代临床”。

## 4. 产品设想：SenseLimb 闭环训练平台

### 页面主标题
SenseLimb = 智能假肢原型 + XR 训练舱 + AI 使用教练 + 3D 定制端部

### 页面可见内容
- Sense：采集肌电 / 脑电 / 姿态等可穿戴信号
- Interpret：识别张手、握拳、捏取、旋转、休息等基础意图
- Train：在 XR 中完成低风险重复训练并获得实时反馈
- Coach：讯飞智能体生成训练提示、复盘记录和使用建议
- Iterate：混元 3D 生成外壳或握持端，拓竹打印快速验证

### 演讲提示
产品设想可以理解成一个闭环：先感知用户意图，再把意图映射到虚拟或物理假肢动作；用户在 XR 中练习，AI 教练把训练数据翻译成可理解建议；最后通过 3D 生成与打印，让外壳和握持端更贴近具体用户和具体任务。

### 画面建议
画一个环形流程图，五个节点分别是 Sense、Interpret、Train、Coach、Iterate。中间放 SenseLimb 产品名。

## 5. 系统总架构：四层协同

### 页面主标题
把课程技术拆成四个可实现模块

### 页面可见内容
| 层级 | 课程技术映射 | 在系统中的作用 |
|---|---|---|
| 信号层 | BrainCo / 可穿戴 / 肌电或脑电 | 捕捉用户控制意图与训练状态 |
| 训练层 | PICO / Apple Vision Pro XR | 构建可重复、低风险、可量化的训练任务 |
| 交互层 | 讯飞智能体 | 用自然语言做陪练、提醒、答疑和复盘 |
| 制造层 | 混元 3D + 拓竹 3D 打印 | 快速生成个性化外壳、握持端和教学样机 |

### 演讲提示
这页用来说明方案不是堆技术，而是按功能分层。信号层回答“用户想做什么”，训练层回答“在哪里安全练”，交互层回答“练完怎么理解”，制造层回答“怎么快速适配到个人和场景”。这样每个课程技术都有明确位置。

### 画面建议
用四层堆叠架构图。每层左侧放技术名称，右侧放一句作用。底部可以画数据流：信号数据、训练日志、部件参数。

## 6. 技术方案一：BrainCo / 肌电或脑电意图识别

### 页面主标题
肌电优先，脑电辅助：先做可靠的基础意图识别

### 页面可见内容
- 输入：表面肌电传感器采集残肢或前臂肌肉活动；BrainCo / 脑电模块可用于注意力、放松度或意图探索
- 处理：滤波、窗口切片、特征提取，识别基础动作类别
- 输出：张手、握拳、捏取、旋转、休息等低维控制指令
- 保护机制：低置信度时不执行危险动作，提示重新校准或切换语音确认

### 技术边界
- 不把脑电包装成“直接精准控制手指”
- 课程原型优先验证手势分类、训练反馈和人机交互逻辑
- 真实假肢控制需要更严格的安全、鲁棒性和临床验证

### 演讲提示
答辩时要主动说明为什么“肌电优先”。肌电距离动作意图更近，适合做基础手势控制；脑电更适合做状态识别、注意力反馈或探索性输入，不适合在课程原型里承诺精细手指控制。系统可以设置置信度阈值，信号不稳定就不让设备动作，而是在 XR 或智能体里提示用户重新调整。

### 画面建议
用信号处理管线图：传感器 → 预处理 → 分类器 → 置信度门控 → 虚拟手 / 假肢动作。右侧用醒目标签写“低置信度 = 先训练，不冒险执行”。

## 7. 技术方案二：XR 训练反馈

### 页面主标题
在 PICO / Apple Vision Pro 中先练会，再连接真实端部

### 页面可见内容
- 虚拟任务：抓杯子、捏方块、转旋钮、开抽屉、拿钥匙
- 实时反馈：意图识别置信度、动作完成时间、轨迹平滑度、错误次数
- 沉浸训练：虚拟手与用户意图同步，帮助建立“我发出什么信号会产生什么动作”的映射
- 训练记录：每次任务生成日志，供讯飞智能体复盘

### 演讲提示
XR 的价值是把高成本、高挫败感的真实练习，先变成可重复、可量化的虚拟任务。比如用户想练“捏取”，XR 中可以反复捏小方块，系统显示识别置信度和误触发次数。这样用户可以看到自己控制信号是否稳定，老师也可以看到训练过程是否有进步。

### 画面建议
左侧画 XR 眼镜中的虚拟手，右侧画三条反馈指标：置信度、完成时间、错误次数。不要把指标写成临床疗效，只写训练表现指标。

## 8. 技术方案三：讯飞智能体康复 / 使用教练

### 页面主标题
把训练数据翻译成用户听得懂的下一步

### 页面可见内容
- 训练前：语音引导佩戴、校准、选择训练任务
- 训练中：提示“信号偏弱”“放松后再握拳”“建议重新贴电极”
- 训练后：生成复盘摘要，例如稳定动作、易误判动作、下次练习重点
- 日常答疑：基于产品说明书和课程资料回答使用问题

### 安全边界
- 智能体只做训练陪伴、操作提醒和信息解释
- 不做医疗诊断，不给个体化治疗处方
- 异常疼痛、皮肤不适、设备损坏等情况提示联系专业人员

### 演讲提示
讯飞智能体的核心不是“替代康复师”，而是降低用户理解训练数据的门槛。很多数据如果只显示成图表，用户未必知道下一步怎么做。智能体可以把“握拳识别置信度下降”翻译成“今天电极位置可能偏移，先重新校准两次”。

### 画面建议
展示一个对话气泡示例：用户问“为什么今天总是误触发？”智能体回答“可能与电极位置或肌肉疲劳有关，建议先重新校准，并降低任务难度”。底部写“不诊断，只辅助训练”。

## 9. 技术方案四：混元 3D + 拓竹 3D 打印定制化端部

### 页面主标题
把“个人差异”变成可快速迭代的外壳和握持端

### 页面可见内容
- 输入：手臂尺寸、佩戴区域、任务需求、审美偏好
- 生成：用混元 3D 生成外壳纹理、保护罩、握持端外形参考
- 制造：用拓竹 3D 打印快速制作 PLA / PETG / TPU 原型件
- 验证：检查佩戴舒适度、抓握任务适配度、装配可维护性

### 可演示样机设想
- 可替换握持端：杯子握持端、笔夹端、钥匙辅助端
- 定制外壳：轻量保护罩、个性化纹理、颜色标识
- 教学样机：透明或半开放结构，便于展示传感器和执行机构

### 材料边界
- 打印件用于课程样机和低风险训练道具
- 不直接作为承重医疗部件或长期贴肤医疗器械
- 需要做强度、热变形、边缘毛刺和皮肤接触风险检查

### 演讲提示
这一页强调“个性化”的工程实现。混元 3D 负责快速生成形态概念，拓竹打印负责快速把概念变成可拿在手里的样机。答辩时要说明，打印件不是临床级承重假肢，而是课程原型中的外壳、训练端部和可替换握持附件。

### 画面建议
用“需求输入 → 3D 生成 → 切片打印 → 试用反馈 → 再设计”的小流程。旁边放三个握持端小图标。

## 10. 预期成效、风险边界、课程收获

### 页面主标题
成效看训练体验和原型闭环，不夸大临床结论

### 页面可见内容
| 维度 | 预期成效 | 可验证指标 |
|---|---|---|
| 训练体验 | 用户更容易理解控制信号与动作结果的关系 | 任务完成率、误触发次数、校准次数、主观易用性评分 |
| 产品迭代 | 从一个标准端部变成多个场景化端部 | 打印迭代次数、装配时间、任务适配评分 |
| 人机共融 | 形成“人学习机器，机器适应人”的循环 | 训练日志、智能体建议采纳率、动作稳定性变化 |

### 风险与边界
- 信号风险：肌电 / 脑电受噪声、佩戴位置和个体差异影响，必须有校准与置信度门控
- 安全风险：真实执行机构需要限力、急停和机械保护
- 隐私风险：训练日志和生理信号需要最小化采集、用户授权和本地化存储优先
- 医疗边界：课程原型不能宣称临床疗效，也不能替代专业康复评估

### 课程收获
- 认识到智能电子产品不是单一硬件，而是传感、算法、交互、制造和伦理边界的组合
- 学会把混元 3D、拓竹打印、XR、讯飞智能体、BrainCo / 可穿戴整合成一个闭环方案
- 对“人机共融”的理解从技术炫技转向长期适配、反馈和可解释交互

### 演讲提示
最后要把项目收束到课程目标：提出产品设想，并用课上技术说明实现。预期成效只讲训练体验、原型迭代和交互理解，不说“康复效果显著”。风险边界要主动讲，这反而会让方案更可信。

### 画面建议
上半页用三列表格讲成效，下半页用四个风险标签：信号、安全、隐私、医疗边界。右下角放一句收束语：“智能义肢的核心不是替代身体，而是建立可学习的人机闭环。”

# 5 分钟问答准备，不计入页数

## Q1：为什么不直接用脑电控制整只手？
答：课程原型中不建议这么承诺。脑电信号对精细手指控制的鲁棒性和实时性要求很高，容易被噪声影响。我们的方案采用“肌电优先，脑电辅助”，肌电用于基础动作意图，脑电或 BrainCo 可穿戴模块用于注意力、放松度、训练状态或探索性输入，这样更符合课程原型的可实现性。

## Q2：这个系统能证明真实康复效果吗？
答：不能，也不应该在课程汇报中这样宣称。我们能验证的是训练交互是否顺畅、基础意图识别是否可用、XR 反馈是否让用户更理解动作映射、3D 定制部件是否能加快样机迭代。临床疗效需要伦理审批、专业人员介入和长期样本研究。

## Q3：如果肌电识别错误，假肢乱动怎么办？
答：设计上加入置信度门控、限力控制、急停按钮和训练模式分级。低置信度时优先在 XR 中提示重新校准，不直接驱动物理端部。真实执行机构也要限制速度和力矩。

## Q4：讯飞智能体会不会给出错误医疗建议？
答：系统提示词和知识库要限制智能体角色：它只做训练陪伴、操作说明和日志复盘，不做诊断、不做治疗处方。出现疼痛、皮肤异常、设备损坏等情况，智能体应提示停止使用并联系专业人员。

## Q5：混元 3D 生成的模型能直接打印成假肢吗？
答：不能直接作为临床假肢。它更适合生成外壳、握持端、保护罩和教学样机的形态参考。正式承重结构需要工程建模、材料测试和专业认证。课程中我们用拓竹打印做快速验证，而不是医疗级交付。

## Q6：项目最小可行演示怎么做？
答：可以做三步演示：第一，用肌电或模拟传感输入识别握拳 / 张手；第二，在 XR 或电脑端显示虚拟手同步动作和置信度；第三，让讯飞智能体根据训练日志给出复盘建议，同时展示一个 3D 打印的可替换握持端样机。

## Q7：这个项目的创新点在哪里？
答：创新点不在某一个零件，而在闭环整合：意图识别解决“我想做什么”，XR 解决“如何低风险练习”，智能体解决“我下一步怎么改”，3D 打印解决“设备如何适配我”。这正好对应课程的人机共融方向。
