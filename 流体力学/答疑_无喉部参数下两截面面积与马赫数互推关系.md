# 💡 答疑：无喉部参数时，如何通过两个截面的面积比 $A_1/A_2$ 互推马赫数？

在有些考试题中，题目**没有给出喉部面积 $A^*$**，也没有直接给出面马关系表。此时，题目会给出**任意两个截面的面积比 $A_1/A_2$** 以及其中一个截面的马赫数 $Ma_1$，要求另一个截面的马赫数 $Ma_2$。

对于这种题型，我们需要通过**质量守恒（连续性方程）**来自己推导它们之间的关系。

---

## 1. 任意两截面的“面积-马赫数”直接关联公式

如果在喷管中任意取截面 1 和截面 2，它们之间的面积比与马赫数满足以下通用公式（以空气 $k=1.4$ 为例）：

$$\frac{A_1}{A_2} = \frac{Ma_2}{Ma_1} \left( \frac{1 + 0.2 Ma_1^2}{1 + 0.2 Ma_2^2} \right)^{3.0}$$

*注：这个公式是面马关系通用公式。如果截面 2 刚好是喉部（即 $A_2 = A^*$，$Ma_2 = 1$），则该公式退化为我们之前所说的 $\frac{A_1}{A^*} = \frac{1}{Ma_1} \left( \frac{1 + 0.2 Ma_1^2}{1.2} \right)^{3.0}$。*

---

## 2. 考场上如何推导这个公式？（防忘证明步骤）

如果考场上忘记了这个公式，可以通过以下三步极速推导出来：

### 第 1 步：写出连续性方程
因为质量守恒，通过两截面的质量流量相等：
$$\rho_1 A_1 v_1 = \rho_2 A_2 v_2 \implies \frac{A_1}{A_2} = \frac{\rho_2}{\rho_1} \frac{v_2}{v_1}$$

### 第 2 步：用马赫数和温度表示流速比
流速 $v = Ma \cdot c = Ma \sqrt{k R T}$，所以流速之比为：
$$\frac{v_2}{v_1} = \frac{Ma_2}{Ma_1} \sqrt{\frac{T_2}{T_1}}$$
因为等熵温度关系 $\frac{T_0}{T} = 1 + 0.2 Ma^2$，所以温度之比为：
$$\frac{T_2}{T_1} = \frac{1 + 0.2 Ma_1^2}{1 + 0.2 Ma_2^2}$$

### 第 3 步：用马赫数表示密度比
因为等熵密度关系 $\frac{\rho}{\rho_0} = \left( 1 + 0.2 Ma^2 \right)^{-2.5}$，所以密度之比为：
$$\frac{\rho_2}{\rho_1} = \left( \frac{1 + 0.2 Ma_1^2}{1 + 0.2 Ma_2^2} \right)^{2.5}$$

### 第 4 步：代回连续性方程相乘
$$\frac{A_1}{A_2} = \frac{\rho_2}{\rho_1} \frac{v_2}{v_1} = \left( \frac{1 + 0.2 Ma_1^2}{1 + 0.2 Ma_2^2} \right)^{2.5} \times \frac{Ma_2}{Ma_1} \left( \frac{1 + 0.2 Ma_1^2}{1 + 0.2 Ma_2^2} \right)^{0.5}$$
指数相加：$2.5 + 0.5 = 3.0$。公式证毕：
$$\frac{A_1}{A_2} = \frac{Ma_2}{Ma_1} \left( \frac{1 + 0.2 Ma_1^2}{1 + 0.2 Ma_2^2} \right)^{3.0}$$

---

## 🎯 总结（20字极简避坑指南）：
* **没有喉部参数时怎么建立面积与马赫数关系？**
  * **解答**：用两截面流量相等及等熵公式联立推导。
* **两截面面积比公式指数是多少？**
  * **解答**：以马赫数项为底，空气对应的指数是 3.0。
