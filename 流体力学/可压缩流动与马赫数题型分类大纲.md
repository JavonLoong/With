# 🗺️ 流体力学：可压缩流动与马赫数相关题型全景分类大纲

在期末考试中，所有与**马赫数（$Ma$）**和**可压缩流动**相关的题目，均可以系统地归纳为以下**四大必考题型**。

---

## 📂 题型一：等熵状态参数换算与气源（滞止）推导（基础题）

* **核心物理概念**：
  研究流体在等熵流动过程中，任意局部截面的状态参数（静压 $P$、静温 $T$、静密度 $\rho$、局部速度 $v$、局部马赫数 $Ma$）与气源的滞止参数（$P_0, T_0, \rho_0$）之间的换算。
* **黄金计算公式（对于空气 $k=1.4$）**：
  1. **温马关系**：$$\frac{T_0}{T} = 1 + 0.2 Ma^2$$
  2. **压马关系**：$$\frac{P_0}{P} = \left(1 + 0.2 Ma^2\right)^{3.5}$$
  3. **密马关系**：$$\frac{\rho_0}{\rho} = \left(1 + 0.2 Ma^2\right)^{2.5}$$
* **考场典型真题**：
  * *真题例*：一个 $500\text{ K}$ 和 $200\text{ kPa}$ 的空气源为喷管提供等熵流动，某截面压力为 $150\text{ kPa}$，求马赫数和温度。（2006年第三题）

---

## 📂 题型二：变截面管流与喷管流动堵塞（中档计算题）

* **核心物理概念**：
  研究渐缩喷管或收缩-扩张（Laval）喷管的流量限制。当喉部（最小截面积 $A^*$）的流速达到当地声速（$Ma_{\text{throat}} = 1$）时，流量达到物理极限，发生**临界塞流（Choked Flow）**。
* **黄金计算公式（对于空气 $k=1.4$，$R=287\text{ J/(kg·K)}$）**：
  1. **临界比值**：$T^* = 0.833 T_0$，$P^* = 0.5283 P_0$，$\rho^* = 0.6339 \rho_0$。
  2. **最大质量流量分步法**：$$\dot{m}_{\max} = \rho^* A^* v^* \quad (\text{其中 } v^* = c^* = \sqrt{k R T^*})$$
  3. **最大质量流量极速秒杀公式**：$$\dot{m}_{\max} \approx 0.6847 \frac{P_0 A^*}{\sqrt{R T_0}}$$
* **考场典型真题**：
  * *真题例*：大气容器连接一 Laval 喷管，喉部面积为 $0.06\text{ m}^2$，等熵流动下的最大质量流量为多少？（2006年第四题）

---

## 📂 题型三：出口背压变化与管内流态/激波判别（压轴分析题）

* **核心物理概念**：
  气源压力 $P_0$ 固定，通过调节下游背压 $P_b$，分析喷管内部的流动流态变化（亚音速、超音速、激波位置）。
* **黄金解题法则（三临界背压区间法）**：
  由出口面积比 $A_e/A^*$ 确定出口处的亚音速马赫数 $Ma_{e,\text{sub}}$ 和超音速马赫数 $Ma_{e,\text{sup}}$，计算三个特征背压：
  1. **第一临界背压 $P_{b1}$**（刚发生阻塞）：对应出口马赫数为 $Ma_{e,\text{sub}}$ 的等熵压力。
  2. **第三临界背压 $P_{b3}$**（设计超音速）：对应出口马赫数为 $Ma_{e,\text{sup}}$ 的等熵压力。
  3. **第二临界背压 $P_{b2}$**（出口正激波）：$P_{b2} = P_{b3} \left[ 1 + 1.1667 \left( Ma_{e,\text{sup}}^2 - 1 \right) \right]$。
* **流态判定表**：
  * $P_b > P_{b1}$ $\implies$ **全管亚音速，无声速点，无激波**
  * $P_{b2} < P_b < P_{b1}$ $\implies$ **管内扩张段有正激波**（激波在出口上游）
  * $P_b = P_{b2}$ $\implies$ **正激波刚好在出口截面上**
  * $P_{b3} < P_b < P_{b2}$ $\implies$ **管内无激波，出口外有压缩波/斜激波**（过膨胀）
  * $P_b = P_{b3}$ $\implies$ **完全等熵超音速设计状态，无激波**
  * $P_b < P_{b3}$ $\implies$ **管内超音速，出口外有膨胀波**（欠膨胀）
* **考场典型真题**：
  * *真题例*：水银测压计读数差为 $15\text{ cm}$，估算下游背压并判定正激波存在性及位置。（2006年大题第四大题）

---

## 📂 题型四：正激波/斜激波前后的突变计算（纯激波计算题）

* **核心物理概念**：
  气流在穿过正激波（Normal Shock）或斜激波（Oblique Shock）时，状态发生突变。激波过程是**非等熵但绝热**的（即**总压 $P_0$ 降低**，但**总温 $T_0$ 不变**）。
* **黄金计算公式**：
  1. **波前后马赫数关系**：$$Ma_2^2 = \frac{2 + (k-1)Ma_1^2}{2k Ma_1^2 - (k-1)}$$
  2. **波前后压力比**：$$\frac{P_2}{P_1} = 1 + \frac{2k}{k+1}(Ma_1^2 - 1)$$
  3. **总压（滞止压力）损失比**：$$\frac{P_{02}}{P_{01}} = \left(\frac{k+1}{2 Ma_1^2}\right)^{\frac{k}{k-1}} \left( \frac{2k Ma_1^2 - (k-1)}{k+1} \right)^{-\frac{1}{k-1}}$$
* **考场典型真题**：
  * *真题例*：已知来流马赫数为 $Ma_1 = 2.0$，静压为 $100\text{ kPa}$。求经过正激波后的马赫数 $Ma_2$、静压 $P_2$ 以及总压损失。
