## 2. 当前最综合的一道题

最适合做核心母题的是：

**2022 春期末计算题：两个油箱经变径突扩钢管连接，求输油流量、A/B 点压强、长管所需液面差。**

对应定位：

- 主索引：`Q0033`
- 全目录候选：`C36940`
- 所属章节：第8/10章，粘性管路与工程损失
- 所属母题：母题6：粘性管路/沿程局部损失/泵水轮机
- 子题类型：水池-管路-泵阀-局部损失综合

为什么它最综合：

1. 同时考大容器液面简化：自由液面 `p=0` 表压，`V≈0`。
2. 同时考 PVZ/机械能方程：左液面到右液面、左液面到 A 点、B 点到右液面。
3. 同时考连续方程：`Q=A_1V_1=A_2V_2`。
4. 同时考局部损失：入口、出口、突扩。
5. 同时考沿程损失：`h_f=f(L/D)V^2/(2g)`。
6. 同时考流态判断：`Re=VD/nu` 或 `Re=rhoVD/mu`。
7. 同时考摩擦系数：层流 `f=64/Re`，湍流用 Colebrook/Moody。
8. 同时考压强点位：A、B 在管内，不能把管内点当自由液面。
9. 同时考表压/绝压、单位换算、速度头使用哪个管段速度。

结论：这道题应放进六页资料的管路母题首位，作为“PVZ + 损失 + Re + 点压强”的总模板。

## 3. 其他必须保留的高价值母题

1. 静水压强/闸门/曲面/浮力  
   目标：压强分布、压力中心、曲面水平/竖直分力、浮力稳定。

2. 控制体动量/弯管/喷嘴/叶片  
   目标：选 CV，列 `sum F = mout Vout - min Vin`，判断支座反力方向。

3. 势流叠加/圆柱绕流/半圆柱升力  
   目标：点源点汇点涡偶极子、镜像法、圆柱表面速度、Bernoulli 压力、升力积分。

4. Laval 喷管/背压/正激波  
   目标：喉部阻塞、面积-马赫数、临界背压、正激波在出口还是管内。

5. 正激波/斜激波/PM 膨胀波  
   目标：判断波型，查表，注意激波后总压下降、PM 不损总压。

6. 层流/Couette/Poiseuille/两层流体  
   目标：先列简化 N-S，再用边界条件定积分常数，最后求速度、流量、剪应力。

7. 边界层/外绕流阻力  
   目标：`Re_x` 判层流/湍流/转捩，算边界层厚度、摩擦阻力、小球/汽车阻力。

8. 量纲分析/相似准则  
   目标：列变量、取基本量纲、做 Pi 群，模型-原型按 Re/Fr/Ma 相似换算。

## 4. 这一步之后怎么做 PDF

`母题标题 -> 真题/教材原题 -> 识别词 -> 第一行落笔 -> 求解顺序 -> 公式链 -> 易错检查 -> 变式`
