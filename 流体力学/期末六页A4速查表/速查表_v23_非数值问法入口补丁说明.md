# 速查表 v23：非数值问法入口补丁说明

## 修改目标

v21/v22 已经把数值题的“题干关键词 -> 模型 -> 公式链”补强；v23 继续补非数值题入口，避免遇到“证明、说明、为什么、判断、比较”时还要在后页分散查找。

## 主要改动

在 `M16 新卷通用定位矩阵` 的 `题目问“求什么”` 中补入：

- 证明 -> 假设 + 方程 + 边界 + 结论；
- 说明/为什么 -> 定义 + 原因 + 后果；
- 判断/比较 -> 先列判据，再代入题给量。

这对应概念题、证明题、判别题的最短过程分链。
