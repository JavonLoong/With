## 二、 逐题深度解析（带考场保分技巧）

### 题 1：光子位置不确定度（早期量子）
* **题面**：光波长为 $\lambda$，已知 $\Delta\lambda/\lambda$，用 $\Delta x\Delta p_x \sim h$ 估算位置不确定度。
* **正确答案**：$\frac{\lambda^2}{\Delta \lambda}$
* **解析**：
  1. 动量为 $p = \frac{h}{\lambda}$。两边微分得到 $\Delta p_x \approx \left| \frac{dp}{d\lambda} \right| \Delta \lambda = \frac{h}{\lambda^2}\Delta\lambda$。
  2. 题目强调用简化的关系式 $\Delta x\Delta p_x \sim h$ 估算，直接代入：
     $$\Delta x \sim \frac{h}{\Delta p_x} = \frac{h}{\frac{h}{\lambda^2}\Delta\lambda} = \frac{\lambda^2}{\Delta\lambda}$$
* **考场保分技巧**：**注意看题目括号里的估算式！** 如果写了“用 $\Delta x\Delta p_x \sim h$ 估算”，答案里绝对不会包含 $\pi$。不需要用 $\hbar/2$，直接把 $h$ 约掉即可。

### 题 2：空间相干性消失的临界距离（光的干涉）
* **题面**：双缝干涉，光源宽度 $b$，缝间距 $d$，光波长 $\lambda$，光源靠近双缝到条纹恰好消失时，光源与缝的距离 $L$。
* **正确答案**：$\frac{bd}{\lambda}$
* **解析**：
  * 光源两端发出的光到达双缝的倾角差为 $\Delta \theta = b/L$。
  * 空间相干性的极限条件为：$\Delta\theta < \frac{\lambda}{d}$。
  * 刚好消失的临界状态就是取等号：$\frac{b}{L} = \frac{\lambda}{d} \implies L = \frac{bd}{\lambda}$。
* **考场保分技巧**：你的草稿纸上写了 $L\lambda = bd$，说明你其实记住了这个比例。空间相干性只考这一种计算，记住 **“角度比值法”** 即可。

### 题 3：望远镜最小分辨角（光的衍射）
* **题面**：望远镜口径 $D$，接收光波长 $\lambda$，可分辨的恒星最小张角。
* **正确答案**：$1.22\lambda/D$
* **解析**：
  * 圆孔衍射的瑞利判据公式：$\theta_{min} = 1.22\frac{\lambda}{D}$。你写得完全正确，送分题。

### 题 4：平晶夹小珠等厚干涉（重点难点）
* **题面**：两块平晶夹 A、B、C 三粒小珠。在 C 上方轻按平晶，条纹变密。已知 A 直径为 $D$，波长为 $\lambda$，求 B、C 的直径。
* **正确答案**：$D_B = D + \frac{\lambda}{2}$ ； $D_C = D - \lambda/2$
* **解析**：
  1. **等厚干涉物理图景**：平晶受三点支撑。每一条条纹对应一个空气膜等厚面，相邻条纹对应的空气厚度差为 $\Delta e = \frac{\lambda}{2}$。
  2. A、B、C 分别在相邻的 2、3、4 级条纹上（看图可知，A 在中间，B 在一侧，C 在另一侧）。所以直径相差一个 $\lambda/2$：
     $$D_B = D \pm \frac{\lambda}{2}, \quad D_C = D \mp \frac{\lambda}{2}$$
  3. **“按压变密”法判定大小**：
     * 轻按 C 上方，相当于强行压低 C 处平晶高度（A、B 作为支撑轴，高度保持不变）。
     * **如果 C 原本较小**：压低 C 使得平晶更加倾斜（倾角变大），条纹变密。这与题意相符！
     * **如果 C 原本较大**：压低 C 会使平晶趋向水平，条纹会变稀。
     * 因此，C 的直径一定比 A 小：$D_C = D - \lambda/2$。
     * 对应地，B 的直径一定比 A 大：$D_B = D + \lambda/2$。
* **考场保分技巧**：
  * **劈尖等厚干涉口诀**：**“按压变密，说明按压点是低谷（小珠子）；按压变稀，说明按压点是高峰（大珠子）。”**
  * 相邻条纹的厚度差固定是 $\lambda/2$。

### 题 5：迈克耳孙干涉仪平移（光的干涉）
* **题面**：移动动臂，条纹移动数 $N$，求动臂平移距离。
* **正确答案**：$\frac{N\lambda}{2}$
* **解析**：
  * 动臂移动 $\Delta d$，由于光是双向往返，光程差改变了 $2\Delta d$。
  * 每移过一条条纹，光程差改变一个波长 $\lambda$，所以 $2\Delta d = N\lambda \implies \Delta d = \frac{N\lambda}{2}$。你写得完全正确！

### 题 6：单缝中央明纹宽度（光的衍射）
* **题面**：缝宽 $a$，波长 $\lambda$，焦距 $f$，求中心明纹宽度。
* **正确答案**：$\frac{2f\lambda}{a}$
* **解析**：
  * 第一级暗纹的角位置满足 $\sin\theta \approx \theta = \pm \frac{\lambda}{a}$。
  * 中央明纹角宽度 $\Delta\theta = 2\theta = \frac{2\lambda}{a}$。
  * 在焦平面上的线宽度为 $\Delta x = f \cdot \Delta\theta = \frac{2f\lambda}{a}$。你写得完全正确！

### 题 7：三块偏振片叠放（光的偏振）
* **题面**：自然光 $I_0$ 通过 $P_1, P_2, P_3$。$P_1, P_2$ 夹角 $30^\circ$，$P_2, P_3$ 夹角 $60^\circ$，$P_1, P_3$ 垂直。求出射光强。
* **正确答案**：$\frac{3}{32}I_0$
* **解析**：
  1. 自然光 $I_0$ 过第一片偏振片 $P_1$：$I_1 = \frac{1}{2}I_0$。
  2. 过 $P_2$：$I_2 = I_1 \cos^2(30^\circ) = \frac{1}{2}I_0 \times \frac{3}{4} = \frac{3}{8}I_0$。
  3. 过 $P_3$：$I_3 = I_2 \cos^2(60^\circ) = \frac{3}{8}I_0 \times \frac{1}{4} = \frac{3}{32}I_0$。
* **物理错题警示**：你的计算完全正确，但写填空题时，**千万不要漏掉光强符号 $I_0$**。

### 题 8：布儒斯特角与折射角（光的偏振）
* **题面**：自然光由空气射向折射率 $n$ 的水面，反射光为完全偏振光，求折射角。
* **正确答案**：$\arctan(1/n)$ （或 $90^\circ - \arctan(n)$）
* **解析**：
  * 反射光为完全偏振光说明入射角为布儒斯特角 $i_B$，此时满足 $\tan i_B = n$。
  * 且此时反射光与折射光垂直，即 $i_B + r = 90^\circ \implies r = 90^\circ - i_B$。
  * 由三角函数性质，$\tan r = \tan(90^\circ - i_B) = \cot i_B = \frac{1}{n} \implies r = \arctan(1/n)$。你写得完全正确！

### 题 9：负晶体双折射的惠更斯作图（作图题）
* **题面**：在负晶体表面用惠更斯作图法画出折射光并标出偏振方向与光名称。
* **正确答案与作图规范**：
  1. **o光（寻常光）**：在晶体中各方向传播速度相同，子波面为**圆**。折射光线为从入射点到圆与公切线切点的连线。其电场振动方向垂直于主截面，在图上用**圆点（$\bullet$）**表示。
  2. **e光（非常光）**：在负晶体中，$v_e > v_o$，其子波面为**椭圆**，且椭圆在圆的外面（切点在光轴方向上）。折射光线为从入射点到椭圆与公切线切点的连线。电场振动方向平行于主截面，在图上用**双向箭头（$\leftrightarrow$）**或短线表示。
* **考场保分技巧**：
  * **一记子波形状**：正晶体（$v_o > v_e$，椭圆在圆内）；负晶体（$v_e > v_o$，椭圆在圆外）。
  * **二记偏振符号**：o光是圆点 $\bullet$（垂直纸面振动），e光是双向箭头 $\leftrightarrow$（平行纸面振动）。

### 题 10：四分之一波片组合（光的偏振）
* **题面**：波片 $P_1$ ($\lambda/4$) 和 $P_2$ ($\lambda/4$) 光轴方向相同。偏振方向与光轴成 $45^\circ$ 的线偏振光过 $P_1$ 后，偏振方向与光轴夹角__________；再过 $P_2$ 后，变成__________光。
* **正确答案**：无固定方向（或“无”、“随时间改变”）； 线偏振
* **解析**：
  1. 线偏振光入射角为 $45^\circ$ 时，分解出的两个垂直分量振幅相等。
  2. 通过第一个四分之一波片 $P_1$ 后，两分量产生 $\pi/2$ 相位差，合成出**圆偏振光**。圆偏振光的电场端点随时间高速旋转，因此**没有固定的偏振方向**。
  3. 由于 $P_1$ 和 $P_2$ 光轴相同，两片延迟量累加：$\frac{\lambda}{4} + \frac{\lambda}{4} = \frac{\lambda}{2}$。这等效于一个**二分之一波片**。
  4. 线偏振光通过二分之一波片后，出射光**依然是线偏振光**（只是振动方向镜像对称到了光轴 of the other side $-45^\circ$）。
* **考场保分技巧**：看到光轴相同的两个波片，**直接把它们的相位延迟相加**！$\lambda/4 + \lambda/4 = \lambda/2$。

### 题 11：黑体辐射的温标换算（早期量子）
* **题面**：人体温度 $T_1$，极大波长 $\lambda_1$，热核爆炸极大波长 $\lambda_2$，求爆炸温度。
* **正确答案**：$\frac{\lambda_1}{\lambda_2} T_1$
* **解析**：
  * 维恩位移定律：$\lambda_{max} T = b$（常数）。
  * 故有 $\lambda_1 T_1 = \lambda_2 T_2 \implies T_2 = \frac{\lambda_1}{\lambda_2} T_1$。
* **考场保分技巧**：黑体辐射只考两个公式：
  * 问**波长与温度关系**用维恩定律：$\lambda T = b$。
  * 问**总辐射能量（辐出度）与温度关系**用斯特藩定律：$M = \sigma T^4$。

### 题 12：康普顿散射波长变化（早期量子）
* **题面**：散射角为 $45^\circ$ 和 $60^\circ$ 的光，其康普顿波长变化之比。
* **正确答案**：$2 - \sqrt{2}$ （或 $\frac{2-\sqrt{2}}{1}$）
* **解析**：
  * 康普顿公式：$\Delta\lambda = \lambda_c(1 - \cos\theta)$。
  * 比例为：$\frac{1 - \cos 45^\circ}{1 - \cos 60^\circ} = \frac{1 - \sqrt{2}/2}{1 - 1/2} = 2 - \sqrt{2}$。

### 题 13：氢原子光谱（原子物理）
* **题面**：$n = 4$ 能级氢原子，辐出光谱最多条数__________；其中属于可见光且波长最短的光子能量为__________。
* **正确答案**：$6$ ； $2.55\text{ eV}$（或 $4.08 \times 10^{-19}\text{ J}$）
* **解析**：
  1. 能级跃迁光谱线数公式：$N = \frac{n(n-1)}{2} = \frac{4 \times 3}{2} = 6$。
  2. 氢原子的可见光发射对应巴耳末系（跃迁到 $n=2$）。从 $n=4$ 出发，属于可见光的有 $3 \to 2$ 和 $4 \to 2$。
  3. 波长最短对应能量最大，故为 $4 \to 2$ 跃迁：
     $$E = E_4 - E_2 = -0.85\text{ eV} - (-3.40\text{ eV}) = 2.55\text{ eV}$$

### 题 14：量子数与轨道角动量（原子物理）
* **题面**：粒子 $n=4$，$m_l = -3$，求 $l$、$m_s$ 以及角动量大小。
* **正确答案**：$3$ ； $\pm 1/2$（或 $-1/2$） ； $2\sqrt{3}\hbar$（或 $\sqrt{12}\hbar$）
* **解析**：
  1. 因为 $|m_l| \le l \le n-1$，已知 $m_l = -3, n=4$，所以角量子数 $l$ 只能为 $3$。
  2. 自旋磁量子数 $m_s$ 恒为 $\pm 1/2$。
  3. 轨道角动量大小公式：$L = \sqrt{l(l+1)}\hbar$。代入 $l=3$：
     $$L = \sqrt{3 \times 4}\hbar = 2\sqrt{3}\hbar$$
* **考场保分技巧**：分清**“轨道角动量大小 ($L = \sqrt{l(l+1)}\hbar$)”**和**“轨道角动量在 z 轴分量 ($L_z = m_l\hbar$)”**。如果问大小，一定要带根号 $\sqrt{l(l+1)}$！
