# 速查表 v21：新卷通用问法链补丁说明

## 修改目标

本版继续执行“不是押往年题，而是换新卷也能靠题干关键词定位模型”的方向。

## 主要改动

1. 在 `M16 新卷通用定位矩阵` 中新增 `题目问“求什么”`：
   - 求压强/水头 -> 静水压或连续+能量；
   - 求力/支反力 -> 先求 `p,V,Q`，再列控制体动量；
   - 求流量 -> 压差、机械能或阻塞给 `Q`；
   - 求面积 -> 由 `M` 接 `A/A*`；
   - 求阻力 -> `Re -> C_f/C_D -> D`；
   - 求时间 -> 连续方程 `A dh/dt = ±Q` 或振动 ODE。

2. 把末页残留的评测导向措辞改成通用考场入口：
   - `低分题专用补丁` 改为 `新卷薄弱题通用补丁`；
   - `低分样本真实处理` 改为 `题干图像/文字不全时`；
   - `剩余低分项考场动作` 改为 `复杂题考场动作`。

3. 清理“固定题号/年份/往年卷”式导航词，保持通用模型定位方向。
