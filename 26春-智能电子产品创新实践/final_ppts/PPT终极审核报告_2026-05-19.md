# PPT终极审核报告

审查对象：

- `NeuroStep_XR智能助行眼镜_结课方案.pptx`
- `MotionTwin_XR动作影分身训练_结课方案.pptx`
- `SenseLimb_智能义肢训练系统_结课方案.pptx`

审查依据：老师结课五段式要求 + 课程四项技术模块 + 技术闭环防守 + 视觉洁癖版清单。

## 总结判断

当前三套 PPT 可以作为“内容草稿”，但不建议直接拿去冲优秀小组。主要问题不是概念不够，而是缺少课程真实证据、成员课程收获页、Q&A 防守页，以及部分封面存在明显文字重叠。

若只选一套继续打磨，建议主推 `MotionTwin`：非医疗、演示感强、评委容易理解，风险边界比 NeuroStep 和 SenseLimb 更好控。但它必须补强 BrainCo/课程证据，否则会被问“这和课程工具到底有什么关系”。

## P0：必须修改，否则容易扣大分

1. 缺独立“课程收获”页
   - 现在三套都把“课程收获”压在最后一页，且没有全体成员姓名/头像/真实个人经历。
   - 必须新增 1 页：每个成员一格，写真实踩坑，如模型破面、3D 打印支撑失败、蓝牙断连、XR 叠加偏移、智能体回答太泛等。

2. 缺课程工具的真实使用证据
   - 三套都没有真实 3D 打印实物照片。
   - 三套都没有讯飞智能体测试对话截图或体验二维码。
   - 建议最少补两张“证据页/证据角标”：一张放拓竹打印照片，一张放讯飞智能体截图。

3. 关键词不够精确
   - PPT 中出现了“混元3D”“拓竹”“讯飞智能体”“BrainCo”“PICO / Apple Vision Pro”。
   - 但未明确出现：`腾讯混元3D`、`拓竹 X1-Carbon`、`讯飞开发者平台`、`星火大模型`、`脑机接口`。
   - 建议在“课程技术如何落地”页直接改成标准术语。

4. 缺 Q&A Backup Slides
   - 三套 PPT 都没有“谢谢聆听”之后的备用页。
   - 至少补 2 页：
     - Backup 1：人体拓扑数据流 / 硬件连接图。
     - Backup 2：讯飞智能体 Prompt / 系统提示词 / 对话截图。

5. 封面视觉有硬伤
   - `MotionTwin` 封面：新增标题和背景图自带标题重叠，主标题区域文字压在一起。
   - `NeuroStep` 封面：同样存在新增标题与背景图内文字叠加的问题。
   - `SenseLimb` 封面相对干净，可保留。
   - 处理方式：封面只保留一套标题。要么裁掉/遮住原图文字，要么不再叠加大标题。

6. 字体未达到清单要求
   - OpenXML 检查显示字体主要是 `Calibri` / 主题字体。
   - 需要统一成中文无衬线：`微软雅黑`；英文数字可用 `Arial` 或 `DIN`。

## P1：强烈建议修改，决定“惊艳程度”

1. 缺“人体拓扑数据流”图
   - 现有架构页是系统框图/卡片图，不够像老师会喜欢的“人机共融闭环”。
   - 建议画一页以人体为中心：眼镜/头环/腕带/踝环/义肢围绕人体，箭头连接到讯飞智能体、XR 反馈、混元3D/拓竹制造。

2. BrainCo 数据说得不够硬
   - 需要明确采集数据：专注度、放松度、疲劳趋势，还是原始 EEG。
   - `MotionTwin` 中 BrainCo 只能做训练状态辅助，不应写成动作识别主传感器。
   - `SenseLimb` 中不要说“读心术”，应说“脑电/专注疲劳作为辅助信号，肌电/姿态负责主要动作意图”。

3. 视觉风格太多“卡片页”
   - 多页是浅灰底 + 六宫格卡片，容易显得像普通学生作业。
   - 技术方案页可以保留卡片，但建议把核心体验页、人体拓扑页、课程证据页做成强视觉页。

4. 预期成效缺可记忆数字
   - 现在多为定性描述。
   - 建议加入“目标用户/场景规模/原型验证指标”：
     - MotionTwin：校园社团、健身房、运动品牌快闪。
     - NeuroStep：社区康复、养老机构、家庭照护。
     - SenseLimb：康复训练、假肢适配、个性化端部验证。

5. “三天内能做什么”要更像真实结课交付
   - 建议明确三天可完成：
     - 讯飞智能体对话 Demo。
     - 混元3D 生成外壳或传感器壳。
     - 拓竹 X1-Carbon 打印一个小部件。
     - XR 视野图/动效视频模拟。

## 三套方案单独评价

### MotionTwin

优势：

- 非医疗，答辩风险低。
- 画面冲击力强，最适合“惊艳全场”。
- 年轻化场景明确：舞蹈、网球、健身、武术、体能训练。

主要问题：

- BrainCo 与动作训练的关系偏弱，必须解释为“专注度/疲劳状态辅助判断”，动作采集主线应是 IMU/腕带/踝环。
- 缺真实课程证据页。
- 封面必须重排。

推荐修改后作为主推方案。

### NeuroStep

优势：

- 社会价值强。
- 与 XR 外部提示、可穿戴、AI 语音教练的结合逻辑成立。
- 对“冻结步态不是害怕”解释较准确。

主要问题：

- 医疗边界要非常谨慎，不能暗示治疗效果。
- 封面文字重叠严重。
- 需要补“医生/康复训练辅助，不替代诊断治疗”的防守页。

适合作为社会价值型备选。

### SenseLimb

优势：

- 四项课程技术覆盖最完整。
- 智能义肢 + XR 训练 + 3D 定制部件的闭环最清楚。
- 封面视觉最好。

主要问题：

- 医疗/工程复杂度最高，Q&A 风险最高。
- 需要明确它是“义肢训练系统/课程原型”，不是承诺做出正式义肢。
- 必须补肌电、BrainCo、XR、3D 打印之间的因果链路。

适合作为技术覆盖最强的备选。

## 建议的最终页序：以 MotionTwin 为例

1. 封面：MotionTwin XR 动作影分身训练
2. 项目背景：训练正在从视频跟练走向实时反馈
3. 当前技术问题：动作差异不可见，反馈不及时
4. 产品设想：三层动作影分身
5. 人体拓扑数据流：人体 + 可穿戴 + XR + 智能体 + 3D 制造
6. 核心体验：影分身、热区、节奏线、语音纠错
7. 课程技术落地：腾讯混元3D / 拓竹 X1-Carbon / 讯飞开发者平台 / BrainCo / PICO
8. 课程证据：智能体测试对话 + 体验二维码
9. 课程证据：3D 打印实物 / 打坏也展示
10. 三天原型计划：可展示 Demo 怎么做
11. 预期成效与市场应用
12. 课程收获：全体成员真实分工与踩坑
13. 谢谢聆听
14. Backup：硬件连接图
15. Backup：智能体 Prompt 和防追问解释
