把偏振题变成四个固定动作

你不需要先懂所有物理细节。考试里先识别模型，再按对应公式走。偏振这一章最常见就四类：偏振片、布儒斯特角、双折射 o/e 光、旋光。

自然光先除 2 线偏振再乘 cos² 布儒斯特反射光完全偏振 方解石分成 o/e 两束 旋光角正比于长度和浓度
偏振片第一片遇自然光：I0/2。后面每片：乘 cos²θ。
布儒斯特tan iB = n2/n1；反射光是线偏振。
双折射方解石把自然光分成 o 光和 e 光，偏振方向互相垂直。
旋光α = [α]lc；交叉尼科耳最亮要转 90°。

1. 偏振片：先判断光是不是自然光

最短判断句

自然光第一次过偏振片，强度变一半；从第二片开始，光已经是线偏振光，只能用马吕斯定律。

自然光过第一片：I1 = I0 / 2 线偏振过偏振片：I2 = I1 cos²θ

θ 是“入射到这一片前的偏振方向”和“这一片透振方向”的夹角。

  1. 1题目说自然光：第一片固定除以 2。
  2. 2题目给两个偏振片夹角：直接用这个角，不用 90° 减。
  3. 3后面每加一片，就乘一次 cos²θ。

快测：自然光过两个偏振片，夹角 45°，出射强度？

2. 布儒斯特角：让反射光变纯

人话版

自然光照到玻璃上，反射光一般只是“有点偏振”。如果入射角刚好等于布儒斯特角，反射光会变成完全线偏振光。

tan iB = n2 / n1 iB + r = 90°

iB 永远从法线量起。n1 是入射侧，n2 是折射侧。

布儒斯特角的反射光振动方向：垂直于入射面。图画在纸面上时，通常就是垂直纸面。

tan iB = n2/n1

3. 方解石双折射：一束光变两束

先不要纠结图，先记考试判断

方解石这类晶体会把入射自然光分成两束：o 光和 e 光。它们都是线偏振光，而且偏振方向互相垂直。

o 光：no 固定，像普通折射 e 光：ne 随方向变，常被光轴影响 o 光与 e 光：偏振方向互相垂直

最容易误解

光轴不是光线。它是晶体内部的特殊方向，像木头纹理。e 光会受这个方向影响。

快测：方解石中分出的 o 光和 e 光，一定可以先判断什么？

4. 旋光：偏振方向被转了一个角

这一页对应你截图里的“旋光与浓度/长度”

有些物质会把线偏振光的振动方向转一个角度。这个角度叫旋光角 α。

溶液旋光：α = [α] l c 比例题：α1/α2 = l1 c1 / (l2 c2) 石英旋光率：ρ = α / l 交叉尼科耳最亮：ρ l = 90° + 180°k

l 是长度，c 是浓度，[α] 是比旋光度。单位必须配套：题目给 °/mm，就用 mm。

三个计算器

溶液旋光

α = [α]lc

交叉尼科耳最亮

lmin = 90°/ρ

左右圆偏振折射率

ρ = 180(nL-nR)/λ，单位 °/m

5. 限时自测：看到题目先选模型

题型 1：自然光过两个偏振片，夹角 45°

模型：偏振片 + 马吕斯定律。

I = (I0/2) cos²45° = I0/4
题型 2：入射角等于布儒斯特角，问反射光性质

模型：布儒斯特角。

反射光 = 完全线偏振光 振动方向 = 垂直入射面
题型 3：方解石、光轴、o 光/e 光

模型：双折射。先写：分成 o/e 两束，偏振方向互相垂直。再看图判断传播方向是否不同。

题型 4：两个互相正交尼科耳之间放旋光片，求最小厚度

起偏器和检偏器互相正交，本来完全不透。要最亮，就让旋光片把偏振方向转到检偏器方向。

最亮条件：ρl = 90° + 180°k 最小厚度：lmin = 90° / ρ 例：ρ = 21.75°/mm lmin = 90 / 21.75 = 4.14 mm
