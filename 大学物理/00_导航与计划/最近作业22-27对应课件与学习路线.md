## 2. 每章要学到什么程度

### 编号 22：光的干涉

题目覆盖：

- 22.2：双缝干涉，条纹间距反推波长。
- 22.3：劳埃德镜，镜边缘到第一明纹距离。
- 22.10：激光干涉装置，条纹间距、衬比度。
- 22.14：二氧化硅薄膜，等厚条纹测膜厚。
- 22.19：MgF2 增透膜厚度。
- 22.22：迈克耳孙干涉仪测波长。

必须掌握的动作：

1. 画出两束相干光的光路。
2. 写光程差，不只写几何路程差。
3. 先判断半波损失，再写明暗条件。
4. 双缝用 `delta ≈ d x / D`，薄膜用 `2 n h` 类光程差，迈克耳孙用 `2 Delta L = N lambda`。
5. 看到“动镜移动、条纹吞吐”必须立刻想到因子 2。

### 编号 23：光的衍射

题目覆盖：

- 23.1：单缝中央明纹宽度。
- 23.6：微波天线中央波束角宽。
- 23.9：圆孔/望远镜分辨率。
- 23.13：双缝干涉加单缝衍射包络。
- 23.16：光栅光谱，估光栅常数和缝宽。
- 23.18：天线阵列，极大极小方向。
- 23.20：X 射线晶体衍射。
- 23.21：电子衍射，和第 26 章德布罗意波交叉。

必须掌握的动作：

1. 先分类：单缝、光栅、圆孔分辨、晶体布拉格、阵列干涉。
2. 单缝暗纹用 `a sin theta = k lambda`，中央明纹全宽要乘 2。
3. 光栅主极大用 `d sin theta = k lambda`，不要把 `d` 和缝宽 `a` 混掉。
4. 分辨率用瑞利判据 `theta_min = 1.22 lambda / D`。
5. 布拉格公式用 `2 d sin phi = k lambda`，先确认题里的角是掠射角还是法线角。

### 编号 24：光的偏振

题目覆盖：

- 24.1、24.2：马吕斯定律，多片偏振片。
- 24.4、24.5、24.8：反射/折射偏振，布儒斯特角。
- 24.9、24.10：方解石晶体，o 光/e 光传播方向和振动方向。
- 24.11、24.13：四分之一波片、偏振态判断。
- 24.15：旋光率。
- 24.16：偏振梯度效应，正交分量相位差沿空间变化。

必须掌握的动作：

1. 光强题先判断入射光是自然光还是线偏振光。自然光过第一片先除以 2。
2. 多片偏振片按相邻夹角连乘 `cos^2 theta`。
3. 布儒斯特角用 `tan i_B = n2 / n1`，且 `i_B + r = 90°`。
4. 波片题先把入射线偏振分解到快慢轴，再看相位差。
5. 四分之一波片只有在两正交分量振幅相等且相位差变成 `pi/2` 时才得到圆偏振。

### 编号 26：波粒二象性

题目覆盖：

- 26.4、26.6：黑体辐射，斯特藩-玻尔兹曼定律、维恩位移定律。
- 26.11：光电效应，最大初动能、截止电压、红限波长。
- 26.15：康普顿散射，反冲电子动能。
- 26.22：德布罗意波，相速度/群速度。
- 26.30：粒子在三维盒子中的零点能，和第 27 章势阱衔接。

必须掌握的动作：

1. 黑体题分清 `lambda_m T = b` 和 `M = sigma T^4`。
2. 光电效应用 `h nu = W + K_max = W + e U_s`。
3. 康普顿散射用 `Delta lambda = lambda_C(1 - cos phi)`，电子动能等于光子能量损失。
4. 德布罗意波用 `lambda = h / p`，电子加速题再接 `p = sqrt(2meU)`。
5. 概率波和不确定关系只要能说清 `Psi` 不是概率，`|Psi|^2` 才是概率密度。

### 编号 27：薛定谔方程与无限深方势阱

题目覆盖：

- 27.2：一维无限深势阱，基态能量和热运动能量量级比较。
- 27.3：无限深斜底势阱中 `n=5` 激发态波函数形状。
- 27.6：不同能态波函数的正交性。
- 27.8：从驻波条件推出无限深势阱能级。
- 27.11：氢分子振动近似为量子谐振子，能级差和发射光子。

必须掌握的动作：

1. 会写含时薛定谔方程和定态薛定谔方程。
2. 无限深势阱先写边界条件 `psi(0)=psi(a)=0`。
3. 能级必须从 `k = n pi / a` 推出，不允许 `n=0`。
4. 会用 `psi_n = sqrt(2/a) sin(n pi x/a)` 和 `E_n = n^2 h^2/(8ma^2)`。
5. 叠加态测量概率用 `|c_n|^2`，平均值用概率加权。
6. 谐振子能级是等间隔，和无限深势阱的 `n^2` 不同。

## 4. 每章固定学习流程

每章不要直接从作业硬算，按下面四步走：

1. 先读章节包的 `章节一句话总纲`、`公式血缘表`、`典型题型表`、`易错点清单`。
2. 再打开原课件，只看与本章作业题号对应的小节和例题。
3. 闭卷做作业题，第一遍只要求写出“模型、主公式、条件、单位检查”。
4. 对照课件或我后续给的解答，把错题归因到四类之一：模型认错、公式条件漏掉、角度/单位错误、代数计算错误。

## 5. 判断“学会了”的最低标准

如果每章都能做到下面程度，就可以开始刷题巩固：

- 22：看到干涉装置，能画出两束光路并写光程差。
- 23：看到衍射题，能先分类到单缝、光栅、圆孔分辨、布拉格。
- 24：看到偏振题，能跟踪光矢量方向、投影和相位差。
- 26：看到量子旧实验，能识别黑体、光电、康普顿、德布罗意并写主公式。
- 27：看到势阱题，能从边界条件推出波函数和能级。
