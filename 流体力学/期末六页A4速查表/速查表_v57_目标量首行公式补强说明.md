# v57 修正说明：目标量首行公式补强

本轮目标：补强新卷使用时的反向检索入口。即题目只问“求某个量”时，先知道第一行该写哪类方程。

已补入 M26：

- 求 `p`：先判静水 / Bernoulli / 等熵 / 激波。
- 求 `F`：先判控制体动量 / 压力积分 / 阻力系数。
- 求 `Q` 或 `\dot m`：先连续，粘性查 `lambda` 或 H--P，可压查 `M`。
- 求 `M`：先等熵压比 / 面积比 / 波表。
- 求 `D`：先判湿表面积 `C_f` 或迎风面积 `C_D`。
- 求时间：先写 `A dh/dt = ±Q`。
