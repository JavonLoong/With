## 2. 无脑学习顺序

1. 先打开原题截图版 PPT，每一页先只看题目截图，不看答案。
2. 回到本清单，找到对应知识点编号。
3. 按“识别信号”判断模型，按“第一行必须写”写出公式。
4. 对着“做题动作”一步一步算，不允许跳过半波损失、角度定义、单位换算。
5. 做完作业原题后，立刻做同一知识点的题库原题。
6. 错题只归入四类：模型认错、条件漏掉、角度/单位错、代数错。

最重要的总原则：

```text
光学题：先判模型，再写光程差/相位差/投影关系。
量子题：先判实验或势能模型，再写能量、动量、波函数或边界条件。
```

## 5. 第 22 章：光的干涉必须掌握到的程度

总图像：

```text
确定哪两束光相遇
-> 写光程差 delta
-> 转成相位差 Delta phi
-> 判断半波损失
-> 套明暗条件
-> 解释条纹位置、移动、衬比度
```

必会公式：

| 模块 | 公式 | 条件 |
|---|---|---|
| 相位差 | `Delta phi = 2 pi delta/lambda` | lambda 用真空波长，delta 是光程差 |
| 双缝 | `delta = d sin theta ≈ d x/D` | 远屏小角 |
| 双缝条纹间距 | `Delta x=lambda D/d` | 相邻同类条纹 |
| 插片 | 附加光程 `(n-1)t` | 一路单程通过薄片 |
| 薄膜正入射 | 几何光程差 `2ne` | 半波损失另判 |
| 劈尖 | `Delta e=lambda/(2n)`，`L=lambda/(2n theta)` | theta 用弧度 |
| 牛顿环 | 空气膜反射暗环 `r_k=sqrt(k R lambda)` | 反射观察中央暗 |
| 迈克耳孙 | `2 Delta d=N lambda` | 动镜位移导致往返光程变 |

必须能解释的坑：

| 坑 | 正确说法 |
|---|---|
| “相位差 3pi，光程是不是 1.5n lambda？” | 光程差 `delta=(Delta phi/2pi)lambda=1.5lambda`；若问介质中几何路程，才是 `1.5lambda/n` |
| “薄膜增透为什么取 `2nh=lambda/2`？” | 反射增透要让两束反射光相消。空气-MgF2-玻璃中两次反射都半波损失，彼此不额外差 pi，所以传播光程要差半波长来相消 |
| “半波损失会不会把明暗条件互换？” | 会。两束反射光相差一次半波损失时，反射明暗条件和无半波损失时互换 |
| “迈克耳孙为什么乘 2？” | 镜子移动 `Delta d`，该臂去程和回程都改变，总光程变 `2 Delta d` |
| “衬比度后半公式怎么来？” | `Imax=(A1+A2)^2`，`Imin=(A1-A2)^2`，代入 `V=(Imax-Imin)/(Imax+Imin)` 得 `2A1A2/(A1^2+A2^2)` |

第 22 章达标自测：

```text
1. 给相位差，能反推光程差。
2. 给双缝 D、d、Delta x，能反推 lambda。
3. 给插片 n、e，能写旧中央的光程差和条纹移动方向。
4. 给 n1/n2/n3，能判断两束反射光半波损失差。
5. 给动镜移动量和条纹数，能算迈克耳孙波长。
```

## 6. 第 23 章：光的衍射必须掌握到的程度

总图像：

```text
单缝：一条缝内部各点相干叠加
光栅：多缝之间主极大 + 单缝衍射包络
圆孔：艾里斑限制分辨率
晶体：晶面反射波满足布拉格加强
```

核心符号：

| 符号 | 意思 |
|---|---|
| `a` | 单缝宽度，决定单缝包络宽度和单缝暗纹 |
| `d` | 光栅常数或两缝中心距，决定主极大位置 |
| `k` | 光栅主极大级次、布拉格衍射级次 |
| `m` | 单缝暗纹级次，缺级题常用它和 k 区分 |
| `N` | 缝数，决定主极大强度和细锐程度 |
| `lambda` | 波长，X 射线/电子题要看单位 nm、A、m |

必会公式：

| 模块 | 公式 | 条件 |
|---|---|---|
| 单缝暗纹 | `a sin theta=k lambda`，`k=1,2,...` | 正入射，夫琅禾费衍射 |
| 中央明纹全宽 | `Delta x0=2 f lambda/a` | 焦平面，小角 |
| 光栅主极大 | `d sin theta=k lambda` | 正入射光栅 |
| 最高级次 | `k_max=floor(d/lambda)` | 还要删去缺级和角域外级次 |
| 缺级 | `k=m d/a` | 主极大落在单缝暗纹上 |
| 圆孔分辨 | `theta_min=1.22 lambda/D` | 圆孔孔径 D |
| 布拉格 | `2d sin phi=k lambda` | phi 是掠射角 |
| 多缝中央强度 | `I_N=N^2 I_1` | N 个等振幅同相叠加 |

必须能解释的坑：

| 坑 | 正确说法 |
|---|---|
| “为什么双缝以前不强调每条缝宽 a？” | 理想杨氏双缝把缝当点光源，只算两缝中心距 d；真实双缝/光栅中缝宽 a 会产生单缝包络，所以第 23 章才同时出现 a 和 d |
| “`d=lambda/sin theta` 为什么？” | 从相邻晶面/缝到观察方向的光程差等于一个波长：`d sin theta=lambda` 或布拉格中 `2d sin phi=lambda`，再移项 |
| “第一极大为什么乘 1？” | 第一级就是级次 `k=1`。`k=0` 是中央/镜面方向，第一非零极大用 `k=1` |
| “缺级里 d/a 最大值怎么想？” | 缺级序列是 `k=m d/a`。若缺 `4,8,12,...`，最大基本比值是 `d/a=4` |
| “中央明纹宽为什么乘 2？” | 中央亮纹从左第一暗纹到右第一暗纹，是两个半宽 |

第 23 章达标自测：

```text
1. 单缝中央明纹宽度题，能先写两侧第一暗纹再乘 2。
2. 光栅最高级次题，能用 sin theta 不超过 1 取整数。
3. 缺级题，能把 a 和 d 分别放进单缝暗纹与光栅主极大。
4. 布拉格题，能判断给的是掠射角还是法线角。
5. N 缝强度题，能说出振幅 N 倍，强度 N^2 倍。
```

## 7. 第 24 章：光的偏振必须掌握到的程度

总图像：

```text
偏振研究光矢量方向
-> 偏振片筛选方向
-> 界面按 s/p 分量选择
-> 晶体按 o/e 或快慢轴分解
-> 相位差决定线、圆、椭圆偏振
```

必会公式：

| 模块 | 公式 | 条件 |
|---|---|---|
| 自然光过第一片 | `I=I0/2` | 入射必须是自然光 |
| 马吕斯定律 | `I=Iin cos^2 alpha` | 入射是线偏振光 |
| 多片偏振片 | `Iout=I0/2 * product cos^2(theta_i)` | theta_i 是相邻通光方向夹角 |
| 偏振度 | `P=(Imax-Imin)/(Imax+Imin)` | 检偏器旋转得到极值 |
| 布儒斯特角 | `tan iB=n2/n1` | 反射光完全偏振 |
| 布儒斯特几何 | `iB+r=90 deg` | 只在布儒斯特角成立 |
| 波片相位差 | `Delta phi=2pi(n_o-n_e)d/lambda` | 正入射，沿主轴分解 |
| 四分之一波片 | `|Delta phi|=pi/2` | 特定波长 |
| 二分之一波片 | `|Delta phi|=pi` | 线偏振方向关于光轴翻折 |

必须能解释的坑：

| 坑 | 正确说法 |
|---|---|
| “两片夹角用 45 度还是 90 度减 45 度？” | 题目说两偏振化方向成 45 度，就直接用 45 度；只有题目给的是和垂直方向/阻光方向夹角时才换 |
| “第二片后为什么不再乘 1/2？” | 第一片后已经是线偏振光，后面按马吕斯定律投影，不再按自然光减半 |
| “强度为什么是 cos^2？” | 电场振幅投影乘 `cos alpha`，强度正比振幅平方，所以乘 `cos^2 alpha` |
| “四分之一波片一定变圆偏振吗？” | 不是。只有两个正交分量振幅相等，且相位差为 `pi/2`，才是圆偏振 |
| “布儒斯特角里的 90 度是谁和谁？” | 是反射光线与折射光线互相垂直，因此 `iB + r = 90 deg` |

第 24 章达标自测：

```text
1. 自然光通过两片偏振片成 45 度，能算 I0/4。
2. 三片偏振片题，能按相邻夹角逐片连乘。
3. 布儒斯特角题，能画出入射、反射、折射并求折射角。
4. 波片题，能先把入射线偏振分解到快慢轴。
5. 能区分自然光、线偏振光、圆偏振光、部分偏振光的检偏表现。
```

## 8. 第 26 章：波粒二象性必须掌握到的程度

总图像：

```text
经典物理解释不了黑体、光电、康普顿
-> 光有能量量子和动量
-> 实物粒子也有德布罗意波
-> 波函数是概率幅
-> 不确定关系限制经典轨道
```

必会公式：

| 模块 | 公式 | 条件 |
|---|---|---|
| 光子能量 | `E=h nu=hc/lambda` | 光子 |
| 光子/物质波动量 | `p=h/lambda` | 光子和德布罗意关系 |
| 黑体峰值 | `lambda_m T=b` | 黑体 |
| 总辐出度 | `M=sigma T^4` | 黑体 |
| 光电效应 | `h nu=W+Kmax=W+e Us` | 一个电子吸收一个光子 |
| 红限 | `nu0=W/h`，`lambda0=hc/W` | 刚好逸出 |
| 康普顿 | `Delta lambda=lambda_C(1-cos phi)` | 近似自由电子散射 |
| 电子加速波长 | `lambda=h/sqrt(2meU)` | 非相对论电子 |
| 布拉格接口 | `2d sin phi=k lambda` | 电子衍射/X 射线衍射 |
| 不确定关系 | `Delta x Delta p >= hbar/2` | 同一方向 |

必须能解释的坑：

| 坑 | 正确说法 |
|---|---|
| “光强变大，光电子最大动能会变大吗？” | 不会。最大动能由频率决定；光强主要改变单位时间光电子数 |
| “截止电压是能量吗？” | 不是。方程里是电子电荷乘电压 `e Us` |
| “康普顿波长改变量和入射波长有关吗？” | 改变量只与散射角有关：`lambda_C(1-cos phi)` |
| “电子加速电压变 4 倍，波长怎么变？” | `lambda` 与 `1/sqrt(U)` 成正比，所以变为 1/2 |
| “不确定关系是仪器不够好吗？” | 不是，是微观状态本身的限制 |

第 26 章达标自测：

```text
1. 能用维恩定律和斯特藩定律分别处理峰值波长和总辐射。
2. 能用光电效应方程处理逸出功、截止电压、红限频率。
3. 能用康普顿公式判断散射角 0 度和 180 度的极限。
4. 能从加速电压求电子德布罗意波长。
5. 能用不确定关系算出 Delta p，并给出轨道能不能近似成立的结论。
```

## 9. 第 27 章：薛定谔方程与势阱必须掌握到的程度

总图像：

```text
波函数 Psi 描述量子态
-> |Psi|^2 给概率密度
-> 薛定谔方程给时间演化
-> 定态方程给能量本征值和本征函数
-> 无限深势阱用边界条件筛出离散能级
-> 叠加态测量概率由系数模方给出
```

必会公式：

| 模块 | 公式 | 条件 |
|---|---|---|
| 含时薛定谔方程 | `i hbar partial Psi/partial t = Hhat Psi` | 非相对论 |
| 哈密顿算符 | `Hhat = -hbar^2/(2m) nabla^2 + U` | 坐标表象 |
| 定态方程 | `Hhat Phi = E Phi` | U 不显含时间 |
| 时间因子 | `Psi_E=Phi_E exp(-iEt/hbar)` | 能量本征态 |
| 无限深势阱波函数 | `psi_n=sqrt(2/a) sin(n pi x/a)` | `0<x<a` |
| 无限深势阱能级 | `E_n=n^2 h^2/(8ma^2)` | `n=1,2,...` |
| 归一化 | `integral |Psi|^2 dx=1` | 全空间或允许区间 |
| 区间概率 | `P=integral |Psi|^2 dx` | 波函数已归一化 |
| 能量测量概率 | `P(E_n)=|c_n|^2` | 已展开成本征态 |
| 平均能量 | `<E>=sum |c_n|^2 E_n` | 离散能级 |
| 谐振子 | `E_n=(n+1/2)hbar omega` | 一维量子谐振子 |

必须能解释的坑：

| 坑 | 正确说法 |
|---|---|
| “Psi 是概率吗？” | 不是。`|Psi|^2` 才是概率密度 |
| “定态是不是波函数不动？” | 定态有时间相位，概率密度不随时间变 |
| “势阱能不能 n=0？” | 不能。`n=0` 会让波函数处处为 0，不是物理态 |
| “最低能量为什么不是 0？” | 空间限制导致动量不可能为 0，是零点能 |
| “平均能量是不是所有能级普通平均？” | 不是，要按概率 `|c_n|^2` 加权 |

第 27 章达标自测：

```text
1. 能写出含时方程、定态方程和哈密顿算符。
2. 能从边界条件推出无限深势阱的 psi_n 和 E_n。
3. 能说明 n 从 1 开始，最低能量不为 0。
4. 给一个叠加态，能写随时间演化。
5. 给区间，能积分 |psi|^2 求概率。
6. 能区分无限深势阱 n^2 能级和谐振子等间隔能级。
```

## 12. 错题定位表

| 错题表现 | 归因 | 修正动作 |
|---|---|---|
| 公式一上来就写错 | 模型认错 | 回到判别树，只写关键词和模型，不算数 |
| 答案差一个 2 | 往返、中央全宽、半波条件没判 | 检查迈克耳孙、单缝中央宽、薄膜反射 |
| 答案差一个 n | 光程和几何路程混了 | 先写 `sum n r`，不要直接用几何路程 |
| 角度用错 | 掠射角/法线角/偏振方向夹角混了 | 画图，标清角是和谁夹的 |
| 光强差平方 | 把振幅和强度混了 | 振幅先投影/叠加，强度再平方 |
| 量子题单位错 | eV/J、nm/m、h/hbar 混了 | 先统一 SI 或统一 eV，不要混用 |
| 概率大于 1 | 没归一化或积分错 | 先做 `integral |Psi|^2 dx=1` |

## 13. 最终掌握标准

如果你能做到下面 10 条，最近这几次作业覆盖的核心题型就基本打通：

1. 看到任意干涉题，能先画两束光并写光程差。
2. 看到薄膜题，能先数半波损失再写明暗条件。
3. 看到迈克耳孙题，能第一时间写出 `2 Delta d=N lambda`。
4. 看到衍射题，能分清单缝、光栅、圆孔、布拉格。
5. 看到光栅题，能分清 `a`、`d`、`k`、`m`。
6. 看到偏振片题，能判断第一片是否要除以 2，后面是否用 `cos^2`。
7. 看到布儒斯特角题，能画出反射线和折射线互相垂直。
8. 看到光电/康普顿/德布罗意题，能写出对应的能量或动量守恒入口。
9. 看到波函数题，能先写 `|Psi|^2`、归一化和积分区间。
10. 看到无限深势阱题，能从边界条件推出 `psi_n` 和 `E_n`，并拒绝 `n=0`。

这份清单的使用结果不是“看懂”，而是“每个知识点至少能闭卷写出第一行、主公式、条件、对应原题”。只有做到这个程度，PPT 里的截图题才真正变成可迁移的题型。
