# 💡 答疑：PDF 资料中“小球低 Re 终速”与“管内层流三方向”的排版与物理界线

看到您发送的最新 PDF 截图，我完全明白您为什么会把这两个公式联想在一起了！

在您的复习资料中，**“小球低 Re 终速”** 和 **“易错 管内层流三方向”** 是**紧挨着排版在一起的**（前一个讲小球，后一个紧接着就是管内层流，且都含有速度、粘度和直径的组合）。

为了帮您在考场上彻底把这两块内容割裂开，不混淆，我们对这两个相邻板块的物理界线做一次清爽的对比：

---

## 🔍 板块一：小球沉降（外流/绕流）—— 对应您的截图“前一部分”

* **核心标题**：`步骤 小球低 Re 终速` / `小球沉降终速总入口：低速 Stokes / 给 CD 二次阻力`
* **适用对象**：在水中自由下沉的球体颗粒（例如第二题的铝球）。
* **核心思想**：列受力平衡方程：
  $$G - F_B - D = 0 \quad (\text{重力 } - \text{浮力 } - \text{阻力 } = 0)$$
* **对应公式**：
  * **低速 (Stokes)**：$U = \frac{(\rho_s - \rho)gd^2}{18\mu}$ （没有根号，粘度 $\mu$ 在分母）
  * **高速 (给 $C_D$)**：$U = \sqrt{\frac{4(\rho_s - \rho)gd}{3C_D\rho}}$ （有根号，不含粘度 $\mu$）

---

## 🔍 板块二：管内层流（内流）—— 对应您的截图“后一部分”

* **核心标题**：`易错 管内层流三方向`
* **适用对象**：流体（水或油）在**固定管道内部**进行层流流动。
* **核心思想**：计算流体在直管中流过时，由于摩擦引起的沿程**压强变化率（压力梯度）**。
* **对应公式（哈根-泊肃叶公式的变体）**：
  * **水平管**：$$\frac{dp}{dx} = -\frac{32\mu V}{d^2}$$
  * **向上管**：$$-\frac{dp}{dz} = \frac{32\mu V}{d^2} + \rho g$$
  * **向下管**：$$-\frac{dp}{dz} = \frac{32\mu V}{d^2} - \rho g$$
  （这里的 $d$ 指的是**管道的直径**，而 $V$ 是**管内流速**。$dp/dx$ 是压强降）。

---

## 🎯 总结（20字极简避坑指南）：
* **为什么这两个公式紧挨着排版？**
  * **解答**：它们都属于层流流动，但一个是外流，一个是内流。
* **考场上如何一秒区分它们？**
  * **解答**：问小球速度用下沉公式；问管道压降用压降公式。
