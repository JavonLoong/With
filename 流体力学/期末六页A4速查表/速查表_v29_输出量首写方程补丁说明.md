# 速查表 v29：输出量/首写方程补丁说明

## 改动目的

v28 已经偏向通用题型识别，但首页仍有一块“常见题归类”偏章节记忆。v29 把这块改成“题目要求量 -> 第一行该写什么方程 -> 最后检查什么”，用于陌生新卷快速下笔拿过程分。

## 改动位置

- P1 `要求量 -> 首写方程 -> 检查点`

## 新增覆盖

- 求 `p/H`：静水压链或能量方程
- 求 `Q/V/t`：连续、能量、H--P、阻塞或变水位微分方程
- 求 `F/R/M`：控制体动量/动量矩
- 求 `dot m,A,M`：状态方程、等熵、面积--Ma
- 求 `D/delta` 或证明：Re 判型、阻力/边界层、假设-方程-边界-结论
