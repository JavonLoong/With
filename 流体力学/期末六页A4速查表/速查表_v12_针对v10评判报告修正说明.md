## v12 做了什么

v12 不再继续加老师课件照片，也没有扩大题图占地。主要改动是替换 M20：

| v10 报告暴露的低分项 | v12 对应补强 |
|---|---|
| 流函数存在性、物理意义不会证明 | M20 加入二维不可压推出 `u=psi_y, v=-psi_x`，以及 `q'=psi_2-psi_1` |
| 速度势、单值性、多连通域概念不稳 | M20 加入 `curl V=0 -> V=grad phi`，以及点涡/环量导致势函数多值 |
| Kelvin 定理、Lagrange 定理不会串 | M20 加入 Kelvin 环量守恒推出无旋保持无旋的三步证明 |
| 涡线、涡管、涡通量、环量关系薄弱 | M20 加入涡线方程、涡通量、Stokes 定理、涡管强度守恒 |
| Helmholtz 涡定理只会背标题 | M20 加入条件和三条可直接写的结论 |
| 相似律/Buckingham Pi 证明题容易丢步骤 | M20 加入几何/运动/动力相似，以及 Buckingham Pi 的标准构造流程 |
| 边界层积分推导只会套公式 | M20 加入 `delta^*`、`theta`、零压梯度和有压梯度动量积分入口 |
| 水击/水波只会概念不会落公式 | M20 加入 `Delta p=rho a Delta V`、`Fr`、深水波相速入口 |
