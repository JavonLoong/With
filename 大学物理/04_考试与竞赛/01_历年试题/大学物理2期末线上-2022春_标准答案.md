## 一、填空题

1. 折射角：`33.7°`

   反射光完全偏振时满足布儒斯特定律：`tan i_B = n₂/n₁ = 1.50`。  
   `i_B = 56.3°`，且 `i_B + r = 90°`，所以 `r = 33.7°`。

2. 穿透系数：`增大`

   势垒越窄，隧穿概率越大。

3. 缝距：`5.0×10⁻⁴ m = 0.50 mm`

   `Δx = λD/d`，所以  
   `d = λD/Δx = 540×10⁻⁹×2.5/(2.70×10⁻³) = 5.0×10⁻⁴ m`。

4. 谱线最多条数：`6 条`；可见光谱线中波长最短光子的能量：`2.55 eV = 4.08×10⁻¹⁹ J`

   `N = n(n−1)/2 = 4×3/2 = 6`。  
   可见光巴耳末系最短为 `4 → 2`：  
   `E = 13.6(1/2² − 1/4²) eV = 2.55 eV`。

5. 掠射角：`30°`

   布拉格公式：`2d sinφ = kλ`。  
   `2×1.68 sinφ = 2×0.84`，所以 `sinφ = 0.5`，`φ = 30°`。

6. 动臂反射镜移动距离：`3.22×10⁻⁴ m = 0.322 mm`

   迈克耳孙干涉仪：`2Δd = Nλ`。  
   `Δd = 1204×534.9 nm / 2 = 3.22×10⁻⁴ m`。

7. 反冲电子动能：`hc(1/λ − 1/λ′)`

   康普顿散射中能量守恒：  
   `K_e = hν − hν′ = hc/λ − hc/λ′`。

8. 中央明纹宽度：`3.28 mm`

   单缝中央明纹全宽：`Δx = 2fλ/a`。  
   `Δx = 2×0.60×546.1×10⁻⁹/(0.20×10⁻³) = 3.28×10⁻³ m`。

9. 遏止电压：`2.5 V`；红限频率：`3.97×10¹⁴ Hz`

   `eU_s = K_max`，所以 `U_s = 4.0×10⁻¹⁹/(1.60×10⁻¹⁹) = 2.5 V`。  
   `ν = c/λ = 3.0×10⁸/(3000×10⁻¹⁰) = 1.0×10¹⁵ Hz`。  
   `ν₀ = ν − K_max/h = 1.0×10¹⁵ − 4.0×10⁻¹⁹/(6.63×10⁻³⁴) = 3.97×10¹⁴ Hz`。

10. 人离汽车距离：`8.94×10³ m ≈ 8.9 km`

    瑞利判据：`θ_min = 1.22λ/D`。  
    两灯张角 `θ ≈ s/L`，所以  
    `L = sD/(1.22λ) = 1.20×5.0×10⁻³/(1.22×550×10⁻⁹) = 8.94×10³ m`。

11. 总辐射本领增大为原来的：`5.06 倍`

    维恩位移定律：`λ_mT = b`，所以 `T₂/T₁ = 0.6/0.4 = 1.5`。  
    斯特藩定律：`M ∝ T⁴`，所以 `M₂/M₁ = 1.5⁴ = 5.06`。

12. 最小刻线总数：`1216 条`

    光栅分辨本领：`R = λ/Δλ = kN`。  
    `N ≥ 656.3/(3×0.18) = 1215.37`，所以至少 `1216` 条。

13. `l = 2`，`m_s = ±1/2`；轨道角动量大小：`√6 ℏ`

    因为 `m_l = −2`，必须有 `l ≥ 2`；又 `n=3` 时 `l = 0,1,2`，所以 `l=2`。  
    `L = √[l(l+1)]ℏ = √6 ℏ`。

14. `M₂` 转过角度：`λ(N₂−N₁)/(2L)`

    等厚条纹间距 `Δx = λ/(2α)`，宽度 `L` 内条纹数 `N = L/Δx = 2αL/λ`。  
    因此转角变化为 `Δα = λ(N₂−N₁)/(2L)`。

15. 横向动量最小不确定量：`5.28×10⁻²⁵ N·s`

    `ΔxΔp_x ≥ ℏ/2`，取 `Δx = 0.1 nm = 1.0×10⁻¹⁰ m`。  
    `Δp_x,min = ℏ/(2Δx) = [6.63×10⁻³⁴/(2π)]/(2×10⁻¹⁰) = 5.28×10⁻²⁵ N·s`。

16. 星体角直径：`2.27×10⁻⁷ rad`，约 `0.0467″`

    星体圆面作光源时，条纹刚消失常用 Michelson 星体干涉首零条件：  
    `dα = 1.22λ`。  
    `α = 1.22×570×10⁻⁹/3.07 = 2.27×10⁻⁷ rad`。

    注：若课堂只用线光源空间相干性的简化式，则为 `α ≈ λ/d = 1.86×10⁻⁷ rad`。本题写“星体角直径”，优先取 `1.22λ/d`。

17. 作图要点：

    - 正晶体：`n_e > n_o`，所以出射时 `e` 光偏折更大，更靠近棱镜底边方向。
    - 光轴为纸面外方向，图中圆点表示光轴垂直纸面向外。
    - 入射光垂直 `AB` 面，进入晶体时不因入射面折射而改变方向；在晶体内分解为 `o` 光和 `e` 光。
    - `o` 光振动方向在纸面内，并垂直于主平面；`e` 光振动方向垂直纸面，可用点/叉表示。
    - 从 `AC` 面出射后画两束光：`e` 光相对 `o` 光偏折更大。

## 二、计算题

### 1. 椭圆偏振光通过偏振片

设两个正交分量为：

`E_x = A cosωt`  
`E_y = 2A cos(ωt + φ)`

总强度：

`I₀ ∝ <E_x²> + <E_y²> = A²/2 + 4A²/2 = 5A²/2`

偏振片通光方向与 `x` 轴夹角为 `θ`，投影电场为：

`E = E_x cosθ + E_y sinθ`

透射光强：

`I ∝ <E²>`

展开：

`<E²> = <E_x²>cos²θ + <E_y²>sin²θ + 2<E_xE_y>sinθcosθ`

其中：

`<E_x²> = A²/2`  
`<E_y²> = 2A²`  
`<E_xE_y> = A² cosφ`

所以：

`I = I₀/5 · (cos²θ + 4sin²θ + 4sinθcosθ cosφ)`

等价写法：

`I = I₀/5 · (cos²θ + 4sin²θ + 2sin2θ cosφ)`

### 2. 动量可能值、概率和平均值

题给：

`Ψ(x) = [4cos²(kx) + √2 − 2] / [2√(2πℏ)]`

利用：

`cos²(kx) = [1 + cos(2kx)]/2`

则：

`4cos²(kx) + √2 − 2 = 2 + 2cos(2kx) + √2 − 2 = √2 + 2cos(2kx)`

所以：

`Ψ(x) = (1/√2) · 1/√(2πℏ) + cos(2kx) · 1/√(2πℏ)`

又：

`cos(2kx) = [e^(i2kx) + e^(−i2kx)]/2`

动量本征函数：

`Φ_p(x) = 1/√(2πℏ) · e^(ipx/ℏ)`

因此展开为：

`Ψ(x) = (1/√2)Φ₀(x) + (1/2)Φ_{2ℏk}(x) + (1/2)Φ_{−2ℏk}(x)`

所以测量动量可能值和概率为：

- `p_x = 0`，概率 `1/2`
- `p_x = 2ℏk`，概率 `1/4`
- `p_x = −2ℏk`，概率 `1/4`

动量平均值：

`<p_x> = 0·1/2 + 2ℏk·1/4 + (−2ℏk)·1/4 = 0`

### 3. N 缝光栅夫琅禾费衍射光强公式

定义：

`β = πa sinθ/λ`  
`α = πd sinθ/λ`

#### 1. 单缝衍射振幅

单缝中央明纹中心振幅为 `E₀`，则衍射角 `θ` 方向的单缝振幅为：

`E_1(θ) = E₀ · sinβ/β`

单缝光强为：

`I_1(θ) = I₀ · (sinβ/β)²`

#### 2. N 缝相干叠加

相邻缝到观察方向的相位差：

`δ = 2πd sinθ/λ = 2α`

N 个等振幅相干波叠加，振幅因子为：

`sin(Nα)/sinα`

所以总振幅可写为：

`E(θ) = E₀ · sinβ/β · sin(Nα)/sinα`

总光强：

`I(θ) = I₀ · (sinβ/β)² · [sin(Nα)/sinα]²`

这就是缝宽为 `a`、光栅常数为 `d` 的 `N` 缝光栅在正入射下的夫琅禾费衍射光强公式。

补充判据：

- 光栅主极大：`d sinθ = kλ`
- 单缝暗纹：`a sinθ = mλ`
- 缺级条件：某一级光栅主极大同时落在单缝暗纹上，即同时满足上面两式。
