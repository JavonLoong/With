## 1. 最重要的结论

1. 你现在主要练大题是对的，因为大题会同时训练公式入口、条件判断、单位换算和计算过程。
2. 但不能只做大题。填空约 70 分，所以每天必须有一轮“公式默写 + 题型识别”。
3. 90+ 的核心不是做很多新题，而是把高频模型做到“看到关键词就自动开头”。
4. 100 分目标需要补低优先概念，但必须在 A 类题型稳定后再补。

1. 重看红题，不做新难题。

## 3. 题型分层

### A 类：必须稳定拿分

| 题型 | 看到什么关键词 | 第一行必须写什么 | 对应材料 |

| 双缝干涉 | 双缝、相邻明纹、屏距、条纹移动 | δ = d sinθ ≈ dx / D | 原题截图版 PPT 22 章；2020/2022 真题 |
| 薄膜干涉 | 薄膜、增透、反射明暗、半波损失 | 先判断半波损失，再写 2ne | 原题截图版 PPT 22 章；作业 22.14、22.19 |
| 迈克耳孙 | 动镜、条纹移动 N 条 | 2Δd = Nλ | 原题截图版 PPT 22 章；题库 3201 |
| 单缝衍射 | 单缝、中央明纹宽度、暗纹 | a sinθ = kλ | 原题截图版 PPT 23 章；2022 填空 |
| 光栅 | 光栅常数、最高级次、缺级 | d sinθ = kλ；缺级联立 a sinθ = mλ | 原题截图版 PPT 23 章；2022 计算 3 |
| 布拉格 | X 射线、晶体、一级极大 | 2d sinφ = kλ | 作业 23.20、23.21 |
| 偏振强度 | 自然光、偏振片、夹角 | 第一片 I₁ = I₀/2，后续 I = I_in cos²α | 原题截图版 PPT 24 章；2022 计算 1 |

| 光电效应 | 截止电压、逸出功、红限频率 | hν = W + K_max = W + eU_s | 2022 填空 |
| 康普顿 | 散射角、波长改变量 | Δλ = λ_C(1 - cosφ) | 2020/2022 填空 |
| 德布罗意 | 电子加速、物质波 | λ = h/p；电子加速 λ = h / √(2m_eU) | 26 章作业 |
| 无限深势阱 | 波函数、概率、平均能量 | ψ_n = √(2/a) sin(nπx/a)，E_n = n²h²/(8ma²) | 2020 计算 3 |

### B 类：冲 90+ 必须会填空

| 题型 | 最小要求 |
|---|---|
| 时间相干性、空间相干性 | 会判断条纹为什么消失；不要因为书上星号误删 |
| 瑞利判据 | 圆孔/望远镜用 θ_min = 1.22λ/D |
| N 缝强度 | 中央主极大振幅 N 倍，强度 N² 倍 |
| 部分偏振与偏振度 | P = (I_max - I_min)/(I_max + I_min) |
| 波片 | 波片只改变两正交分量相位差，四分之一波片不一定直接变圆偏振 |
| 双折射 | o 光/e 光、光轴、主截面、振动方向能判断 |
| 不确定关系 | ΔxΔp ≥ ℏ/2，ΔEΔt ≥ ℏ/2 |
| 量子数 | n、l、m_l、m_s 的合法范围；壳层最多 2n² 个电子 |
| X 射线截止波长 | λ_min = hc/(eU) |
| 激光 | 受激辐射、粒子数反转、谐振腔 |

## 4. 必背公式清单

每天至少闭卷默写两遍。背公式时不要只背式子，要连同“什么时候用”一起背。

### 22 章 光的干涉

| 用途 | 公式 |
|---|---|
| 相位差与光程差 | Δφ = 2πδ / λ |
| 光程 | δ = Σ n r 的差 |
| 干涉明纹 | δ = kλ |
| 干涉暗纹 | δ = (k + 1/2)λ |
| 杨氏双缝 | δ = d sinθ ≈ dx / D |
| 条纹间距 | Δx = λD / d |
| 迈克耳孙动镜 | 2Δd = Nλ |
| 薄膜正入射 | 几何光程差 2ne |
| 劈尖相邻条纹厚度差 | Δe = λ / (2n) |
| 衬比度 | V = (I_max - I_min)/(I_max + I_min) = 2A₁A₂/(A₁² + A₂²) |

半波损失口诀：反射从低折射率到高折射率时，反射光多 π 相位。薄膜题先判半波损失，再决定明暗条件。

### 23 章 光的衍射

| 用途 | 公式 |
|---|---|
| 单缝暗纹 | a sinθ = kλ，k = 1,2,... |
| 中央明纹角宽近似 | Δθ ≈ 2λ/a |
| 透镜焦平面中央明纹宽 | Δx ≈ 2fλ/a |
| 光栅主极大 | d sinθ = kλ |
| 光栅最高级次 | abs(k) ≤ d/λ |
| 缺级 | d sinθ = kλ 与 a sinθ = mλ 同时成立 |
| 光栅分辨本领 | R = λ/Δλ = kN |
| 瑞利判据 | θ_min = 1.22λ/D |
| 布拉格衍射 | 2d sinφ = kλ |

角度口诀：布拉格题最容易错角。如果题给的是晶面与入射线的夹角，用 φ；如果给的是法线夹角，用 90° - 题给角。

### 24 章 光的偏振

| 用途 | 公式 |
|---|---|
| 自然光过第一片偏振片 | I₁ = I₀/2 |
| 马吕斯定律 | I = I_in cos²α |
| 多片偏振片 | 第一片除 2，后面逐片乘 cos²α |
| 布儒斯特角 | tan i_B = n₂/n₁ |
| 布儒斯特几何关系 | i_B + r = 90° |
| 部分偏振度 | P = (I_max - I_min)/(I_max + I_min) |
| 波片相位延迟 | Δφ = 2π(n_o - n_e)d / λ |
| 四分之一波片 | abs(Δφ) = π/2 |
| 二分之一波片 | abs(Δφ) = π |

偏振强度口诀：自然光只有第一次过偏振片除以 2；后面只用 cos²。

### 26 章 波粒二象性

| 用途 | 公式 |
|---|---|
| 光子能量 | E = hν = hc/λ |
| 光子动量 | p = h/λ |
| 光电效应 | hν = W + K_max = W + eU_s |
| 红限频率 | ν₀ = W/h |
| 康普顿效应 | Δλ = λ_C(1 - cosφ) |
| 德布罗意波长 | λ = h/p |
| 电子经电压 U 加速 | λ = h / √(2m_e eU) |
| 不确定关系 | ΔxΔp ≥ ℏ/2 |
| 黑体维恩定律 | λ_m T = b |
| 黑体斯特藩定律 | M = σT⁴ |

### 27 章 薛定谔方程

| 用途 | 公式 |
|---|---|
| 概率密度 | ρ = abs(Ψ)² |
| 归一化 | ∫ abs(Ψ)² dx = 1 |
| 定态薛定谔方程 | Ĥψ = Eψ |
| 一维无限深势阱波函数 | ψ_n = √(2/a) sin(nπx/a) |
| 一维无限深势阱能级 | E_n = n²h²/(8ma²) |
| 动量本征函数 | φ_p(x) = 1/√(2πℏ) e^(ipx/ℏ) |
| 谐振子能级 | E_n = (n + 1/2)ℏω |

动量本征态题口诀：看到 coskx，就写成 (e^(ikx) + e^(-ikx))/2；看到 sinkx，就写成 (e^(ikx) - e^(-ikx))/(2i)。

### 28 章 原子中的电子

| 用途 | 公式/结论 |
|---|---|
| 氢原子能级 | E_n = -13.6/n² eV |
| 跃迁光子 | hν = abs(E_i - E_f) |
| 里德伯公式 | 1/λ = R(1/n_f² - 1/n_i²) |
| 角动量大小 | L = √(l(l+1))ℏ |
| 角动量 z 分量 | L_z = m_lℏ |
| 自旋 | m_s = ±1/2 |
| 壳层容量 | 2n² |
| 支壳层容量 | 2(2l + 1) |
| X 射线最短波长 | λ_min = hc/(eU) |

## 5. 大题模板

### 模板 1：干涉类大题

第一行：

```text
δ = 几何光程差 + 介质引起的光程差 + 可能的半波损失
```

然后按题型选：

| 题型 | 核心动作 |
|---|---|
| 双缝 | 写 δ = d sinθ ≈ dx/D |
| 加介质片 | 多出来的光程差是 (n - 1)e |
| 薄膜 | 先判半波损失，再写 2ne |
| 迈克耳孙 | 动镜位移一定写 2Δd = Nλ |

### 模板 2：衍射/光栅类大题

第一行：

```text
主极大：d sinθ = kλ
单缝暗纹：a sinθ = mλ
```

缺级题就是把两式联立。最高级次题就是看 |sinθ| ≤ 1。

### 模板 3：偏振强度类大题

第一行：

```text
自然光第一片：I₁ = I₀/2
线偏振后续：I = I_in cos²α
```

如果入射本来不是自然光，而是已经给了椭圆偏振或两个正交分量，就不能直接 I₀/2。要把光场投影到偏振片通光方向，再对时间平均。

### 模板 4：动量本征态展开

第一行：

```text
把三角函数写成 e^(ikx) 和 e^(-ikx)
```

然后：

| 动作 | 意义 |
|---|---|
| 展开波函数 | 找到可能测得的动量 |
| 看系数模平方 | 得到概率 |
| 概率加权 | 求平均动量 |

### 模板 5：无限深势阱

第一行：

```text
ψ_n = √(2/a) sin(nπx/a)，E_n = n²h²/(8ma²)
```

然后按题意求概率、平均能量、节点位置、跃迁能量。

## 6. 错题归类法

| 标记 | 含义 | 处理 |
|---|---|---|
| 红题 | 看题不知道第一行写什么 | 回到第 3 节题型表，背关键词 |
| 黄题 | 第一公式对，但符号、角度、半波损失、单位错 | 把易错点写在题旁边，隔 2 小时重做 |
| 绿题 | 能闭卷写完，结果也对 | 不再重复刷，考前只看第一行 |

每做完一套卷，只记录三列：

```text
题号 | 错因 | 下次第一行应该写什么
```
