# 速查表 v10 针对 v8 全量评判报告的修正说明

## 读取结论

`速查表v8_全量测试评判报告` 显示：v8 已从 v6 的约 50 分提升到可读往年卷平均约 76.6 分，2022 春卷约 80.5 分。剩余扣分主要不是基础公式缺失，而是：

1. 可压缩、Moody、PM、斜激波等完整查表不足。
2. 复杂控制体受力题还缺“最后怎么收口”的方向模板。
3. 模型相似/量纲换算仍容易只写骨架、不知道怎么换算。
4. 扫描图读图和长推导仍然不是六页纸能完全替代的内容。

## v10 做了什么

v10 没有再扩大图片，也没有新增大段解释；只把末页 `M26` 改成更高密度的“高频计算/查表/控制体收口”：

| v8 报告剩余风险 | v10 对应补强 |
|---|---|
| 复杂控制体受力方向不稳 | 加入多出口通式 `ΣF=Σout ρQV-Σin ρQV`，并提醒压力用表压、题问管/螺栓要取反。 |
| 喷嘴/弯管题容易只列动量不会收口 | 加入“连续求 V、Bernoulli 求 p、再分量列动量”的三步。 |
| 可压缩题查表入口仍不够快 | 明确等熵/面积输入 `M`，正激波输入 `M1`，斜激波输入 `M1,θ`，PM 输入 `ν(M)`。 |
| 管路题 Moody/局部损失易混 | 加入层/湍判断、`λ=64/Re`、光滑管公式、粗糙管查 Moody、局部损失用所在管段速度。 |
| 相似题只会写 π 定理不会换算 | 补 `F~ρV²L²`、`Δp~ρV²`、同流体缩尺下 `Fr` 与 `Re` 的速度比例。 |
