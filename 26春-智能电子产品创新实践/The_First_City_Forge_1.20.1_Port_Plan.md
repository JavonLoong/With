# The First City 完整移植计划文档

## 1. 文档目的

本文档用于评估并规划将 Minecraft 模组 **The First City** 从现有公开版本移植到 **Minecraft 1.20.1 Forge** 的完整实施方案。

本文档适用于以下场景：

- 与客户沟通报价和工期。
- 判断该项目是否适合承接。
- 拆分开发阶段、验收标准和风险。
- 作为后续正式合同、技术评估报告或开发排期的基础。

## 2. 当前已知信息

基于公开页面和 jar 结构粗查，当前模组情况如下：

| 项目 | 信息 |
| --- | --- |
| 模组名称 | The First City |
| 当前公开版本 | 1.0.2 |
| 当前 Minecraft 版本 | 1.19.3 |
| 当前加载器 | Fabric |
| 目标移植版本 | Minecraft 1.20.1 Forge |
| 公开依赖 | Fabric API、Cloth Config、GeckoLib |
| 内嵌/关联依赖 | Lodestone、Satin、Cardinal Components、MidnightLib 等 |
| 授权状态 | All Rights Reserved |
| jar 大小 | 约 169 MB |
| class 数量 | 约 400 个，其中模组本体约 278 个，Lodestone 相关约 122 个 |
| 数据/资源 | 包含自定义维度、预制区域、结构、模型、动画、贴图、音效、粒子等 |

初步结论：  
该项目不是普通升版本，也不是简单更换加载器。它属于 **Fabric 到 Forge 的大型玩法模组完整移植**，涉及服务端玩法、客户端渲染、多人同步、维度、预制地图、脚本流程和第三方库替换。

## 3. 项目目标

将 The First City 从 `Minecraft 1.19.3 Fabric` 完整移植为 `Minecraft 1.20.1 Forge` 模组。

完整移植目标包括：

- Forge 1.20.1 客户端可正常加载。
- Forge 1.20.1 专用服务器可正常加载。
- 单人模式可完整体验原模组主流程。
- 多人服务器可完整体验原模组主流程。
- 自定义维度、传送门、结构、预制地图正常工作。
- Boss、怪物、特殊实体、攻击实体、交互实体正常工作。
- 方块、物品、方块实体、调试工具正常注册和运行。
- 粒子、模型、动画、天空盒、音效、GUI、摄像机效果尽量复刻原版。
- 存档重进、死亡重生、掉线重连后主流程不被破坏。

## 4. 项目前置条件

正式进入完整开发前，必须满足以下条件：

1. 客户提供原作者或版权方授权。
2. 客户提供完整源码。
3. 客户提供完整资源文件。
4. 客户确认目标版本为 `Minecraft 1.20.1 Forge`。
5. 客户确认验收范围是“完整复刻”还是“核心流程可玩”。
6. 客户接受分阶段评估、分阶段付款、分阶段验收。

如果客户只能提供闭源 jar，不建议直接签完整移植包成功合同。此时应先做付费技术评估，评估完成后再决定是否继续。

## 5. 项目范围

### 5.1 包含范围

本项目默认包含：

- Fabric 工程迁移为 ForgeGradle 工程。
- `fabric.mod.json` 迁移为 `mods.toml`。
- Fabric 注册系统迁移为 Forge 注册系统。
- Fabric 事件迁移为 Forge EventBus。
- Fabric 网络通信迁移为 Forge SimpleChannel。
- Cardinal Components 迁移为 Forge Capability 或 SavedData 等价方案。
- 自定义实体、实体 AI、实体渲染器迁移。
- 自定义方块、物品、方块实体迁移。
- 自定义维度、维度类型、结构、预制区域迁移。
- 剧情脚本、阶段流程、目标系统迁移。
- 客户端摄像机、屏幕震动、标题、覆盖层迁移。
- 粒子、音效、天空盒、模型、动画迁移。
- GeckoLib 相关模型动画绑定适配 Forge 1.20.1。
- Lodestone/Satin 相关能力替换、移植或重写。
- 单人和多人完整流程测试。
- 安装文档、依赖文档、测试报告、已知问题清单。

### 5.2 不包含范围

除非另行报价，本项目默认不包含：

- 移植到 NeoForge。
- 移植到 Fabric 1.20.1。
- 支持 1.20.2、1.20.4、1.21 或其他 Minecraft 版本。
- 保证与大型整合包或未知第三方模组兼容。
- 重制美术资源、模型、音效或剧情内容。
- 新增原模组没有的玩法。
- 绕过版权限制或规避原作者授权。
- 无源码条件下承诺 100% 完整复刻。

## 6. 技术迁移方案

### 6.1 工程与构建系统

原 Fabric 工程需要迁移为 ForgeGradle 工程。

主要工作：

- 建立 Forge 1.20.1 项目结构。
- 使用 Java 17。
- 配置 ForgeGradle。
- 配置 Mojang mappings 或项目确认的映射体系。
- 将 Fabric entrypoint 拆分为 Forge mod 主类、客户端初始化、公共初始化。
- 配置资源目录、数据目录、运行配置和打包任务。

验收标准：

- 空壳 Forge mod 可启动客户端。
- 空壳 Forge mod 可启动专用服务器。
- 基础资源、语言文件、图标可被加载。

### 6.2 注册系统迁移

Fabric 注册方式需要迁移为 Forge 的 `DeferredRegister` 和 RegistryObject 体系。

主要对象：

- 方块。
- 物品。
- 方块实体类型。
- 实体类型。
- 粒子类型。
- 音效事件。
- 菜单/GUI 类型。
- 自定义维度相关注册项。
- 自定义命令。

注意事项：

- 需要处理 1.19.3 到 1.20.1 注册表变化。
- 数据驱动内容应优先保留为 datapack/json。
- 代码注册内容需要统一迁移到 Forge 生命周期。

### 6.3 事件系统迁移

Fabric 事件需要迁移到 Forge EventBus。

主要涉及：

- 服务端 tick。
- 客户端 tick。
- 世界渲染事件。
- 玩家登录、登出、重生、维度切换。
- 实体伤害、死亡、生成。
- 命令注册。
- 资源加载。
- 客户端渲染注册。

验收标准：

- 原模组依赖的生命周期事件全部恢复。
- 服务端逻辑不会在客户端侧错误执行。
- 客户端渲染逻辑不会在专用服务器加载时报错。

### 6.4 网络通信迁移

Fabric networking 需要迁移为 Forge `SimpleChannel`。

主要网络包类型：

- 客户端到服务端的交互包。
- 服务端到客户端的摄像机控制包。
- 服务端到客户端的粒子/爆炸/标题显示包。
- Boss 阶段同步包。
- 目标系统同步包。
- 方块实体或调试界面设置包。
- 传送、维度切换、玩家准备状态相关包。

设计要求：

- 所有包必须声明协议版本。
- 所有包必须区分客户端处理和服务端处理。
- 所有服务端处理必须回到主线程执行。
- 所有包必须验证玩家、维度、实体是否仍然有效。

验收标准：

- 单人模式网络逻辑正常。
- 专用服务器多人模式网络逻辑正常。
- 玩家掉线、重连、维度切换时不会产生崩溃。

### 6.5 组件与存档迁移

原模组使用 Cardinal Components 保存世界或实体状态，需要迁移到 Forge 能力体系或等价持久化方案。

可选实现：

- 实体状态使用 Forge Capability。
- 世界/全局状态使用 SavedData。
- 简单状态可使用实体 persistent data。
- 同步频繁状态使用自定义网络包。

重点状态：

- 当前目标/任务。
- 玩家特殊状态。
- 慢落状态。
- 炮台/发射相关状态。
- 背部部件或附属实体状态。
- Boss 阶段状态。
- 脚本流程状态。

验收标准：

- 保存退出后重新进入，主流程状态不丢失。
- 玩家死亡重生后关键状态符合原模组行为。
- 多人服务器重启后世界状态可恢复。

### 6.6 自定义维度与预制地图迁移

该模组包含自定义维度、维度类型、结构、schematic、region 文件和预制世界内容。

主要工作：

- 检查所有 `dimension` 和 `dimension_type` json。
- 适配 1.20.1 数据包格式。
- 迁移预制 region/entity 数据加载逻辑。
- 迁移自定义 ChunkGenerator 或预制 ChunkGenerator。
- 修复维度进入、退出、重生点、传送逻辑。
- 确认服务器首次生成、已有存档加载、多人进入都正常。

验收标准：

- 玩家可从主世界进入模组维度。
- 预制地图内容正确加载。
- 实体、方块实体、结构数据不丢失。
- 服务器重启后维度仍可正常进入。

### 6.7 实体与 Boss 逻辑迁移

该模组包含多个自定义实体和 Boss/攻击逻辑。

主要工作：

- 迁移实体类型注册。
- 迁移实体属性注册。
- 迁移实体 AI goal。
- 迁移自定义攻击实体。
- 迁移投射物、特效实体、触发实体。
- 迁移实体 NBT 保存和读取。
- 迁移实体网络同步数据。
- 迁移 GeckoLib 动画控制器。

验收标准：

- 所有核心实体可生成。
- Boss 战阶段能推进。
- 实体动画和攻击行为正常。
- 多人下实体状态同步正常。

### 6.8 方块、物品与方块实体迁移

主要工作：

- 迁移自定义方块。
- 迁移自定义物品。
- 迁移方块实体。
- 迁移方块实体渲染器。
- 迁移交互逻辑。
- 迁移调试工具。
- 迁移 loot table、blockstate、model、tag。

验收标准：

- 方块和物品可以正常注册、显示、放置、交互。
- 方块实体保存、加载、渲染正常。
- 关键交互不会在服务端产生异常。

### 6.9 客户端渲染迁移

该项目客户端表现复杂，是高风险部分。

主要工作：

- 实体渲染器迁移。
- 方块实体渲染器迁移。
- GeckoLib 模型和动画绑定。
- 粒子系统迁移。
- 天空盒和维度特效迁移。
- 屏幕覆盖层迁移。
- 标题渲染迁移。
- 屏幕震动迁移。
- 特殊 shader 或后处理效果迁移。
- Lodestone/Satin 相关能力替换或重写。

验收标准：

- 模型、动画、贴图显示正常。
- 粒子和音效按原流程触发。
- 天空盒和维度氛围效果可用。
- 客户端无明显渲染崩溃。
- 专用服务器不会加载客户端专属类。

### 6.10 摄像机与剧情脚本迁移

该模组包含摄像机控制、阶段脚本和剧情流程。

主要工作：

- 迁移摄像机点位、插值、镜头阶段。
- 迁移服务端触发脚本。
- 迁移客户端镜头播放逻辑。
- 迁移玩家输入限制或视角限制。
- 迁移标题、音效、粒子和镜头之间的同步。
- 处理玩家中途掉线、死亡、重进时的脚本恢复。

验收标准：

- 核心剧情镜头可播放。
- Boss 阶段切换镜头可触发。
- 多人下镜头同步行为符合预期。
- 玩家异常退出不会卡死流程。

## 10. 验收标准

### 10.1 基础验收

- Forge 1.20.1 客户端可正常启动。
- Forge 1.20.1 专用服务器可正常启动。
- 客户端可加入专用服务器。
- 模组资源无大面积缺失。
- 创建新世界不崩溃。

### 10.2 功能验收

- 传送门或入口机制可正常触发。
- 玩家可进入自定义维度。
- 预制地图加载正确。
- 核心实体可生成并执行 AI。
- Boss 流程可推进。
- 阶段切换可正常完成。
